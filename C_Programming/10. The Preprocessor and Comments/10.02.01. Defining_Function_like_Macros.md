# ✅ Function‑Like Macros

The `#define` directive can do more than simple text substitution—it can also create **macros that accept arguments**. These are known as **function‑like macros**, and they behave somewhat like inline functions, except the substitution happens entirely in the preprocessor. According to the GNU C Preprocessor documentation, a function‑like macro is defined by placing a parameter list immediately after the macro name with no space in between.

---

## ✅ Basic Example

```c
#include <stdio.h>
#define ABS(a) ((a) < 0 ? -(a) : (a))

int main(void)
{
    printf("abs of -1 and 1: %d %d", ABS(-1), ABS(1));
    return 0;
}
```

When the preprocessor expands this code, every occurrence of `ABS(x)` is replaced with the expression:

```
((x) < 0 ? -(x) : (x))
```

So `ABS(-1)` becomes `((-1) < 0 ? -(-1) : (-1))`.

---

## ✅ Why Parentheses Matter

The GNU documentation explains that macro parameters are replaced *literally* with the tokens of the argument. Because of this, **parentheses are essential** to preserve correct operator precedence.

For example:

```
ABS(10-20)
```

would expand to:

```
(10-20) < 0 ? -(10-20) : (10-20)
```

But if the macro were written without parentheses:

```c
#define ABS(a) a < 0 ? -a : a
```

the expansion would become:

```
10-20 < 0 ? -10-20 : 10-20
```

which evaluates incorrectly. Stack Overflow discussions emphasize this exact issue and recommend always wrapping both the entire macro body and each parameter in parentheses.

---

## ✅ Advantages and Trade‑offs

### **✅ Benefit: Speed**
Function‑like macros avoid function call overhead, so they can be faster than real functions.

### **⚠️ Drawback: Code Size**
Because macros expand inline, large macros can **inflate the final program** by duplicating code at every use.

### **⚠️ Drawback: Safety**
Macros do not evaluate arguments exactly once. If you pass an expression with side effects (like `i++`), it may be evaluated multiple times. CERT guidelines warn about this behavior and recommend caution with parameterized macros.

---

## ✅ Modern Alternative: `inline`

C99 introduced the `inline` keyword, which provides the speed benefits of macros while preserving type checking and safe argument evaluation. For most cases, `inline` functions are preferred over complex macros.

---
