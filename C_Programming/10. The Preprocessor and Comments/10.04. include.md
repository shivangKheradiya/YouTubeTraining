# ✅ The `#include` Directive

The **`#include`** directive instructs the C preprocessor to insert the contents of another file into the current source file before compilation begins. As Microsoft’s documentation explains, `#include` literally copies the contents of the specified file into the program during preprocessing.

You can write an include in two forms:

```c
#include "stdio.h"
#include <stdio.h>
```

Both forms ultimately bring in the declarations from the standard I/O header, but **the way the compiler searches for the file differs**, as confirmed by GCC’s documentation and Stack Overflow discussions.

---

# ✅ How the Search Rules Work

### **1. Angle brackets: `<file>`**
- Used for **system headers**.
- The compiler searches **only the system include directories** (e.g., `/usr/include` on Unix).
- This is the conventional form for standard library headers.

### **2. Double quotes: `"file"`**
- Used for **user‑defined headers**.
- The compiler first searches the **directory of the current source file**, then falls back to the system include paths if not found.
- This allows you to include project‑specific headers easily.

These behaviors match the search‑path rules described in GCC’s documentation.

---

# ✅ Nested Includes

An included file may itself contain `#include` directives—this is called **nested inclusion**.  
The C standards require compilers to support a minimum nesting depth:

- **C89:** at least **8** levels  
- **C99:** at least **15** levels  

Most modern compilers support far more.

---

# ✅ Typical Usage

Although both forms work, programmers generally follow this convention:

- **Angle brackets** for standard headers  
- **Quotes** for project headers  

This is a convention, not a rule—you can technically use either form for any file.

---

# ✅ Headers vs. Files

C defines a set of **standard headers** that provide declarations for the language’s libraries.  
A header is an **abstraction**: it may correspond to a file, but the standard does not require it to.  
In practice, however, headers are almost always implemented as files on disk.
