# ✅ Using `#ifdef` and `#ifndef` for Conditional Compilation

Conditional compilation in C can also be controlled using **`#ifdef`** (“if defined”) and **`#ifndef`** (“if not defined”). These directives check whether a macro has been defined earlier—typically using `#define`. According to cppreference, both directives are part of the standard conditional‑inclusion system, and ProgrammerAll confirms their meanings and usage.

---

## ✅ `#ifdef` — Compile Code Only If a Macro *Is* Defined

General form:

```c
#ifdef MACRO_NAME
    /* code */
#endif
```

If `MACRO_NAME` has been defined earlier, the enclosed code is included in the compilation. Otherwise, it is skipped.

---

## ✅ `#ifndef` — Compile Code Only If a Macro *Is Not* Defined

General form:

```c
#ifndef MACRO_NAME
    /* code */
#endif
```

This is the opposite of `#ifdef`: the block is compiled only when the macro is **not** defined.

---

## ✅ Both Directives Support `#else` and `#elif`

Just like `#if`, you can attach `#else` or `#elif` to create alternate compilation paths. ProgrammerAll confirms that `#elif` and `#else` work with `#ifdef` and `#ifndef` in the same way they do with `#if`.

---

## ✅ Example

```c
#include <stdio.h>
#define TED 10

int main(void)
{
#ifdef TED
    printf("Hi Ted\n");
#else
    printf("Hi anyone\n");
#endif

#ifndef RALPH
    printf("RALPH not defined\n");
#endif

    return 0;
}
```

### Output:

```
Hi Ted
RALPH not defined
```

- Because `TED` **is defined**, the first block prints “Hi Ted”.
- Because `RALPH` **is not defined**, the second block prints “RALPH not defined”.

If `TED` were not defined, the program would instead print:

```
Hi anyone
RALPH not defined
```

---

## ✅ Nesting Rules

Conditional directives can be nested. cppreference notes that nested conditional inclusion is fully supported in the C standard.

Minimum required nesting depth:

- **C89:** at least **8** levels  
- **C99:** at least **63** levels  

Each `#endif`, `#else`, or `#elif` always matches the **nearest** unmatched `#ifdef`, `#ifndef`, or `#if`.
