# ✅ Conditional Compilation with `#if`, `#else`, `#elif`, and `#endif`

C provides a group of preprocessor directives that let you **selectively compile** parts of your program based on constant expressions. This mechanism—called *conditional compilation*—is widely used to adapt code for different environments, configurations, or feature sets.

---

## ✅ `#if` — Compile Code Only When a Condition Is True

The basic structure is:

```c
#if constant-expression
    /* code */
#endif
```

According to Microsoft’s documentation, the expression must evaluate to a non‑zero value for the enclosed code to be included in the translation unit. The expression is evaluated **at compile time**, so it may only use constants or macros, not variables.

### Example

```c
#define MAX 100

#if MAX > 99
    printf("Compiled for array greater than 99.\n");
#endif
```

Because `MAX` is 100, the message is included in the compiled program.

---

## ✅ `#else` — Provide an Alternative Block

`#else` works like the `else` keyword in C: it provides a fallback when the `#if` condition is false. GeeksforGeeks confirms that `#else` defines the alternate block for a failed `#if`.

```c
#define MAX 10

#if MAX > 99
    printf("Compiled for array greater than 99.\n");
#else
    printf("Compiled for small array.\n");
#endif
```

Here, the second message is compiled because the condition is false.

---

## ✅ `#elif` — “Else If” for Multiple Conditions

`#elif` allows you to chain multiple compile‑time tests. Only the first true condition is used, and the rest are ignored. cppreference lists `#elif` as part of the standard conditional inclusion system.

General form:

```c
#if expression
    /* code */
#elif expression1
    /* code */
#elif expression2
    /* code */
...
#endif
```

### Example

```c
#define US 0
#define ENGLAND 1
#define FRANCE 2
#define ACTIVE_COUNTRY US

#if ACTIVE_COUNTRY == US
    char currency[] = "dollar";
#elif ACTIVE_COUNTRY == ENGLAND
    char currency[] = "pound";
#else
    char currency[] = "franc";
#endif
```

Only the block matching the active country is compiled.

---

## ✅ Nesting Conditional Directives

Conditional blocks can be nested. Tutorialspoint notes that nested conditional compilation is fully supported in C. The standards specify minimum nesting depths:

- **C89:** at least 8 levels  
- **C99:** at least 63 levels  

Each `#endif`, `#else`, or `#elif` always matches the **nearest** unmatched `#if` or `#elif`.

### Valid nested example

```c
#if MAX > 100
    #if SERIAL_VERSION
        int port = 198;
    #elif
        int port = 200;
    #endif
#else
    char out_buffer[100];
#endif
```
