# ✅ The `#line` Directive

The **`#line`** directive allows you to manually change the values of the predefined macros **`__LINE__`** and **`__FILE__`**, which the compiler normally uses to report the current line number and source filename. According to Microsoft’s documentation, `#line` instructs the preprocessor to reset the compiler’s notion of the current line number and optionally the filename. cppreference confirms that `#line` alters the preprocessor’s internal tracking of both values.

---

## ✅ What `__LINE__` and `__FILE__` Normally Do

- **`__LINE__`** expands to the current line number in the source file.  
- **`__FILE__`** expands to a string literal containing the name of the current input file.

These macros are automatically updated as the preprocessor reads each line.

---

## ✅ Syntax of `#line`

```c
#line number "filename"
```

- **number** — a positive integer that becomes the new value of `__LINE__`.  
- **"filename"** — optional; if provided, becomes the new value of `__FILE__`.  

The filename must be in quotes, as required by the standard and documented by Microsoft.

---

## ✅ Why Use `#line`?

`#line` is mainly used in **debugging**, **code generators**, and **tools that produce C code**. For example, parser generators like *bison* use `#line` so that compiler error messages refer to the original source file rather than the generated C output. Stack Overflow confirms this is the primary real‑world use case.

---

## ✅ Example Explained

```c
#include <stdio.h>

#line 100   /* reset the line counter */

int main(void)   /* now treated as line 100 */
{                /* line 101 */
    printf("%d\n", __LINE__);   /* line 102 */
    return 0;
}
```

Here’s what happens:

1. `#line 100` tells the preprocessor:  
   “Pretend the next line is line 100.”

2. The line containing `int main(void)` is therefore treated as line **100**.

3. The `{` line becomes **101**.

4. The `printf` line becomes **102**, so the program prints:

```
102
```

This behavior matches the description in cppreference and Microsoft’s documentation, which state that the line number increments after each processed line.
