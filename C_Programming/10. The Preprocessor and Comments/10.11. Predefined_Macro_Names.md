# ✅ Predefined Macro Names

C provides a set of **built‑in predefined macros** that the compiler automatically supplies during preprocessing. These macros give you information about the source file, the compilation environment, and the C standard version being used. According to GCC’s documentation and GeeksforGeeks, these macros are available in all conforming C compilers and expand to constant values during compilation.

The standard predefined macros are:

- **`__LINE__`**  
- **`__FILE__`**  
- **`__DATE__`**  
- **`__TIME__`**  
- **`__STDC__`**

C99 adds two more:

- **`__STDC_HOSTED__`**  
- **`__STDC_VERSION__`**

---

## ✅ `__LINE__` and `__FILE__`

These two macros were discussed earlier with `#line`, but in summary:

- **`__LINE__`** expands to the **current line number** in the source file as an integer.  
  GCC notes that its value changes with each new line processed.

- **`__FILE__`** expands to a **string literal** containing the name (or path) of the current source file.

These are commonly used in debugging, logging, and error reporting.

---

## ✅ `__DATE__`

- Expands to a **string literal** representing the date the file was compiled.  
- IBM’s documentation states the format is `"Mmm dd yyyy"` (e.g., `"Dec 01 2025"`).

This is useful for embedding build timestamps.

---

## ✅ `__TIME__`

- Expands to a **string literal** containing the compilation time.  
- The format is `"hh:mm:ss"` according to standard references.

---

## ✅ `__STDC__`

- Defined as **1** if the compiler conforms to the ANSI/ISO C standard.  
- Geekpedia confirms this is how you detect standard‑compliant compilers.

---

## ✅ C99 Additions

### **`__STDC_HOSTED__`**
- Defined as **1** if the implementation is *hosted* (i.e., running under an operating system).  
- Defined as **0** for *freestanding* environments such as embedded systems.

### **`__STDC_VERSION__`**
- Indicates the version of the C standard supported.  
- For C99, the value is **199901L** or greater, as documented by GCC and IBM.

Future standards increase this value accordingly.

---

These predefined macros are extremely helpful for diagnostics, conditional compilation, and embedding build metadata directly into your programs.
