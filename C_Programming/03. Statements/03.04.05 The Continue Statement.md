# 🔄 The `continue` Statement

## Overview
The **`continue` statement** works similarly to the `break` statement but with an important difference. Instead of terminating the loop entirely, `continue` **skips the remaining code in the current iteration** and forces the next iteration of the loop to begin immediately.  

---

## 🛠️ Behavior
- In a **`for` loop**, `continue` causes the **increment** and then the **conditional test** portions of the loop to execute.  
- In a **`while`** or **`do-while` loop**, program control passes directly to the **conditional test**.  
- This allows programmers to skip over certain cases without breaking out of the loop completely.  

---

## ✔️ Example 1: Counting Spaces
```c
/* Count spaces */
#include <stdio.h>

int main(void) {
    char s[80], *str;
    int space;
    printf("Enter a string: ");
    gets(s);
    str = s;

    for (space = 0; *str; str++) {
        if (*str != ' ') continue;
        space++;
    }

    printf("%d spaces\n", space);
    return 0;
}
```

### Explanation
- Each character in the string is tested.  
- If it is **not a space**, `continue` skips the increment of `space` and moves to the next iteration.  
- If it **is a space**, `space` is incremented.  

---

## ✔️ Example 2: Skipping Output After Special Character
```c
void code(void) {
    char done, ch;
    done = 0;

    while (!done) {
        ch = getchar();
        if (ch == '$') {
            done = 1;
            continue;
        }
        putchar(ch + 1);  /* shift alphabet one position higher */
    }
}
```

### Explanation
- Each character typed is shifted one position higher (e.g., `A` → `B`).  
- When `$` is entered, `done` becomes true.  
- The `continue` statement forces the loop to recheck the condition immediately, skipping the `putchar()` call.  
- The loop then terminates because `done` is true.  

---

## 📌 Key Notes
- `continue` is useful when you want to **skip certain iterations** but keep the loop running.  
- It provides finer control compared to `break`, which exits the loop entirely.  
- Commonly used in input validation, filtering, or skipping unwanted values during iteration.
