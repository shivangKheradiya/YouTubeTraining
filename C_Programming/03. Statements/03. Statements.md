# 📝 Statements

## Overview
In C, a **statement** is the fundamental unit of execution. Each statement specifies an **action** that the program can perform. Together, statements form the logic and flow of a program.  

C categorizes statements into several groups, each serving a distinct purpose in program control and structure.  

---

## 🛠️ Categories of Statements

- **Selection Statements**  
  - Used for decision-making.  
  - Examples: `if`, `switch`.  
  - Often referred to as **conditional statements**.  

- **Iteration Statements**  
  - Used for repetition (loops).  
  - Examples: `while`, `for`, `do-while`.  

- **Jump Statements**  
  - Used to alter the normal flow of control.  
  - Examples: `break`, `continue`, `goto`, `return`.  

- **Label Statements**  
  - Used with `switch` and `goto`.  
  - Examples: `case`, `default`, and labels for `goto`.  

- **Expression Statements**  
  - A valid expression followed by a semicolon.  
  - Example: `x = y + 2;`.  

- **Block Statements (Compound Statements)**  
  - A group of statements enclosed in `{ }`.  
  - Example:  
    ```c
    {
        int x = 5;
        printf("%d", x);
    }
    ```

---

## 📌 Key Notes
- Many statements depend on the outcome of **conditional tests** (true or false).  
- **True** is represented by any nonzero value.  
- **False** is represented by `0`.  
- Understanding how statements are categorized helps in structuring programs logically and efficiently.
