# 🔁 The `do-while` Loop

## Overview
Unlike `for` and `while` loops, which test their condition **at the top** of the loop, the **`do-while` loop** checks its condition **at the bottom**. This guarantees that the loop body executes **at least once**, regardless of the condition.  

---

## 🛠️ General Form
```c
do {
    statement;
} while (condition);
```

- **statement** → May be a single statement, block of statements, or even empty.  
- **condition** → Any valid expression; true is nonzero, false is `0`.  
- Curly braces `{}` are optional for a single statement but recommended for clarity.  
- The loop continues until the condition becomes false.  

---

## ✔️ Example 1: Reading Numbers Until ≤ 100
```c
do {
    scanf("%d", &num);
} while (num > 100);
```

### Explanation
- The loop reads numbers from the keyboard.  
- It repeats until the user enters a number less than or equal to 100.  
- Since the condition is checked at the bottom, the loop executes at least once.  

---

## ✔️ Example 2: Menu Selection
```c
void menu(void) {
    char ch;
    printf("1. Check Spelling\n");
    printf("2. Correct Spelling Errors\n");
    printf("3. Display Spelling Errors\n");
    printf("Enter your choice: ");

    do {
        ch = getchar();  /* read the selection */
        switch (ch) {
            case '1':
                check_spelling();
                break;
            case '2':
                correct_errors();
                break;
            case '3':
                display_errors();
                break;
        }
    } while (ch != '1' && ch != '2' && ch != '3');
}
```

### Explanation
- The menu is displayed once, guaranteed by the `do-while`.  
- The loop continues until the user enters a valid option (`1`, `2`, or `3`).  
- Invalid input causes the menu to reprompt.  

---

## 📌 Key Notes
- The `do-while` loop is ideal when the body must run **at least once**.  
- Commonly used for **menu-driven programs**, input validation, and retry mechanisms.  
- Condition checking at the bottom eliminates the need for a separate pre-loop test.
