# ✅ True and False

## Overview
Many statements in C rely on **conditional expressions** to determine the program’s flow of execution. A conditional expression evaluates to either **true** or **false**, guiding which action should be taken.  

---

## 🛠️ True and False in C
- **True** → Any **nonzero value**, including negative numbers.  
- **False** → The value `0`.  
- This design allows C to handle conditions with great efficiency, since almost any numeric result can be directly interpreted as a Boolean outcome.  

---

## 📌 Key Notes
- C does not have a dedicated Boolean type in its earliest versions; instead, integers are used to represent truth values.  
- Modern C (C99 and later) introduces `_Bool` and `stdbool.h` for explicit Boolean usage, but the traditional rule (`0` = false, nonzero = true) remains valid.  
- This approach makes conditional checks flexible and efficient, enabling compact coding patterns.  

---

## ✔️ Example
```c
#include <stdio.h>

int main(void) {
    int x = -5;   // nonzero, so true
    int y = 0;    // zero, so false

    if (x) {
        printf("x is true\n");
    }
    if (!y) {
        printf("y is false\n");
    }
    return 0;
}
```

### Output:
```
x is true
y is false
```
