# ❓ The `?` Alternative (Ternary Operator)

## Overview
The **ternary operator (`? :`)** in C provides a concise way to write conditional logic. It can often replace simple `if-else` statements, making code shorter and more expressive.  

---

## 🛠️ General Form
```c
Exp1 ? Exp2 : Exp3
```

- **Exp1** → The condition to evaluate.  
- **Exp2** → The expression executed if `Exp1` is true.  
- **Exp3** → The expression executed if `Exp1` is false.  
- The colon (`:`) separates the two possible outcomes.  

---

## 📌 Key Notes
- The ternary operator requires **three operands**, hence the name *ternary*.  
- The value of the entire expression depends on the evaluation of `Exp1`.  
- It can be used for assignments, function calls, or inline conditional logic.  
- While compact, it should be used for **simple conditions** — complex logic is better expressed with `if-else`.  

---

## ✔️ Example 1: Assignment
```c
int x = 10;
int y = x > 9 ? 100 : 200;
```
- If `x > 9` is true, `y = 100`.  
- Otherwise, `y = 200`.  

Equivalent `if-else`:
```c
if (x > 9) 
    y = 100;
else 
    y = 200;
```

---

## ✔️ Example 2: Squaring With Sign Preservation
```c
#include <stdio.h>

int main(void) {
    int isqrd, i;
    printf("Enter a number: ");
    scanf("%d", &i);

    isqrd = i > 0 ? i * i : -(i * i);
    printf("%d squared is %d", i, isqrd);

    return 0;
}
```
- Positive numbers are squared normally.  
- Negative numbers are squared but the sign is preserved (e.g., `-10` → `-100`).  

---

## ✔️ Example 3: Function Calls in Ternary Operator
```c
#include <stdio.h>

int f1(int n) {
    printf("%d ", n);
    return 0;
}

int f2(void) {
    printf("entered");
    return 0;
}

int main(void) {
    int t;
    printf("Enter a number: ");
    scanf("%d", &t);

    t ? f1(t) + f2() : printf("zero entered.");
    printf("\n");

    return 0;
}
```
- If `t` is nonzero, both `f1()` and `f2()` execute.  
- If `t` is zero, `printf("zero entered.")` executes.  
- The result of the ternary expression is discarded in this case.  

---

## ✔️ Example 4: Magic Number Program With `?`
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int magic;
    int guess;

    magic = rand();  /* generate the magic number */
    printf("Guess the magic number: ");
    scanf("%d", &guess);

    if (guess == magic) {
        printf("** Right ** ");
        printf("%d is the magic number", magic);
    } else {
        guess > magic ? printf("High") : printf("Low");
    }

    return 0;
}
```
- Uses the ternary operator to print **High** or **Low** depending on the guess.  

---

## ⚠️ Important Note
- Compilers may **rearrange the order of evaluation** of expressions for optimization.  
- This can sometimes cause function calls inside ternary expressions to execute in an unexpected sequence.
