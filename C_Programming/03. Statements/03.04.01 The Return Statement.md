# ↩️ The `return` Statement

## Overview
The **`return` statement** is used to exit from a function and transfer control back to the point where the function was called. It is categorized as a **jump statement** because it causes execution to "jump back" to the caller.  

A `return` may or may not have a value associated with it, depending on the function’s return type.  

---

## 🛠️ General Form
```c
return expression;
```

- **With expression** → Used in functions declared with a non-`void` return type. The value of the expression becomes the function’s return value.  
- **Without expression** → Used in functions declared as `void`. No value is returned.  

---

## 📌 Key Notes
- In **C89**, a `return` statement in a non-`void` function does not technically require a value. If omitted, a **garbage value** is returned.  
- In **C99** (and C++), a `return` statement in a non-`void` function **must return a value**.  
- Even in C89, it is considered **bad practice** to omit a return value in a non-`void` function.  
- A function can contain multiple `return` statements, but execution stops at the first one encountered.  
- The closing brace `}` of a function also implies a return. In a non-`void` function, this results in an **undefined return value**.  
- A `void` function cannot contain a `return` statement with a value.  

---

## ✔️ Example 1: Returning a Value
```c
int square(int x) {
    return x * x;  /* returns the square of x */
}
```

### Explanation
- The function `square` is declared with a return type of `int`.  
- The `return` statement provides the computed value back to the caller.  

---

## ✔️ Example 2: Returning Without a Value
```c
void greet(void) {
    printf("Hello, world!\n");
    return;  /* optional, exits the function */
}
```

### Explanation
- The function `greet` is declared as `void`.  
- The `return;` statement exits the function but does not return a value.  

---

## ✔️ Example 3: Multiple Returns
```c
int compare(int a, int b) {
    if (a > b) return 1;
    if (a < b) return -1;
    return 0;  /* equal */
}
```

### Explanation
- The function exits immediately when a condition is met.  
- Multiple `return` statements provide different outcomes depending on input.

## 🎯 Learning Goals
By the end of this section, you will:
- Understand the syntax and purpose of the `return` statement.  
- Recognize the differences between C89 and C99/C++ regarding return values.  
- Apply `return` correctly in both `void` and non-`void` functions.  
- Avoid undefined behavior by always returning a value in non-`void` functions.
