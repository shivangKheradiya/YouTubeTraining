# 🔁 The `for` Loop

## Overview
The **`for` loop** is one of the most widely used iteration constructs in C and other procedural programming languages. In C, it offers **unexpected flexibility and power**, allowing concise control over initialization, condition checking, and variable updates within a single statement.  

---

## 🛠️ General Form
```c
for (initialization; condition; increment) statement;
```

- **Initialization** → Sets the loop control variable (executed once at the start).  
- **Condition** → A relational expression that determines whether the loop continues.  
- **Increment** → Defines how the loop control variable changes after each iteration.  
- Each section is separated by **semicolons**.  
- The loop executes as long as the condition is **true**. Once false, execution resumes after the loop.  

---

## ✔️ Example 1: Printing Numbers 1–100
```c
#include <stdio.h>

int main(void) {
    int x;

    for (x = 1; x <= 100; x++) 
        printf("%d ", x);

    return 0;
}
```

### Explanation
- `x` starts at 1.  
- The condition `x <= 100` keeps the loop running.  
- Each iteration increments `x` by 1 (`x++`).  
- The loop terminates when `x > 100`.  

---

## ✔️ Example 2: Iterating a Block of Statements
```c
for (x = 100; x != 65; x -= 5) {
    z = x * x;
    printf("The square of %d is %d\n", x, z);
}
```

### Explanation
- `x` starts at 100.  
- Each iteration subtracts 5 (`x -= 5`).  
- The loop continues until `x == 65`.  
- Both squaring and printing occur each iteration.  
- This is a **negative-running loop** since the control variable decreases.  

---

## ✔️ Example 3: Condition False at Entry
```c
x = 10;
for (y = 10; y != x; ++y) 
    printf("%d", y);

printf("%d", y);  /* Only this executes */
```

### Explanation
- Since `y == x` at the start, the condition `y != x` is false immediately.  
- The loop body never executes.  
- The only output is the final `printf`, which prints `10`.  

---

## 📌 Key Notes
- The conditional test is always performed **at the top of the loop**.  
- If the condition is false at the start, the loop body will not execute at all.  
- The `for` loop can be used for both **incrementing** and **decrementing** control variables.  
- Flexibility allows creative variations, but clarity should always be prioritized.
