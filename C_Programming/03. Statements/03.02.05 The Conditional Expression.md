# ⚖️ The Conditional Expression

## Overview
In C, **any valid expression** can be used to control an `if` statement or the ternary (`? :`) operator. Unlike some languages (such as BASIC or Pascal), you are not restricted to relational or logical operators. Instead, the expression simply needs to evaluate to either **true** (nonzero) or **false** (`0`).  

---

## 🛠️ Key Concept
- **True** → Any nonzero value (positive or negative).  
- **False** → The value `0`.  
- This flexibility allows programmers to use variables directly in conditions without explicitly comparing them to zero.  

---

## ✔️ Example Program: Divide Two Numbers
```c
#include <stdio.h>

int main(void) {
    int a, b;
    printf("Enter two numbers: ");
    scanf("%d%d", &a, &b);

    if (b) 
        printf("%d\n", a / b);
    else 
        printf("Cannot divide by zero.\n");

    return 0;
}
```

### Explanation
- If `b` is nonzero, the condition evaluates to **true**, and the division executes.  
- If `b` is `0`, the condition evaluates to **false**, and the `else` clause executes, preventing a divide-by-zero error.  

---

## 📌 Style Note
Writing the condition as:
```c
if (b != 0) printf("%d\n", a / b);
```
is **redundant** and considered **bad style**.  
- The value of `b` alone is sufficient to control the `if`.  
- Adding `!= 0` introduces unnecessary comparison and potential inefficiency.  

---

## 🎯 Learning Goals
By the end of this section, you will:
- Understand that any valid expression can control an `if` or `? :` operator.  
- Recognize that nonzero values are treated as true, while zero is false.  
- Avoid redundant comparisons like `!= 0` when a variable alone suffices.  
- Write cleaner, more efficient conditional expressions in C.
