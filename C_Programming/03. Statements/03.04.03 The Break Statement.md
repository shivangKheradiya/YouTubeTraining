# ⛔ The `break` Statement

## Overview
The **`break` statement** is a jump statement in C with two primary uses:  
1. To **terminate a case** in a `switch` statement.  
2. To **force immediate termination of a loop**, bypassing the normal loop conditional test.  

When encountered, `break` causes program control to exit from the innermost enclosing loop or `switch` and resume execution at the statement immediately following it.  

---

## 🛠️ General Form
```c
break;
```

- Exits the nearest enclosing loop (`for`, `while`, `do-while`) or `switch`.  
- Does not affect outer loops unless explicitly inside them.  

---

## ✔️ Example 1: Breaking Out of a Loop
```c
#include <stdio.h>

int main(void) {
    int t;
    for (t = 0; t < 100; t++) {
        printf("%d ", t);
        if (t == 10) break;
    }
    return 0;
}
```

### Explanation
- Prints numbers `0` through `10`.  
- When `t == 10`, the `break` statement terminates the loop immediately, overriding the condition `t < 100`.

## ✔️ Example 3: Break Exits Only Innermost Loop
```c
for (t = 0; t < 100; ++t) {
    int count = 1;
    for (;;) {
        printf("%d ", count);
        count++;
        if (count == 10) break;
    }
}
```

### Explanation
- Inner loop prints numbers `1` through `9`.  
- When `count == 10`, `break` exits only the **inner loop**.  
- Control returns to the outer loop, which repeats 100 times.  

---

## 📌 Key Notes
- `break` exits **only the innermost loop or switch**.  
- In a `switch`, `break` terminates the current case but does not affect any surrounding loop.  
- Without `break`, execution in a `switch` will “fall through” into the next case.  
- `break` is often used to handle **special conditions** that require immediate termination.
