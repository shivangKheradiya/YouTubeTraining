# 🧩 Nested `if` Statements

## Overview
A **nested `if`** is an `if` statement that appears inside another `if` or `else`. Nested `if` statements are very common in programming and allow for more complex decision-making.  

In nested structures, an **`else` always associates with the nearest unmatched `if`** within the same block. This rule ensures clarity in how conditions are evaluated.  

---

## 🛠️ General Behavior
- An `else` belongs to the **closest `if`** in the same block that does not already have an `else`.  
- Example:  
  ```c
  if (i) {
      if (j) dosomething1();
      if (k) dosomething2();   /* this if */
      else dosomething3();     /* associated with if(k) */
  }
  else dosomething4();         /* associated with if(i) */
  ```
- The final `else` is **not** associated with `if(j)` because it is outside its block.  

---

## 📌 Key Notes
- **C89** requires compilers to support at least **15 levels of nesting**.  
- **C99** raises this limit to **127 levels**.  
- Most modern compilers allow even more, but **deep nesting is rarely necessary**.  
- Excessive nesting can make code hard to read and maintain.  

---

## ✔️ Example Program: Magic Number with Nested `if`
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int magic;  /* magic number */
    int guess;  /* user's guess */

    magic = rand();  /* get a random number */
    printf("Guess the magic number: ");
    scanf("%d", &guess);

    if (guess == magic) {
        printf("** Right **\n");
        printf("%d is the magic number\n", magic);
    } else {
        printf("Wrong, ");
        if (guess > magic) 
            printf("too high\n");   /* nested if */
        else 
            printf("too low\n");
    }

    return 0;
}
```

### Explanation
- The outer `if` checks if the guess equals the magic number.  
- If not, the `else` executes and contains another `if` to check whether the guess is too high or too low.  
- This nested structure provides **more detailed feedback** to the player.
