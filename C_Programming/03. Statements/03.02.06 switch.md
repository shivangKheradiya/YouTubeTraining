# 🔀 The `switch` Statement

## Overview
C provides a built-in **multiple-branch selection statement** called `switch`. It allows a program to test the value of an expression against a list of **integer or character constants**, executing the statements associated with the first matching case.  

---

## 🛠️ General Form
```c
switch (expression) {
    case constant1:
        statement sequence
        break;
    case constant2:
        statement sequence
        break;
    case constant3:
        statement sequence
        break;
    ...
    default:
        statement sequence
}
```

- The **expression** must evaluate to an **integer type** (including characters, which are converted to integers).  
- **Floating-point expressions are not allowed**.  
- The `default` case executes if no matches are found. It is optional.  
- Execution continues until a `break` statement or the end of the `switch` block is reached.  

---

## 📌 Key Notes
- **C89** requires compilers to support at least **257 case statements**.  
- **C99** raises this requirement to **1,023 case statements**.  
- In practice, fewer cases are recommended for efficiency.  
- `case` is a **label statement** and cannot exist outside of a `switch`.  
- The `break` statement is optional. If omitted, execution **“falls through”** into the next case.  

---

## ⚖️ Differences Between `switch` and `if`
- `switch` can only test for **equality**.  
- `if` can evaluate **any relational or logical expression**.  
- No two case constants in the same `switch` can have identical values.  
- Character constants used in `switch` are automatically converted to integers.  

---

## ✔️ Example 1: Menu Selection
```c
void menu(void) {
    char ch;
    printf("1. Check Spelling\n");
    printf("2. Correct Spelling Errors\n");
    printf("3. Display Spelling Errors\n");
    printf("Strike Any Other Key to Skip\n");
    printf("Enter your choice: ");

    ch = getchar();  /* read the selection from the keyboard */

    switch (ch) {
        case '1':
            check_spelling();
            break;
        case '2':
            correct_errors();
            break;
        case '3':
            display_errors();
            break;
        default:
            printf("No option selected");
    }
}
```

### Explanation
- The user selects a menu option by pressing a key.  
- The `switch` executes the corresponding function.  
- The `default` handles invalid input.

## ✔️ Example 2: Drop-Through Behavior
```c
void inp_handler(int i) {
    int flag = -1;

    switch (i) {
        case 1:  /* These cases share the same sequence */
        case 2:
        case 3:
            flag = 0;
            break;
        case 4:
            flag = 1;   /* No break here */
        case 5:
            error(flag); /* Execution continues into case 5 */
            break;
        default:
            process(i);
    }
}
```

### Explanation
- Cases `1`, `2`, and `3` all execute the same statements (`flag = 0; break;`).  
- Case `4` sets `flag = 1` but has no `break`, so execution continues into case `5`, calling `error(flag)`.  
- This **fall-through behavior** avoids duplication of code.
