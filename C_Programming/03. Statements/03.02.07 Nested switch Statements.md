# 🔄 Nested `switch` Statements

## Overview
In C, you can place a **`switch` statement inside another `switch`**. This is called a **nested `switch`**. Even if the inner and outer `switch` statements contain **case constants with common values**, no conflicts occur because each `switch` operates independently within its own scope.  

---

## 🛠️ General Concept
- A nested `switch` is simply a `switch` used as part of the statement sequence of another `switch`.  
- Case constants in the inner `switch` do not interfere with those in the outer `switch`.  
- Each `switch` evaluates its own expression and executes its own case sequence.  

---

## ✔️ Example: Nested `switch`
```c
switch (x) {
    case 1:
        switch (y) {
            case 0: 
                printf("Divide by zero error.\n");
                break;
            case 1: 
                process(x, y);
                break;
        }
        break;

    case 2:
        /* other logic here */
        break;
}
```

### Explanation
- The outer `switch` evaluates the value of `x`.  
- If `x == 1`, the inner `switch` evaluates the value of `y`.  
- If `y == 0`, it prints a divide-by-zero error.  
- If `y == 1`, it calls `process(x, y)`.  
- The outer `switch` continues with other cases (like `case 2`).  

---

## 📌 Key Notes
- Nested `switch` statements are valid and commonly used when multiple variables need to be tested.  
- Each `switch` must have its own `break` statements to prevent unintended fall-through.  
- While nesting is allowed, **deeply nested `switch` statements can reduce readability**.  
- Consider refactoring into functions if nesting becomes too complex.
