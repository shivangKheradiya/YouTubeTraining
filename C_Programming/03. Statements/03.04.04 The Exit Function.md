# 🚪 The `exit()` Function

## Overview
The **`exit()` function** is part of the C standard library and provides a way to **terminate an entire program immediately**, returning control to the operating system. Unlike `break` or `return`, which exit only from loops or functions, `exit()` ends the program itself.  

---

## 🛠️ General Form
```c
#include <stdlib.h>

void exit(int return_code);
```

- **return_code** → An integer value returned to the calling process (usually the operating system).  
  - `0` → Indicates **normal program termination**.  
  - Nonzero values → Indicate **errors or abnormal termination**.  
  - Macros `EXIT_SUCCESS` and `EXIT_FAILURE` (defined in `<stdlib.h>`) can be used for clarity.  

---

## 📌 Key Notes
- `exit()` is not a control statement but a **library function**.  
- It acts as if the program "breaks out" completely.  
- Commonly used when a **mandatory condition** for execution is not satisfied.  
- Requires including the header file `<stdlib.h>`.  

---

## ✔️ Example 1: Hardware Requirement Check
```c
#include <stdlib.h>

int main(void) {
    if (!virtual_graphics()) 
        exit(1);   /* terminate if graphics adapter not present */

    play();
    /* ... */
}
```

### Explanation
- `virtual_graphics()` checks for required hardware.  
- If unavailable, the program terminates immediately with return code `1`.  
- Otherwise, execution continues with `play()`.  

---

## ✔️ Example 2: Menu with Exit Option
```c
void menu(void) {
    char ch;
    printf("1. Check Spelling\n");
    printf("2. Correct Spelling Errors\n");
    printf("3. Display Spelling Errors\n");
    printf("4. Quit\n");
    printf("Enter your choice: ");

    do {
        ch = getchar();  /* read user input */
        switch (ch) {
            case '1':
                check_spelling();
                break;
            case '2':
                correct_errors();
                break;
            case '3':
                display_errors();
                break;
            case '4':
                exit(0);  /* terminate program */
        }
    } while (ch != '1' && ch != '2' && ch != '3');
}
```

### Explanation
- The menu executes at least once.  
- Options `1–3` perform actions.  
- Option `4` calls `exit(0)`, terminating the program and returning control to the operating system.
