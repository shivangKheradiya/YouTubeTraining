# 🔄 The `while` Loop

## Overview
The **`while` loop** is the second looping construct available in C. It repeatedly executes a statement or block of statements **as long as a condition remains true**. When the condition becomes false, program control passes to the line immediately following the loop.  

---

## 🛠️ General Form
```c
while (condition) 
    statement;
```

- **condition** → Any valid expression; true is any nonzero value, false is `0`.  
- **statement** → May be empty, a single statement, or a block of statements enclosed in `{ }`.  
- The test is performed **at the top of the loop**, meaning the body may not execute at all if the condition is false initially.  

---

## ✔️ Example 1: Waiting for Input
```c
char wait_for_char(void) {
    char ch;
    ch = '\0';  /* initialize ch */
    while (ch != 'A') 
        ch = getchar();
    return ch;
}
```

### Explanation
- `ch` starts as `'\0'`.  
- The loop continues until the user types `A`.  
- Once `ch == 'A'`, the condition becomes false, and the loop terminates.  

---

## ✔️ Example 2: Padding a String
```c
#include <stdio.h>
#include <string.h>

void pad(char *s, int length);

int main(void) {
    char str[80];
    strcpy(str, "this is a test");
    pad(str, 40);
    printf("%d", strlen(str));
    return 0;
}

/* Add spaces to the end of a string. */
void pad(char *s, int length) {
    int l;
    l = strlen(s);  /* find out how long it is */
    while (l < length) {
        s[l] = ' ';  /* insert a space */
        l++;
    }
    s[l] = '\0';    /* terminate with null */
}
```

### Explanation
- If the string is shorter than `length`, spaces are added until it reaches the desired size.  
- If the string is already long enough, the loop body does not execute.  

---

## ✔️ Example 3: Multiple Exit Conditions
```c
void func1(void) {
    int working;
    working = 1;  /* true */
    while (working) {
        working = process1();
        if (working)
            working = process2();
        if (working)
            working = process3();
    }
}
```

### Explanation
- The loop continues while `working` is true.  
- Any of the three functions may return false, causing the loop to exit.  

---

## ✔️ Example 4: Empty Body Loop
```c
while ((ch = getchar()) != 'A') ;
```

### Explanation
- The loop runs until the user types `A`.  
- The assignment inside the condition is valid because `=` is an operator that evaluates to the right-hand value.  
- No body is needed; the condition itself performs the work.  

---

## 📌 Key Notes
- The `while` loop is ideal for **open-ended iteration** where the number of repetitions is not known in advance.  
- The condition is checked **before each iteration**, so the loop may never execute.  
- Empty-body loops are valid and sometimes useful for concise algorithms.  
- Multiple conditions can be combined into a single loop-control variable.
