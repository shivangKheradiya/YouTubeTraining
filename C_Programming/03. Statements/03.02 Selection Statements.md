# 🔀 Selection Statements

## Overview
C provides mechanisms to make **decisions** within a program. These are called **selection statements**, and they allow the program to choose different paths of execution based on conditions.  

---

## 🛠️ Types of Selection Statements
- **`if` Statement**  
  - Executes a block of code if a condition evaluates to true.  
  - Can be extended with `else` and `else if` for multiple branches.  

- **`switch` Statement**  
  - Allows multi-way branching based on the value of an expression.  
  - Uses `case` labels and an optional `default` label.  

- **Ternary Operator `? :`**  
  - A compact alternative to `if` in certain circumstances.  
  - Syntax:  
    ```c
    condition ? expression_if_true : expression_if_false;
    ```  
  - Example:  
    ```c
    int max = (a > b) ? a : b;
    ```

---

## 📌 Key Notes
- Selection statements are often referred to as **conditional statements**.  
- The ternary operator is best used for **simple conditional assignments**.  
- For complex logic, prefer `if` or `switch` for clarity.  

---

## ✔️ Example
```c
#include <stdio.h>

int main(void) {
    int x = 10, y = 20;

    // if statement
    if (x < y) {
        printf("x is less than y\n");
    }

    // switch statement
    switch (x) {
        case 10:
            printf("x is 10\n");
            break;
        default:
            printf("x is not 10\n");
    }

    // ternary operator
    int max = (x > y) ? x : y;
    printf("Max is %d\n", max);

    return 0;
}
```
