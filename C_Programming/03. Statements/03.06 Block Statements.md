# 📦 Block Statements

## Overview
A **block statement** (also called a **compound statement**) is a group of related statements that are treated as a single unit. Blocks are enclosed in **curly braces `{}`** and are logically bound together.  

Programmers most often use block statements to create a **multi-statement target** for control structures such as `if`, `for`, `while`, or `switch`. However, a block can appear **anywhere** a single statement is valid.  

---

## 🛠️ General Form
```c
{
    statement1;
    statement2;
    ...
}
```

- Begins with `{` and ends with `}`.  
- Contains one or more statements that execute together.  
- Can be used wherever a single statement is allowed.  

---

## ✔️ Example: Free-Standing Block
```c
#include <stdio.h>

int main(void) {
    int i;

    {   /* a free-standing block statement */
        i = 120;
        printf("%d", i);
    }

    return 0;
}
```

### Explanation
- The block `{ ... }` is independent and valid even outside of control structures.  
- Inside the block, `i` is assigned the value `120` and printed.  
- Although unusual, this demonstrates that blocks can be used anywhere a statement is valid.  

---

## 📌 Key Notes
- Blocks are essential for grouping multiple statements under a single control structure.  
- They improve readability and maintainability by clearly defining logical units of code.  
- Free-standing blocks are valid but rarely used in practice.  
- Variables declared inside a block have **block scope**, meaning they are accessible only within that block.
