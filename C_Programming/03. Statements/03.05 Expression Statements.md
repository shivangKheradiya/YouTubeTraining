# 🖊️ Expression Statements

## Overview
An **expression statement** in C is simply a **valid expression followed by a semicolon**. While expressions are covered in detail elsewhere, a few special points are worth noting here. Expression statements are the most common type of statement in C, used for function calls, assignments, and even empty (null) operations.  

---

## 🛠️ General Form
```c
expression;
```

- Any valid expression followed by a semicolon is an expression statement.  
- The expression is evaluated, and if it produces side effects (like assignments or function calls), those effects occur.  

---

## ✔️ Examples
```c
func();      /* a function call */
a = b + c;   /* an assignment statement */
b + f();     /* valid, but unusual statement */
;            /* an empty (null) statement */
```

### Explanation
- **Function call (`func();`)** → Executes the function.  
- **Assignment (`a = b + c;`)** → Stores the result of `b + c` into `a`.  
- **Strange but valid (`b + f();`)** → Evaluates the expression even if the result is unused. The function `f()` may perform necessary side effects.  
- **Empty statement (`;`)** → Represents a null operation. Sometimes useful in loops or placeholders.  

---

## 📌 Key Notes
- Expression statements are the **workhorses of C programs**, since most actions (assignments, function calls) are expressed this way.  
- Even seemingly “strange” expressions are valid if they follow the syntax rules.  
- Empty statements (`;`) are legal and sometimes used intentionally, for example in loops with no body.  

---

## 🎯 Learning Goals
By the end of this section, you will:
- Understand what constitutes an expression statement.  
- Recognize common forms: function calls, assignments, and null statements.  
- Appreciate that even unused expressions may have side effects.  
- Apply empty statements appropriately in special cases.
