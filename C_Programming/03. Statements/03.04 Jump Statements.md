# 🚀 Jump Statements in C

## Overview
C provides four **jump statements** that perform an **unconditional branch** in program execution. These statements allow control to move directly to another part of the program, bypassing the normal sequential flow.  

---

## 🛠️ The Four Jump Statements
- **`return`**  
  - Exits from a function immediately.  
  - Can optionally return a value to the calling function.  
  - Usable anywhere inside a function.  

- **`goto`**  
  - Transfers control to a labeled statement within the same function.  
  - Usable anywhere inside a function.  
  - Powerful but often discouraged because it can make code harder to read and maintain.  

- **`break`**  
  - Terminates the nearest enclosing loop (`for`, `while`, `do-while`) or a `switch` statement.  
  - Program control resumes at the statement immediately following the loop or switch.  

- **`continue`**  
  - Skips the remaining code in the current iteration of a loop.  
  - Control jumps to the next iteration by re-evaluating the loop condition.  

---

## 📌 Key Notes
- `return` and `goto` can be used **anywhere inside a function**.  
- `break` and `continue` are used **only with loops**, and `break` also applies to `switch`.  
- These statements provide flexibility but should be used carefully to maintain readability and structure.  

---

## ✔️ Example: Using `break` in a `switch`
```c
switch (choice) {
    case 1:
        printf("Option 1 selected\n");
        break;
    case 2:
        printf("Option 2 selected\n");
        break;
    default:
        printf("Invalid option\n");
}
```

---

## ✔️ Example: Using `continue` in a Loop
```c
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) 
        continue;  /* skip even numbers */
    printf("%d ", i);  /* prints only odd numbers */
}
```
