# 🧾 Declaring Variables within a `for` Loop

## Overview
In **C99** and **C++** (but not in **C89**), it is possible to **declare a variable directly within the initialization portion of a `for` loop**. Such a variable has its **scope limited to the loop itself**, meaning it is local to that loop and cannot be accessed outside of it.  

This feature improves code clarity by keeping loop control variables confined to where they are used.  

---

## 🛠️ Example
```c
/* 
   Here, i is local to the for loop; 
   j is known outside the loop.
   *** This example is invalid in C89. ***
*/
int j;

for (int i = 0; i < 10; i++) 
    j = i * i;

/* i = 10;  *** Error *** -- i not known here! */
```

### Explanation
- `i` is declared inside the `for` loop initialization.  
- Its scope is limited to the loop block.  
- Outside the loop, `i` is **unknown** and cannot be referenced.  
- `j`, declared outside the loop, remains accessible after the loop ends.  

---

## 📌 Key Notes
- Declaring variables inside the `for` loop is **common practice** in modern C and C++.  
- It ensures that loop control variables are not accidentally reused outside the loop.  
- This feature is **not supported in C89**, so code must declare loop variables before the loop in that standard.  
- Limiting scope improves readability and reduces potential errors.
