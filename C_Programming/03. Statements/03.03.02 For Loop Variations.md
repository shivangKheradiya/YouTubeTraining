# 🔁 `for` Loop Variations

## Overview
The **`for` loop** is one of the most flexible constructs in C. While its most common form involves a single loop control variable, C allows several **variations** that increase its power, adaptability, and usefulness in different programming situations.  

---

## 🛠️ Common Variations

### 1. Multiple Loop Control Variables
Using the **comma operator**, you can control a loop with more than one variable.  
```c
for (x = 0, y = 0; x + y < 10; ++x) {
    y = getchar();
    y = y - '0';  /* convert ASCII digit to integer */
    ...
}
```
- Both `x` and `y` are initialized inside the `for`.  
- Each iteration increments `x` and updates `y` from keyboard input.  
- Both variables must reach the correct values for the loop to terminate.  

---

### 2. Converging From Both Ends
The following function demonstrates **two loop control variables** converging toward the middle of a string:  
```c
void converge(char *targ, char *src) {
    int i, j;
    printf("%s\n", targ);

    for (i = 0, j = strlen(src); i <= j; i++, j--) {
        targ[i] = src[i];
        targ[j] = src[j];
        printf("%s\n", targ);
    }
}
```
- `i` increases from the start, `j` decreases from the end.  
- Characters are copied from both ends until they meet in the middle.  

---

### 3. Complex Conditions
The condition can be **any relational or logical expression**, not just a simple comparison.  
```c
for (x = 0; x < 3 && strcmp(str, "password"); ++x) {
    printf("Enter password please: ");
    gets(str);
}
```
- The loop terminates either when the user enters the correct password (`strcmp == 0`) or after three attempts.  

---

### 4. Function Calls in Loop Sections
Each part of the `for` loop can contain **function calls**.  
```c
for (prompt(); t = readnum(); prompt()) 
    sqrnum(t);
```
- `prompt()` asks for input.  
- `readnum()` reads a number.  
- If the number is `0`, the loop terminates.  
- Otherwise, `sqrnum()` prints the square.  

---

### 5. Optional Sections
Any of the three sections (initialization, condition, increment) can be **left blank**.  
```c
for (x = 0; x != 123; ) 
    scanf("%d", &x);
```
- The increment section is omitted.  
- The loop runs until the user enters `123`.  

---

### 6. Initialization Outside the Loop
Sometimes the loop control variable must be initialized before the loop begins.  
```c
gets(s);  /* read a string into s */
if (*s) 
    x = strlen(s);  /* string length */
else 
    x = 10;

for (; x < 10; ) {
    printf("%d", x);
    ++x;
}
```
- Initialization occurs outside the `for`.  
- The loop runs until `x` reaches 10.  

---

## 📌 Key Notes
- The **comma operator** allows multiple expressions in initialization or increment.  
- Conditions can be **complex logical statements**, not just simple comparisons.  
- Any section of the `for` loop can be omitted.  
- Initialization can occur outside the loop when needed.  
- These variations make the `for` loop one of the most **powerful and flexible constructs** in C.
