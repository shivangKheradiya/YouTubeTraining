# 🔁 Iteration Statements

## Overview
In C, as in all modern programming languages, **iteration statements** (commonly called *loops*) allow a set of instructions to be executed repeatedly until a specified condition is met.  

This condition may be:  
- **Predetermined** → as in the `for` loop, where the number of iterations is typically known in advance.  
- **Open-ended** → as in the `while` and `do-while` loops, where execution continues until a condition becomes false.  

---

## 🛠️ Types of Iteration Statements
- **`for` Loop**  
  - Best suited when the number of iterations is known ahead of time.  
  - Combines initialization, condition, and increment in a single statement.  

- **`while` Loop**  
  - Executes as long as the condition remains true.  
  - Condition is checked before each iteration.  

- **`do-while` Loop**  
  - Similar to `while`, but guarantees at least one execution.  
  - Condition is checked **after** the loop body runs.  

---

## 📌 Key Notes
- Loops are fundamental for tasks such as traversing arrays, processing input, or repeating calculations.  
- Choosing the right loop depends on whether the iteration count is known or depends on runtime conditions.  
- Infinite loops can occur if the condition never becomes false — these must be used carefully.  

---

## ✔️ Example
```c
#include <stdio.h>

int main(void) {
    int i;

    // for loop: predetermined iterations
    for (i = 0; i < 5; i++) {
        printf("Iteration %d\n", i);
    }

    // while loop: open-ended
    i = 0;
    while (i < 5) {
        printf("While loop iteration %d\n", i);
        i++;
    }

    // do-while loop: executes at least once
    i = 0;
    do {
        printf("Do-while iteration %d\n", i);
        i++;
    } while (i < 5);

    return 0;
}
```
