# 🔎 The `if` Statement

## Overview
The **`if` statement** is the most fundamental decision-making construct in C. It allows a program to execute a block of code only if a specified condition evaluates to **true**. Optionally, an **`else` clause** can be added to handle the case when the condition is **false**.  

---

## 🛠️ General Form
```c
if (expression) 
    statement;
else 
    statement;
```

- **expression** → must evaluate to a scalar result (integer, character, pointer, floating-point, or `_Bool` in C99).  
- **statement** → can be a single statement, a block of statements enclosed in `{ }`, or nothing (empty statement).  
- The **`else` clause** is optional.  

---

## 📌 Key Notes
- If the **expression** evaluates to **true** (any nonzero value), the `if` block executes.  
- If the **expression** evaluates to **false** (`0`), the `else` block executes (if present).  
- Only one branch executes — **never both**.  
- Floating-point values can be used in conditions, but this is rare because floating-point operations are slower than integer or character operations.  

---

## ✔️ Example 1: Basic `if`
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int magic;  /* magic number */
    int guess;  /* user's guess */

    magic = rand();  /* generate the magic number */
    printf("Guess the magic number: ");
    scanf("%d", &guess);

    if (guess == magic) 
        printf("** Right **");

    return 0;
}
```

### Explanation
- The program generates a random number using `rand()`.  
- If the user’s guess matches the magic number, it prints **Right**.  
- Otherwise, nothing happens (since no `else` clause is present).  

---

## ✔️ Example 2: Using `else`
```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int magic;  /* magic number */
    int guess;  /* user's guess */

    magic = rand();  /* generate the magic number */
    printf("Guess the magic number: ");
    scanf("%d", &guess);

    if (guess == magic) 
        printf("** Right **");
    else 
        printf("Wrong");

    return 0;
}
```

### Explanation
- Adds an `else` clause to handle incorrect guesses.  
- If the guess is wrong, the program prints **Wrong**.
