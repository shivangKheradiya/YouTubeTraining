# 🧵 String Constants

## Overview
In C, a **string constant** (also called a *string literal*) is a sequence of characters enclosed in **double quotes**. Strings are widely used in functions like `printf()` and `scanf()` to display or process text.  

Although C supports string constants, it does **not** have a formal *string data type*. Instead, strings are represented internally as arrays of characters terminated by a special null character (`'\0'`).

---

## 📝 Syntax
```c
"This is a test"
```
- A string constant is enclosed in double quotes.  
- It is stored as a character array with an automatic `'\0'` at the end.  

---

## ✔️ Examples
```c
printf("Hello, World!");   // prints a string constant
char *str = "C programming"; // assigns a string constant to a pointer
```

---

## ⚖️ Strings vs. Characters
It is important not to confuse **strings** with **character constants**:  

- **Character constant** → Enclosed in single quotes `'a'`  
- **String constant** → Enclosed in double quotes `"a"`  

```c
char c = 'a';   // character constant
char *s = "a";  // string constant containing one character
```

- `'a'` is a single character.  
- `"a"` is a string containing one character plus the terminating `'\0'`.  

---

## 📌 Key Notes
- Strings in C are essentially **arrays of characters**.  
- Every string constant automatically ends with a **null terminator** (`'\0'`).  
- Since C does not have a built-in string type, strings are manipulated using pointers and arrays.
