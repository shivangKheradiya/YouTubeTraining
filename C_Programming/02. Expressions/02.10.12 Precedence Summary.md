# 📑 Operator Precedence Summary

## Overview
C defines a clear set of **operator precedence rules** that determine the order in which expressions are evaluated. Understanding precedence is critical to writing correct and predictable code, especially when combining multiple operators in a single expression.  

---

## 🛠️ General Rules
- **Most operators associate from left to right.**  
- **Unary operators** (`*`, `&`, `-`) and the **ternary operator (`? :`)** associate from **right to left**.  

---

## 📌 Key Notes
- Precedence determines **which operator is applied first** when multiple operators appear in an expression.  
- Associativity determines **the direction of evaluation** when operators of the same precedence appear together.  
- Parentheses `( )` can always be used to **override precedence** and make evaluation order explicit.  

---

## ✔️ Example
```c
int x = 10, y = 5, z;
z = x > y ? x - y : y - x;
```
- The ternary operator (`? :`) associates **right to left**, so the condition `x > y` is evaluated first.  
- Depending on the result, either `x - y` or `y - x` is chosen.  

---

## 🎯 Learning Goals
By the end of this section, you will:
- Understand how operator precedence affects expression evaluation.  
- Recognize the difference between **left-to-right** and **right-to-left** associativity.  
- Use parentheses to control and clarify the order of operations in complex expressions.
