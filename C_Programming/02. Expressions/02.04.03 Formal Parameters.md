# 🎯 Formal Parameters

## Overview
When a function in C is designed to accept input values, it must declare variables that will hold those values. These variables are called **formal parameters**.  

Formal parameters behave like **local variables** inside the function:  
- They are created when the function is called.  
- They exist only during the function’s execution.  
- They are destroyed once the function returns.  

---

## 📝 Declaration of Formal Parameters
Formal parameters are declared **inside the parentheses** following the function name.  

**General form:**
```c
return_type function_name(type1 param1, type2 param2, ...);
```

---

## ✔️ Example
```c
/* Return 1 if c is part of string s; 0 otherwise */
int is_in(char *s, char c) {
    while(*s)
        if(*s == c) return 1;
        else s++;
    return 0;
}
```

- The function `is_in()` has two formal parameters:  
  - `s` → a pointer to a string (`char *`)  
  - `c` → a character (`char`)  

- The function checks if the character `c` exists in the string `s`.  
- Returns `1` if found, `0` otherwise.  

---

## ⚖️ Behavior of Formal Parameters
- Formal parameters **receive the values** of the arguments passed to the function.  
- They can be used like any other local variable:  
  - You can assign new values to them.  
  - You can use them in expressions.  
- Like local variables, they are **dynamic**:  
  - Created when the function is entered.  
  - Destroyed when the function exits.  

---

## 📌 Key Notes
- Formal parameters are **isolated** from variables outside the function.  
- They provide a safe way to pass data into functions without relying on global variables.  
- Since they are local, their values **do not persist** between function calls.
