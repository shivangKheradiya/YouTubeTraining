# 🗂️ Storage Class Specifiers

## Overview
In C, **storage class specifiers** define how variables are stored, their lifetime, and their visibility within a program. They precede the type in a variable declaration and provide the compiler with instructions on how to manage the variable.  

Understanding storage classes is essential for writing efficient and predictable C programs.

---

## 🛠️ The Four Storage Class Specifiers
C supports four primary storage class specifiers:

1. **`extern`**  
   - Declares a variable that is defined elsewhere (often in another source file).  
   - Used to share global variables across multiple files.  
   - Example:  
     ```c
     extern int count; // declared here, defined elsewhere
     ```

2. **`static`**  
   - Limits the scope of a variable to the file or block in which it is declared.  
   - Retains its value between function calls.  
   - Example:  
     ```c
     static int counter = 0; // persists across calls
     ```

3. **`register`**  
   - Suggests that the variable should be stored in a CPU register for faster access.  
   - Useful for frequently accessed variables.  
   - Example:  
     ```c
     register int i; // stored in CPU register if possible
     ```

4. **`auto`**  
   - Declares a local variable with automatic storage duration.  
   - This is the default for local variables, so `auto` is rarely used explicitly.  
   - Example:  
     ```c
     auto int x = 5; // equivalent to just "int x = 5;"
     ```

---

## 📝 General Form
The syntax for declaring a variable with a storage class specifier is:

```c
storage_specifier type var_name;
```

Example:
```c
static int total;
extern double balance;
register char c;
auto int value;
```

---

## ⚖️ Special Note on `typedef`
- Both **C89** and **C99** treat `typedef` as a storage class specifier for syntactic convenience.  
- However, `typedef` is **not** a true storage class specifier in the common sense.  
- It is used to create type aliases and will be examined separately later in the tutorial.
