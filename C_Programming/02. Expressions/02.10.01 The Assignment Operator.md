# ➡️ The Assignment Operator

## Overview
The **assignment operator (`=`)** in C is one of the most fundamental operators. Unlike many other languages (such as Pascal, BASIC, or FORTRAN), where assignment is treated as a special statement, C allows the assignment operator to be used within **any valid expression**.  

The general form is:  
```c
variable_name = expression;
```
- The **left side (target)** must be an object capable of receiving a value (a modifiable lvalue).  
- The **right side (expression)** can be as simple as a constant or as complex as needed.  

---

## 🔑 lvalue vs. rvalue
- **lvalue (left value):** An object that can appear on the left side of an assignment. If it is modifiable, it essentially means a variable.  
- **rvalue (right value):** The value of an expression that appears on the right side of an assignment.  

Example:
```c
int x;
x = 10;   // x is the lvalue, 10 is the rvalue
```

---

## 🔄 Type Conversion in Assignments
When assigning values of different types, **type conversion** occurs automatically:  
- The **expression (right side)** is converted to the type of the **target variable (left side)**.  

### Example
```c
int x;
char ch;
float f;

void func(void) {
    ch = x;  // line 1
    x = f;   // line 2
    f = ch;  // line 3
    f = x;   // line 4
}
```

- **Line 1:** High-order bits of `x` are discarded; `ch` stores only the lower 8 bits.  
- **Line 2:** `x` receives the non-fractional part of `f`.  
- **Line 3:** `f` converts the 8-bit value of `ch` into floating-point format.  
- **Line 4:** `f` converts the integer value of `x` into floating-point format.  

---

## 📊 Common Type Conversions

| Target Type        | Expression Type         | Possible Info Loss                          |
|--------------------|-------------------------|---------------------------------------------|
| signed char        | char                    | If value > 127, target becomes negative      |
| char               | short int               | High-order 8 bits lost                      |
| char               | int (16 bits)           | High-order 8 bits lost                      |
| char               | int (32 bits)           | High-order 24 bits lost                     |
| char               | long int                | High-order 24 bits lost                     |
| short int          | int (16 bits)           | None                                        |
| short int          | int (32 bits)           | High-order 16 bits lost                     |
| int (16 bits)      | long int                | High-order 16 bits lost                     |
| int (32 bits)      | long int                | None                                        |
| long int (32 bits) | long long int (64 bits) | High-order 32 bits lost (C99 only)          |
| int                | float                   | Fractional part lost                        |
| float              | double                  | Precision loss, result rounded              |
| double             | long double             | Precision loss, result rounded              |

⚠️ Note: Conversions only change the **representation** of the value, not its precision or accuracy.

## 📌 Multiple Assignments
C allows assigning the same value to multiple variables in a single statement:  
```c
x = y = z = 0;
```
This is commonly used in professional programs to initialize several variables at once.

---

## ✍️ Compound Assignments
Compound assignment operators simplify repetitive assignment operations.  

Example:
```c
x = x + 10;   // standard assignment
x += 10;      // compound assignment
```

- `+=` assigns to `x` the value of `x + 10`.  
- Compound assignment operators exist for all binary operators (`+=`, `-=`, `*=`, `/=`, `%=` etc.).  

General form:
```c
var = var operator expression;
```
can be rewritten as:
```c
var operator= expression;
```

Example:
```c
x = x - 100;   // equivalent to
x -= 100;
```

Compound assignments are more compact and widely used in professional C programs, often referred to as **shorthand assignments**.
