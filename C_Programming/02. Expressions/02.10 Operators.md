# ⚙️ TOperators

## Overview
C is a language that places strong emphasis on **operators**, making them central to its programming style. Operators are special symbols that perform operations on variables and values. They allow concise, powerful manipulation of data and expressions.  

C provides a rich set of built-in operators, grouped into several categories based on their purpose.

---

## 🛠️ Main Classes of Operators

### 1. Arithmetic Operators
Used for mathematical calculations.  
Examples:  
- `+` (addition)  
- `-` (subtraction)  
- `*` (multiplication)  
- `/` (division)  
- `%` (modulus – remainder after division)  

---

### 2. Relational Operators
Used to compare values. They return **true (1)** or **false (0)**.  
Examples:  
- `==` (equal to)  
- `!=` (not equal to)  
- `<` (less than)  
- `>` (greater than)  
- `<=` (less than or equal to)  
- `>=` (greater than or equal to)  

---

### 3. Logical Operators
Used to combine or invert logical conditions.  
Examples:  
- `&&` (logical AND)  
- `||` (logical OR)  
- `!` (logical NOT)  

---

### 4. Bitwise Operators
Operate directly on the **binary representation** of integers.  
Examples:  
- `&` (bitwise AND)  
- `|` (bitwise OR)  
- `^` (bitwise XOR)  
- `~` (bitwise NOT)  
- `<<` (left shift)  
- `>>` (right shift)  

---

## 🔑 Special Operators
In addition to the main classes, C provides special-purpose operators:  
- **Assignment (`=`)** → Assigns a value to a variable.  
- **Increment/Decrement (`++`, `--`)** → Increase or decrease a variable by 1.  
- **Conditional (`?:`)** → Ternary operator for inline decisions.  
- **Comma (`,`)** → Allows multiple expressions in a single statement.  
- **sizeof** → Returns the size of a data type or variable.  

---

## 📌 Key Notes
- Operators are fundamental to C’s design, enabling concise and efficient code.  
- Many operators can be combined to form complex expressions.  
- Understanding operator precedence and associativity is crucial for correct evaluation of expressions.
