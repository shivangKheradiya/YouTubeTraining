# 📍 Local Variables

## Overview
**Local variables** are variables declared inside a function or code block. They are sometimes referred to as *automatic variables*, but the term *local variable* is more commonly used.  

Local variables are accessible **only within the block** in which they are declared. A block of code begins with an opening curly brace `{` and ends with a closing curly brace `}`.

---

## 🔑 Key Characteristics
- **Scope:** Limited to the block in which they are declared.  
- **Lifetime:** Created upon entry into the block and destroyed upon exit.  
- **Independence:** Variables with the same name in different blocks are distinct and unrelated.  
- **Storage:** By default, local variables are stored on the **stack**.  
- **Initialization:** They can be initialized when declared, and the value is reset each time the block is entered.  

---

## 📝 Examples

### Example 1: Local variables in different functions
```c
void func1(void) {
    int x;
    x = 10;
}

void func2(void) {
    int x;
    x = -199;
}
```
Here, `x` in `func1` and `x` in `func2` are completely independent. Each exists only within its own function.

---

### Example 2: Local variable inside an inner block
```c
#include <stdio.h>

int main(void) {
    int x;
    x = 10;

    if(x == 10) {
        int x; // hides the outer x
        x = 99;
        printf("Inner x: %d\n", x);
    }

    printf("Outer x: %d\n", x);
    return 0;
}
```

**Output:**
```
Inner x: 99
Outer x: 10
```

The inner `x` hides the outer `x` inside the `if` block. Once the block ends, the outer `x` becomes visible again.

---

### Example 3: Local variable inside a conditional block
```c
void f(void) {
    int t;
    scanf("%d%*c", &t);

    if(t == 1) {
        char s[80]; // created only upon entry
        printf("Enter name: ");
        gets(s);
        // s is valid only inside this block
    }
    // s is not accessible here
}
```

---

## ⚖️ C89 vs. C99 Rules
- **C89:** All local variables must be declared at the **start of a block**, before any executable statements.  
```c
void f(void) {
    int i;
    i = 10;
    int j; // ❌ Error in C89
    j = 20;
}
```

- **C99 and C++:** Variables can be declared **anywhere within a block**, prior to their first use.  

---

## 🧠 Important Notes
- Local variables **cannot retain values between function calls**. Each call creates new instances.  
- To retain values across calls, use the `static` modifier.  
- Declaring variables close to where they are used improves readability and reduces unintended side effects.  
- The keyword `auto` can declare local variables, but since all non-global variables are `auto` by default, it is rarely used.  

---

## 📊 Example: Reinitialization of local variables
```c
#include <stdio.h>

void f(void);

int main(void) {
    int i;
    for(i = 0; i < 10; i++) f();
    return 0;
}

void f(void) {
    int j = 10;
    printf("%d ", j);
    j++; // has no lasting effect
}
```

**Output:**
```
10 10 10 10 10 10 10 10 10 10
```

Each time `f()` is called, `j` is reinitialized to 10, demonstrating that local variables do not persist between calls.
