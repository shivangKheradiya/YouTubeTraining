# 📍 Local Variables

## Overview
**Local variables** are variables declared inside a function or code block. They are sometimes referred to as *automatic variables*, but the term *local variable* is more commonly used.  

Local variables are accessible **only within the block** in which they are declared. A block of code begins with an opening curly brace `{` and ends with a closing curly brace `}`.

---

## 🔑 Key Characteristics
- **Scope:** Limited to the block in which they are declared.  
- **Lifetime:** Created upon entry into the block and destroyed upon exit.  
- **Independence:** Variables with the same name in different blocks are distinct and unrelated.  
- **Storage:** By default, local variables are stored on the **stack**.  
- **Initialization:** They can be initialized when declared, and the value is reset each time the block is entered.

## 🧠 Important Notes
- Local variables **cannot retain values between function calls**. Each call creates new instances.  
- To retain values across calls, use the `static` modifier.  
- Declaring variables close to where they are used improves readability and reduces unintended side effects.  
- The keyword `auto` can declare local variables, but since all non-global variables are `auto` by default, it is rarely used.
