# ➕ The Comma Operator

## Overview
The **comma operator (`,`)** in C allows multiple expressions to be evaluated in sequence within a single statement. It is particularly useful when you want to perform several operations but only return the value of the last expression.  

---

## 🛠️ General Behavior
- The **left-hand expression** is evaluated, but its result is discarded (treated as `void`).  
- The **right-hand expression** is evaluated, and its result becomes the value of the entire comma-separated expression.  

---

## ✔️ Example
```c
x = (y = 3, y + 1);
```
- First, `y` is assigned the value `3`.  
- Then, `x` is assigned the value `y + 1`, which is `4`.  

⚠️ Parentheses are required because the comma operator has **lower precedence** than the assignment operator.  

---

## 📌 Key Notes
- The comma operator creates a **sequence of operations**.  
- When used on the right side of an assignment, the **last expression** determines the assigned value.  
- Conceptually, it works like the English phrase: *“do this, and this, and this.”*  

---

## 📝 Example in Practice
```c
int a, b, c;
a = (b = 2, c = b + 5);  
// b = 2, then c = 7, finally a = 7
```
