# 🛡️ The `const` Qualifier

## Overview
The **`const` qualifier** in C is used to declare variables whose values cannot be modified by the program. This ensures data integrity and allows the compiler to optimize memory usage, often placing such variables in **read-only memory (ROM)**.  

Although `const` variables cannot be changed by the program, they can be initialized with a value at declaration and used freely in expressions.

---

## 📝 Declaration Example
```c
const int a = 10;
```
- Declares an integer `a` with an initial value of 10.  
- The program cannot modify `a` after initialization.  
- `a` can still be used in expressions, calculations, or passed to functions.  

---

## 📌 Using `const` with Function Parameters
The `const` qualifier is especially useful when passing pointers to functions. It prevents the function from modifying the object being pointed to.

## 📚 Standard Library Usage
Many standard library functions use `const` in their parameter declarations to guarantee that arguments are not modified.  

Example:
```c
size_t strlen(const char *str);
```
- `strlen()` calculates the length of a string.  
- Declaring `str` as `const` ensures the function does not alter the string.  

---

## ⚖️ Key Notes
- `const` variables can be initialized explicitly or set by hardware-dependent means.  
- Declaring a variable as `const` proves that any changes to it must come from **external events** (e.g., hardware devices).  
- Using `const` improves program safety, readability, and reliability.
