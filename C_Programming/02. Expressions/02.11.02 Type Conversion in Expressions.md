# 🔄 Type Conversion in Expressions

## Overview
When constants and variables of **different types** are mixed in an expression, C automatically converts them to a **common type**. This process is known as **type promotion**.  

Type conversion ensures that operations are performed consistently, but it can also lead to **loss of precision or truncation** if not carefully managed.

---

## 🛠️ Type Promotion Rules
1. **Integral Promotion**  
   - All `char` and `short int` values are automatically promoted to `int`.  
   - In **C99**, integer promotion may also result in conversion to `unsigned int`.  

2. **Conversion Algorithm**  
   After integral promotion, operands are converted step by step according to the following hierarchy:  

   - If one operand is `long double` → the other is converted to `long double`.  
   - Else if one operand is `double` → the other is converted to `double`.  
   - Else if one operand is `float` → the other is converted to `float`.  
   - Else if one operand is `unsigned long` → the other is converted to `unsigned long`.  
   - Else if one operand is `long` → the other is converted to `long`.  
   - Else if one operand is `unsigned int` → the other is converted to `unsigned int`.  

   **Special Case:**  
   - If one operand is `long` and the other is `unsigned int`, and the `unsigned int` value cannot be represented by a `long`, both operands are converted to `unsigned long`.  

---

## 📌 Key Notes
- After conversion, **each pair of operands is of the same type**, and the result of the operation matches that type.  
- Type conversion is automatic, but programmers should be aware of possible **precision loss** when mixing types.  
- Floating-point conversions (`float → double → long double`) increase range but **do not add precision**.  

---

## ✔️ Example
```c
char ch;
int i;
float f;
double d;

double result = (ch / i) + (f * d);
```

- `ch` is promoted to `int`.  
- `ch / i` produces an `int`, which is then converted to `double` because of multiplication with `d`.  
- `f + i` produces a `float` because `f` is a float.  
- The final result is `double`.
