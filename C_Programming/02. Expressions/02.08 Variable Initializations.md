# 📝 Variable Initializations

## Overview
In C, variables can be assigned an initial value at the time of declaration. This process is called **initialization**. It ensures that a variable starts with a known value rather than containing unpredictable data.  

---

## 🛠️ General Form
The syntax for initializing a variable is:

```c
type variable_name = constant;
```

---

## ✔️ Examples
```c
char ch = 'a';          // character initialized to 'a'
int first = 0;          // integer initialized to 0
double balance = 123.23; // double initialized to 123.23
```

---

## ⚖️ Initialization Rules
- **Global variables** → Initialized **once at program startup**.  
- **Static local variables** → Also initialized **once at program startup**.  
- **Local variables (non-static)** → Initialized **each time the block is entered**.  
- **Uninitialized local variables** → Contain **unknown (garbage) values** until explicitly assigned.  
- **Uninitialized global and static local variables** → Automatically set to **zero** by the compiler.  

---

## 📌 Key Notes
- Initializing variables prevents undefined behavior caused by using uninitialized values.  
- Global and static variables are predictable (default to zero if not explicitly initialized).  
- Local variables must be carefully initialized to avoid errors, since they start with garbage values.
