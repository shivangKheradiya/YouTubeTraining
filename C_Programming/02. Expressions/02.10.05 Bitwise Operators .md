# 🧮 Bitwise Operators

## Overview
C supports a **full set of bitwise operators**, designed to manipulate individual bits within integral data types such as `char` and `int`. Since C was intended to replace assembly language for many programming tasks, bitwise operations provide direct control over hardware-level data.  

Bitwise operations are commonly used in **device drivers**, **embedded systems**, **cryptography**, and **low-level data processing**.

---

## 🛠️ Bitwise Operators

| Operator | Action                          |
|----------|---------------------------------|
| `&`      | Bitwise AND                     |
| `|`      | Bitwise OR                      |
| `^`      | Bitwise Exclusive OR (XOR)      |
| `~`      | One’s complement (bitwise NOT)  |
| `>>`     | Shift right                     |
| `<<`     | Shift left                      |

⚠️ Bitwise operators cannot be applied to floating-point types (`float`, `double`, `long double`) or complex types.

---

## 📊 XOR Truth Table

| p | q | `p ^ q` |
|---|---|----------|
| 0 | 0 |    0     |
| 1 | 0 |    1     |
| 1 | 1 |    0     |
| 0 | 1 |    1     |

- Result is **true (1)** only if exactly one operand is true.

## ✔️ Examples

### Bitwise AND (Clearing Bits)
```c
char get_char_from_modem(void) {
    char ch;
    ch = read_modem();   // get a character from modem port
    return (ch & 127);   // clear the parity bit (8th bit)
}
```
- `ch & 127` resets the high-order parity bit to `0`.  

---

### Bitwise OR (Setting Bits)
```c
int result = 128 | 3;  // sets high-order bit
```

---

### Bitwise XOR (Toggling Bits)
```c
int result = 127 ^ 120;  // compares bits, sets differing ones to 1
```

---

### Bit Shifts
Shift operators move bits left or right:  
- **Left shift (`<<`)** → multiplies by 2.  
- **Right shift (`>>`)** → divides by 2.  

```c
#include <stdio.h>
int main(void) {
    unsigned int i = 1;
    int j;

    // Left shifts
    for (j = 0; j < 4; j++) {
        i = i << 1; // multiply by 2
        printf("Left shift %d: %d\n", j, i);
    }

    // Right shifts
    for (j = 0; j < 4; j++) {
        i = i >> 1; // divide by 2
        printf("Right shift %d: %d\n", j, i);
    }
    return 0;
}
```

---

### One’s Complement (Bitwise NOT)
Flips all bits in the operand:  
```c
char encode(char ch) {
    return (~ch);  // complement each bit
}
```
- Applying `~` twice restores the original value.  
- Often used in simple cipher routines.  

---

## 📌 Key Notes
- Bitwise operators apply only to **integral types** (`char`, `int`, etc.).  
- Unlike logical operators, bitwise operations may produce values beyond `0` or `1`.  
- Shifts are **not rotations**—bits shifted off one end are lost.  
- Useful for **masking bits**, **multiplying/dividing by powers of two**, and **encoding/decoding data**.
