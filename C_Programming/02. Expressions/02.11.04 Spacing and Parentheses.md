# 📐 Spacing and Parentheses

## Overview
Readable code is maintainable code. In C, you can use **tabs, spaces, and parentheses** to make expressions clearer without affecting their execution. Proper formatting helps both you and others understand the intended order of evaluation.  

---

## 🛠️ Spacing
- Adding spaces around operators improves readability.  
- Example:  
  ```c
  x=10/y~(127/x);       // less readable
  x = 10 / y ~(127/x);  // more readable
  ```
- Both expressions are **functionally identical**, but the second is easier to interpret.  

---

## 🛠️ Parentheses
- Parentheses can be used to **clarify the order of evaluation**.  
- Redundant parentheses do not cause errors or slow down execution.  
- Example:  
  ```c
  x = y/3 - 34*temp + 127;          // harder to parse quickly
  x = (y / 3) - (34 * temp) + 127;  // clearer and more structured
  ```

---

## 📌 Key Notes
- Use spacing and parentheses to **improve readability**, not just correctness.  
- Parentheses make complex expressions easier to understand at a glance.  
- Clear formatting reduces the chance of logical errors and helps with debugging.  

---

## 🎯 Learning Goals
By the end of this section, you will:
- Recognize the importance of spacing in expressions.  
- Use parentheses to explicitly define evaluation order.  
- Write expressions that are both correct and easy to read.
