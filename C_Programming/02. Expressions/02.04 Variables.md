# 📦 Variables

## Overview
A **variable** in C is a named location in memory used to store a value that can be modified during program execution. Variables are fundamental to programming, allowing data to be stored, manipulated, and reused.  

All variables must be **declared before use**, ensuring the compiler knows their type and memory requirements.

---

## 📝 General Form of Declaration
The syntax for declaring variables is:

```
type variable_list;
```

- **type** → A valid data type (e.g., `int`, `char`, `double`) plus any modifiers (`signed`, `unsigned`, `short`, `long`).  
- **variable_list** → One or more identifier names, separated by commas.  

---

## ✔️ Examples of Declarations
```c
int i, j, l;              // Declares three integers without value assignment(initialization)
int x = 0, y = i = 0;     // Declares three integers with value assignment(initialization)
short int si;             // Declares a short integer (uninitialized)
unsigned int ui;          // Declares an unsigned integer (uninitialized)
double balance, profit, loss; // Declares three double-precision floating-point variables (uninitialized)
```

---

## ⚖️ Important Notes
- The **name of a variable** is independent of its type. For example, naming a variable `count` does not imply it must be an integer—it depends entirely on its declared type.  
- Declaring multiple variables of the same type in a single statement is common practice.  
- Modifiers (`signed`, `unsigned`, `short`, `long`) allow fine-tuning of variable storage and range.
