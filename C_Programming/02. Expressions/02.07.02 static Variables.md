# 🗂️ `static` Variables

## Overview
The **`static` specifier** in C creates variables that persist for the lifetime of the program but are restricted in visibility depending on where they are declared. Unlike global variables, `static` variables are not accessible outside their function or file, yet they retain their values between function calls.  

This makes `static` variables especially useful for building **generalized functions** and **libraries** that need to preserve state without exposing internal details.

---

## 🔑 Two Uses of `static`

### 1. Static Local Variables
- Declared inside a function or block.  
- Retain their value between function calls.  
- Remain **local in scope**—only accessible within the block they are declared in.  

**Example: Number Series Generator**
```c
int series(void) {
    static int series_num;
    series_num = series_num + 23;
    return series_num;
}
```
- `series_num` persists across calls to `series()`.  
- Each call generates a new number based on the previous one.  
- Unlike normal local variables, `series_num` is not destroyed when the function exits.  

**Initialization Example**
```c
int series(void) {
    static int series_num = 100; // initialized once at program start
    series_num = series_num + 23;
    return series_num;
}
```
- Initialization occurs only once, at program startup.  
- The series begins at 123 and continues from there.  

---

### 2. Static Global Variables
- Declared outside of functions but marked with `static`.  
- Have **internal linkage**: visible only within the file they are declared in.  
- Prevent unwanted side effects by hiding global variables from other files.  

**Example: File-Scoped Series Generator**
```c
/* This must all be in one file */
static int series_num;

void series_start(int seed);
int series(void);

int series(void) {
    series_num = series_num + 23;
    return series_num;
}

/* initialize series_num */
void series_start(int seed) {
    series_num = seed;
}
```
- `series_num` is global within the file but hidden from other files.  
- Functions `series()` and `series_start()` can use it safely without exposing it to the rest of the program.  

---

## ⚖️ Key Notes
- **Local static variables** → Known only to their block, retain values between calls.  
- **Global static variables** → Known only to their file, hidden from other files.  
- Static variables are initialized **once** at program startup, not each time the block is entered.  
- Using `static` helps prevent **side effects** and improves modularity in large programs.  

---

## 📌 Advantages
- Preserve state without relying on global variables.  
- Hide implementation details from other parts of the program.  
- Reduce risk of accidental modification in multi-file projects.  
- Improve maintainability in large, complex codebases.
