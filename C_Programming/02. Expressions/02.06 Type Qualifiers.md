# 🛡️ Type Qualifiers

## Overview
In C, **type qualifiers** provide additional control over how variables may be accessed or modified. They refine the behavior of basic data types by imposing restrictions or special conditions.  

Type qualifiers must always **precede the type names** they qualify.

---

## 📌 Type Qualifiers in C

### C89 Qualifiers
- **`const`**  
  - Declares a variable whose value cannot be modified after initialization.  
  - Ensures data integrity by preventing accidental changes.  
  - Example:  
    ```c
    const int maxUsers = 100; // value cannot be altered
    ```

- **`volatile`**  
  - Informs the compiler that a variable’s value may change unexpectedly (e.g., hardware registers, shared memory).  
  - Prevents the compiler from applying certain optimizations that assume the value is stable.  
  - Example:  
    ```c
    volatile int statusFlag; // may change outside program control
    ```

### C99 Addition
- **`restrict`** *(covered in Part Two)*  
  - Applies to pointers.  
  - Indicates that the pointer is the only reference to the object it points to, allowing more aggressive compiler optimizations.  

---

## ⚖️ Key Notes
- Type qualifiers **modify access rules**, not the underlying data type itself.  
- They are especially important in systems programming, embedded development, and performance-critical applications.  
- Misuse of qualifiers can lead to errors or undefined behavior, so they should be applied thoughtfully.
