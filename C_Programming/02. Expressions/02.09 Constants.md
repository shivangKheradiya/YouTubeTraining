# 🔒 Constants

## Overview
In C, **constants** (also called *literals*) are fixed values that cannot be altered by the program during execution. They can be of any basic data type, and the way they are represented depends on their type. Constants ensure stability and predictability in code by providing values that remain unchanged.

---

## 🛠️ Types of Constants

### 1. Character Constants
- Enclosed in **single quotes**.  
- Examples:  
  ```c
  'a'   // character constant
  '%'   // character constant
  ```
- **Multibyte characters**: consist of one or more bytes, e.g. `'xy'`.  
- **Wide characters**: usually 16 bits long, used for large character sets. Declared with `L` prefix.  
  ```c
  wchar_t wc;
  wc = L'A'; // wide-character constant
  ```
- Wide characters use the type `wchar_t` defined in `<stddef.h>`.

---

### 2. Integer Constants
- Whole numbers without fractional components.  
- Examples:  
  ```c
  10      // positive integer
  -100    // negative integer
  ```

---

### 3. Floating-Point Constants
- Require a decimal point or fractional component.  
- Examples:  
  ```c
  11.123       // floating-point constant
  4.34e-3      // scientific notation
  ```
- By default, floating-point constants are treated as **double**.

---

## ⚖️ Compiler Defaults
- The compiler fits numeric constants into the **smallest compatible type**.  
  - Example (assuming 16-bit integers):  
    - `10` → `int`  
    - `103000` → `long int`  
- The compiler does not cross type boundaries (e.g., `10` will not be treated as `char`).  
- Floating-point constants default to **double** unless specified otherwise.

---

## 📌 Type Suffixes
You can explicitly control the type of a constant using suffixes:

- **Floating-point constants**:  
  - `F` or `f` → `float`  
  - `L` or `l` → `long double`  

- **Integer constants**:  
  - `U` or `u` → `unsigned`  
  - `L` or `l` → `long`  
  - `LL` or `ll` → `long long` (C99 and later)

## ✔️ Examples

| Data Type       | Constant Examples                |
|-----------------|----------------------------------|
| `int`           | `1`, `123`, `21000`, `-234`      |
| `long int`      | `35000L`, `-34L`                 |
| `unsigned int`  | `10000U`, `987u`, `40000U`       |
| `float`         | `123.23F`, `4.34e-3f`            |
| `double`        | `123.23`, `1.0`, `-0.9876324`    |
| `long double`   | `1001.2L`                        |
| `long long int` | `123456789LL` (C99)              |
