# 📍 The `&` and `*` Pointer Operators

## Overview
Pointers are one of C’s most powerful features. A **pointer** is a variable that stores the memory address of another object. Pointers enable:  
- Fast referencing of array elements.  
- Functions to modify their calling parameters.  
- Implementation of dynamic data structures such as linked lists and binary trees.  

This section introduces the two fundamental operators used to manipulate pointers: **`&` (address-of)** and **`*` (dereference)**.

---

## 🛠️ The `&` Operator (Address-of)
- `&` is a **unary operator** that returns the memory address of its operand.  
- Example:  
  ```c
  m = &count;
  ```
  - `m` receives the memory address of `count`.  
  - If `count` is stored at memory location `2000` and has a value of `100`, then `m = 2000`.  
- Think of `&` as meaning **“the address of.”**

---

## 🛠️ The `*` Operator (Dereference)
- `*` is the complement of `&`.  
- It is a **unary operator** that returns the value stored at the memory address it points to.  
- Example:  
  ```c
  q = *m;
  ```
  - If `m` contains the address of `count` (2000), then `q` receives the value stored at that address (`100`).  
- Think of `*` as meaning **“at address.”**

---

## ⚖️ Important Notes
- The symbols `*` and `&` are overloaded in C:  
  - `*` is also the multiplication operator.  
  - `&` is also the bitwise AND operator.  
  - These uses are unrelated to pointer operations.  
- Both `&` and `*` have **high precedence**, equal to the unary minus operator.  

---

## 📌 Declaring Pointer Variables
To declare a pointer, place `*` before the variable name:  
```c
char *ch;   // ch is a pointer to a character
```
- `ch` is not a character itself, but a pointer to a character.  
- The type of data a pointer points to is called its **base type**.  
- The pointer variable holds the address of an object of that base type.  

You can mix pointer and non-pointer variables in the same declaration:  
```c
int x, *y, count;
```
- `x` and `count` are integers.  
- `y` is a pointer to an integer.  

---

## 📝 Example Program
```c
#include <stdio.h>
int main(void) {
    int target, source;
    int *m;

    source = 10;
    m = &source;     // m stores the address of source
    target = *m;     // target receives the value at that address (10)

    printf("%d", target);  // Output: 10
    return 0;
}
```
