# 🔙 Backslash Character Constants (Escape Sequences)

## Overview
In C, most character constants can be represented directly using **single quotes** (e.g., `'a'`, `'%'`). However, certain special characters—such as carriage return or tab—cannot be represented this way. To handle these, C provides **backslash character constants**, also known as **escape sequences**.  

Escape sequences allow programmers to insert special characters into strings and character constants in a portable, readable way, rather than relying on raw ASCII codes.

---

## 📝 Syntax
Escape sequences begin with a **backslash (`\`)** followed by a character or code that represents the special constant.  

Example:
```c
#include <stdio.h>

int main(void) {
    printf("\n\tThis is a test.");
    return 0;
}
```

**Output:**
```
    This is a test.
```
- `\n` → New line  
- `\t` → Horizontal tab  

---

## 📌 Common Escape Sequences

| Code   | Meaning                          |
|--------|----------------------------------|
| `\b`   | Backspace                        |
| `\f`   | Form feed                        |
| `\n`   | New line                         |
| `\r`   | Carriage return                  |
| `\t`   | Horizontal tab                   |
| `\"`   | Double quote                     |
| `\'`   | Single quote                     |
| `\\`   | Backslash                        |
| `\v`   | Vertical tab                     |
| `\a`   | Alert (bell)                     |
| `\?`   | Question mark                    |
| `\N`   | Octal constant (N = octal value) |
| `\xN`  | Hexadecimal constant (N = hex value) |

---

## ⚖️ Key Notes
- Escape sequences improve **portability** by avoiding direct use of ASCII codes.  
- They are widely used in **string formatting**, **console output**, and **file handling**.  
- Octal (`\N`) and hexadecimal (`\xN`) escapes allow representation of arbitrary characters by their numeric codes.
