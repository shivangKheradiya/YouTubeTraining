# 🔢 Hexadecimal and Octal Constants

## Overview
In addition to the familiar **decimal (base 10)** number system, C allows you to represent integer constants using **octal (base 8)** and **hexadecimal (base 16)** notation. These alternative number systems are widely used in programming, especially in low-level tasks such as bit manipulation, memory addressing, and hardware programming.

---

## 🛠️ Number Systems
- **Octal (Base 8)**  
  - Digits: `0–7`  
  - Example:  
    - Octal `10` = Decimal `8`  

- **Hexadecimal (Base 16)**  
  - Digits: `0–9` and letters `A–F` (representing values 10–15).  
  - Example:  
    - Hexadecimal `10` = Decimal `16`  

---

## 📝 Syntax in C
- **Octal constants** → Begin with `0`  
- **Hexadecimal constants** → Begin with `0x` or `0X`  

---

## ✔️ Examples
```c
int hex = 0x80;  // 128 in decimal
int oct = 012;   // 10 in decimal
```

- `0x80` → Hexadecimal constant equal to decimal `128`.  
- `012` → Octal constant equal to decimal `10`.  

---

## ⚖️ Key Notes
- These notations are especially useful when working with **binary data**, since octal and hexadecimal provide compact representations of binary values.  
- Hexadecimal is commonly used in **memory addresses**, **color codes**, and **bitwise operations**.  
- Octal is less common today but still appears in contexts like **file permissions** in Unix/Linux systems.
