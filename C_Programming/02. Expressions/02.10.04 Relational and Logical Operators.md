# 🔗 Relational and Logical Operators

## Overview
C provides two important categories of operators that often work together:  

- **Relational operators** → Define relationships between values (e.g., greater than, equal to).  
- **Logical operators** → Connect or invert those relationships to form complex conditions.  

These operators are fundamental in decision-making and control flow, forming the basis of `if`, `while`, and other conditional statements.

---

## 🛠️ True and False in C
- **True** → Any nonzero value.  
- **False** → Zero (`0`).  
- Expressions using relational or logical operators return `1` for true and `0` for false.  

📌 Note:  
- Like **C89**, **C99** defines true as nonzero and false as zero.  
- C99 also introduces the **`_Bool` data type**, which can explicitly hold `1` (true) or `0` (false).

## ✔️ Relational Operators

| Operator | Action                        |
|----------|-------------------------------|
| `>`      | Greater than                  |
| `>=`     | Greater than or equal to      |
| `<`      | Less than                     |
| `<=`     | Less than or equal to         |
| `==`     | Equal to                      |
| `!=`     | Not equal to                  |

## ✔️ Logical Operators

| Operator | Action        |
|----------|---------------|
| `&&`     | Logical AND   |
| `||`     | Logical OR    |
| `!`      | Logical NOT   |

## 📊 Truth Table (Logical Operators)

| p | q | `p && q` | `p || q` | `!p` |
|---|---|----------|----------|------|
| 0 | 0 |    0     |    0     |  1   |
| 0 | 1 |    0     |    1     |  1   |
| 1 | 1 |    1     |    1     |  0   |
| 1 | 0 |    0     |    1     |  0   |

## 📝 Examples

### Combining Operators
```c
if (10 > 5 && !(10 < 9) || 3 <= 4) {
    printf("True\n");
}
```
- Result: **True**  
- Demonstrates combining relational and logical operators in one expression.  

### XOR Implementation
C does not have a built-in **exclusive OR (XOR)** operator, but it can be implemented using logical operators:  

```c
#include <stdio.h>

int xor(int a, int b);

int main(void) {
    printf("%d\n", xor(1, 0)); // 1
    printf("%d\n", xor(1, 1)); // 0
    printf("%d\n", xor(0, 1)); // 1
    printf("%d\n", xor(0, 0)); // 0
    return 0;
}

/* Perform a logical XOR operation */
int xor(int a, int b) {
    return (a || b) && !(a && b);
}
```

---

## ⚖️ Precedence
- Relational and logical operators have **lower precedence** than arithmetic operators.  
- Example:  
  ```c
  10 > 1 + 12   // evaluated as 10 > (1 + 12) → false
  ```
- Parentheses `()` can be used to override precedence and control evaluation order.  

---

## 📌 Key Notes
- Relational and logical expressions always evaluate to `1` (true) or `0` (false).  
- Parentheses improve readability and ensure correct evaluation order.  
- Logical operators are essential for building complex conditions in control structures.
