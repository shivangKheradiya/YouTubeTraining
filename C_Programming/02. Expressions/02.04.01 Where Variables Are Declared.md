# 📍 Where Variables Are Declared

## Overview
In C, the **location of a variable declaration** determines its scope, lifetime, and accessibility. Variables can be declared in three distinct places, each serving a different purpose in program design.

---

## 🛠️ Declaration Locations
Variables may be declared in the following contexts:

1. **Inside Functions** → *Local Variables*  
   - Declared within a function body.  
   - Exist only while the function is executing.  
   - Accessible only inside that function.  
   - Memory is typically allocated on the stack.  

2. **Function Parameters** → *Formal Parameters*  
   - Declared in the function definition’s parameter list.  
   - Act as local variables initialized with values passed during function calls.  
   - Provide a way to pass data into functions.  

3. **Outside All Functions** → *Global Variables*  
   - Declared outside of any function.  
   - Accessible by all functions within the same source file (and across files if declared with `extern`).  
   - Exist for the entire duration of program execution.  
   - Memory is typically allocated in the data segment(static storage).

---

## 📊 Comparison of Variable Types

| Location of Declaration | Variable Type     | Scope                  | Lifetime              | Example |
|--------------------------|------------------|------------------------|-----------------------|---------|
| Inside a function        | Local Variable   | Function-only          | Until function ends   | `int count;` |
| Function parameter list  | Formal Parameter | Function-only          | Until function ends   | `void add(int x, int y)` |
| Outside all functions    | Global Variable  | Entire program/file    | Entire program run    | `int total;` |

---

## ⚖️ Key Notes
- **Local variables** are preferred for modularity and avoiding unintended side effects.  
- **Global variables** should be used sparingly, as they can make debugging and maintenance more difficult.  
- **Formal parameters** provide a clean way to pass values into functions without relying on global state.  

---

## 🎯 Learning Goals
By the end of this section, you would:
- Understand the three possible locations for variable declarations.  
- Recognize the differences in scope and lifetime between local, global, and formal parameters.  
- Apply best practices when deciding where to declare variables in your programs.
