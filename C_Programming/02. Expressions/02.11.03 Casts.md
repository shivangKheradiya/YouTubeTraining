# 🎭 Casts

## Overview
In C, a **cast** allows you to explicitly convert an expression to a specific type. This is useful when you need precise control over how operations are performed, especially when mixing different data types.  

---

## 🛠️ General Form
```c
(type) expression
```

- **type** → Any valid C data type (e.g., `int`, `float`, `double`, `char`).  
- **expression** → The value or operation to be converted.  

---

## ✔️ Example
```c
(float) x / 2
```
- Forces the division to be performed as a `float` operation.  
- Without the cast, if `x` is an integer, the division would be integer division (truncating the fractional part).  

---

## 📌 Key Notes
- Casts are **operators** in C.  
- They are **unary operators**, meaning they apply to a single operand.  
- Casts have the **same precedence** as other unary operators (like `++`, `--`, `sizeof`).  
- Casting does not change the original variable’s type—it only affects the evaluation of the expression.  

---

## 📝 Example Program
```c
#include <stdio.h>

int main(void) {   /* print i and i/2 with fractions */
    int i;
    for (i = 1; i <= 100; ++i)
        printf("%d / 2 is: %f\n", i, (float) i / 2);
    return 0;
}
```

### Output (sample):
```
1 / 2 is: 0.500000
2 / 2 is: 1.000000
3 / 2 is: 1.500000
...
```

- Without `(float)`, the division would be integer division, producing only whole numbers.  
- The cast ensures the fractional part is preserved.
