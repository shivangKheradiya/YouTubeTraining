# ➗ Arithmetic Operators

## Overview
C provides a rich set of **arithmetic operators** that allow mathematical manipulation of data. These operators work similarly to those in most other programming languages and can be applied to nearly all built-in data types.  

Arithmetic operators are fundamental for calculations, loops, and data processing in C.

---

## 🛠️ Arithmetic Operators

| Operator | Action                                   |
|----------|------------------------------------------|
| `+`      | Addition                                 |
| `-`      | Subtraction (also unary minus)           |
| `*`      | Multiplication                           |
| `/`      | Division (integer division truncates remainder) |
| `%`      | Modulus (remainder of integer division)  |
| `++`     | Increment (adds 1 to operand)            |
| `--`     | Decrement (subtracts 1 from operand)     |

---

## ✔️ Examples

### Division and Modulus
```c
int x, y;
x = 5;
y = 2;

printf("%d ", x / y); // displays 2
printf("%d ", x % y); // displays 1 (remainder)
```

- `5 / 2` → `2` (integer division truncates remainder).  
- `5 % 2` → `1` (remainder of division).  

```c
x = 1;
y = 2;
printf("%d %d", x / y, x % y); // displays 0 1
```
- `1 / 2` → `0` (integer division).  
- `1 % 2` → `1` (remainder).  

⚠️ Note: The modulus operator `%` cannot be applied to floating-point types.

---

### Unary Minus
```c
int a = 10;
int b = -a; // unary minus changes sign
```
- The unary minus multiplies its operand by `-1`.  
- Any number preceded by `-` switches its sign.  

---

### Increment and Decrement
```c
int i = 5;
i++;   // i becomes 6
i--;   // i becomes 5 again
```
- `++` increases a variable by 1.  
- `--` decreases a variable by 1.  
- Commonly used in loops and counters.  

---

## 📌 Key Notes
- Integer division **truncates** results (no rounding).  
- `%` is only valid for integer types.  
- Arithmetic operators can be combined in complex expressions.  
- Operator precedence determines evaluation order (covered later).
