# 📘 Data Types

## Overview
This tutorial introduces the **fundamental data types in C**, as defined by the ANSI C89 standard and extended in C99. They tell the **compiler** what type of data a variable can store and how much memory it occupies. Mastering these types is essential for writing portable, efficient, and reliable C programs. 

We begin with the five foundational types and gradually expand into the newer additions introduced in later standards.

---

# 🔍 **Binary Storage of Data Types (Bits & Bytes)**

This guide shows how common data types in C are stored in computer memory — in both **bits** and **bytes**.

---

## 📌 **1️⃣ Integer (`int`) — 32-bit storage**

Most systems store `int` using **4 bytes = 32 bits** (two’s complement format).

| Decimal Value | 32-bit Binary Representation          | Bytes Used |
| ------------- | ------------------------------------- | ---------- |
| `1`           | `00000000 00000000 00000000 00000001` | 4 bytes    |
| `25`          | `00000000 00000000 00000000 00011001` | 4 bytes    |
| `30`          | `00000000 00000000 00000000 00011110` | 4 bytes    |

➡ Integers always occupy **4 bytes**, regardless of value.

---

## 📌 **2️⃣ Boolean (`bool`) — 1 byte storage**

Even though a bool is true/false, it still occupies **1 full byte = 8 bits**.

| Boolean Value | Stored Decimal | 8-bit Binary | Bytes Used |
| ------------- | -------------- | ------------ | ---------- |
| `true`        | `1`            | `00000001`   | 1 byte     |
| `false`       | `0`            | `00000000`   | 1 byte     |

➡ Only the **least-significant bit** represents the value; remaining bits stay `0`.

---

## 📌 **3️⃣ Double (`double`) — 64-bit IEEE 754 storage**

A `double` always uses **8 bytes = 64 bits**.

### Example: `25.4`

IEEE-754 64-bit binary representation:

```
0100000000111001011001100110011001100110011001100110011001100110
```

Formatted in bytes (groups of 8 bits):

| Byte | Bits       |
| ---- | ---------- |
| 1    | `01000000` |
| 2    | `00111001` |
| 3    | `01100110` |
| 4    | `01100110` |
| 5    | `01100110` |
| 6    | `01100110` |
| 7    | `01100110` |
| 8    | `01100110` |

| Value  | Bits    | Bytes   |
| ------ | ------- | ------- |
| `25.4` | 64 bits | 8 bytes |

## 🔑 Core Data Types (C89)
C89 defines five basic data types, which serve as the building blocks for all other types:

| Data Type | Keyword | Description |
|-----------|----------|-------------|
| Character | `char`   | Represents single-byte characters, typically ASCII. Always 1 byte. |
| Integer   | `int`    | Whole numbers. Size depends on the system architecture (16-bit or 32-bit). |
| Floating-Point | `float` | Single-precision decimal numbers. |
| Double Floating-Point | `double` | Double-precision decimal numbers with greater range and accuracy. |
| Valueless | `void`   | Indicates no value returned (e.g., functions) or used for generic pointers. |

---

## ⚙️ System Variations
- The **size and range** of these data types vary across processors and compilers.  
- Example:  
  - On **16-bit systems** (DOS, Windows 3.1), `int` is 16 bits.  
  - On **32-bit systems** (Windows 95/98/NT/2000), `int` is 32 bits.  
- **Portability Tip:** Never assume fixed sizes; rely on C’s minimal range guarantees.

---

## 📈 Floating-Point Precision
- The exact representation of floating-point values depends on the implementation.  
- **Standard C minimum range:** `1E–37` to `1E+37`.  
- Precision varies between `float` and `double`.  

---

## 🆕 Additions in C99
C99 expands the set of basic data types with three new entries:

| Data Type | Keyword | Description |
|-----------|----------|-------------|
| Boolean   | `_Bool`      | Represents truth values (`true`/`false`). |
| Complex   | `_Complex`   | Supports complex numbers. |
| Imaginary | `_Imaginary` | Represents purely imaginary numbers. |

These will be covered in **Part Two** of the series.

---

## 📌 Notes
- `char` variables are generally used for ASCII characters, but behavior may differ for values outside the ASCII range depending on the compiler.  
- `void` is versatile:  
  - Declares functions that return no value.  
  - Creates generic pointers for flexible programming.
