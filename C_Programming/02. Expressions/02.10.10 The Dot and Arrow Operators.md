# 🎯 The Dot (`.`) and Arrow (`->`) Operators

## Overview
C provides two special operators—**dot (`.`)** and **arrow (`->`)**—to access individual members of **structures** and **unions**. These compound data types group related variables under a single name, and the dot/arrow operators allow direct access to their elements.  

---

## 🛠️ The Dot (`.`) Operator
- Used when working with a **structure or union variable directly**.  
- Syntax:  
  ```c
  structure_variable.member
  ```
- Example:  
  ```c
  emp.wage = 123.23;
  ```
  - Assigns `123.23` to the `wage` member of the structure variable `emp`.  

---

## 🛠️ The Arrow (`->`) Operator
- Used when working with a **pointer to a structure or union**.  
- Syntax:  
  ```c
  pointer_to_structure->member
  ```
- Example:  
  ```c
  struct employee *p = &emp;  // p points to emp
  p->wage = 123.23;
  ```
  - Assigns `123.23` to the `wage` member of the structure pointed to by `p`.  

---

## 📌 Key Notes
- Both operators provide access to structure/union members, but the choice depends on whether you are working with a **direct variable (`.`)** or a **pointer (`->`)**.  
- The arrow operator is essentially shorthand for dereferencing a pointer and then using the dot operator:  
  ```c
  (*p).wage = 123.23;  // equivalent to p->wage
  ```  
- Using `->` improves readability and is the standard practice when dealing with pointers to structures.  

---

## 📝 Example Program
```c
#include <stdio.h>

struct employee {
    char name[80];
    int age;
    float wage;
};

int main(void) {
    struct employee emp;
    struct employee *p = &emp;

    emp.wage = 123.23;   // using dot operator
    p->wage = 123.23;    // using arrow operator

    printf("Wage: %.2f\n", emp.wage);
    return 0;
}
```
