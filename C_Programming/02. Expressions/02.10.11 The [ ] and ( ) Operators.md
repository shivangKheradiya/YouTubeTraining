# 🔢 The `[ ]` and `( )` Operators

## Overview
C provides two important operators that are widely used in programming:  

- **Parentheses `( )`** → Control **precedence** of operations in expressions.  
- **Square brackets `[ ]`** → Perform **array indexing**, allowing direct access to elements of an array.  

---

## 🛠️ Parentheses `( )`
- Parentheses are used to **increase precedence** and ensure certain operations are performed first.  
- Example:  
  ```c
  int result = (5 + 3) * 2;  // evaluates 5+3 first, then multiplies by 2
  ```

---

## 🛠️ Square Brackets `[ ]`
- Square brackets are used for **array indexing**.  
- Arrays in C are **zero-based**, meaning the first element is at index `0`.  
- Syntax:  
  ```c
  array[index]
  ```

---

## ✔️ Example Program
```c
#include <stdio.h>

char s[80];   // declare an array of 80 characters

int main(void) {
    s[3] = 'X';              // assign 'X' to the 4th element (index 3)
    printf("%c", s[3]);      // print the element at index 3
    return 0;
}
```

- `s[3] = 'X';` → assigns `'X'` to the fourth element of the array `s`.  
- `printf("%c", s[3]);` → prints the character stored at index `3`.  

---

## 📌 Key Notes
- Parentheses `( )` are essential for controlling **order of evaluation** in complex expressions.  
- Square brackets `[ ]` provide **direct access** to array elements.  
- Always remember: **arrays start at index 0**.
