# 🧩 Expressions

## Overview
In C, an **expression** is any valid combination of:  
- **Operators**  
- **Constants**  
- **Functions**  
- **Variables**  

Expressions are the building blocks of C programs, forming the logic that drives computation and decision-making.  

---

## 🛠️ General Behavior
- Most expressions follow the familiar **rules of algebra**, making them intuitive to write and understand.  
- The result of an expression is a **value**, which can be assigned to a variable, used in a condition, or passed to a function.  
- Expressions can range from **simple** (e.g., `x + 1`) to **complex** (e.g., `(a * b) + func(c, d)`).  

---

## 📌 Key Notes
- While algebraic rules apply, C introduces **specific aspects** of expressions that programmers must understand, such as:  
  - **Operator precedence and associativity** (which determine evaluation order).  
  - **Type conversions** (automatic promotion or casting of values).  
  - **Side effects** (e.g., increment `++` or function calls that modify state).  
- Expressions are not limited to arithmetic—they also include **logical**, **relational**, **bitwise**, and **pointer-based** operations.  

---

## ✔️ Example
```c
int x = 5, y = 10;
int z = (x + y) * 2;   // z = 30
```
- Combines variables, operators, and constants into a single expression.  
- Parentheses ensure correct evaluation order.
