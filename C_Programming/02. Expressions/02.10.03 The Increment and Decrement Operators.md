# 🔼🔽 Increment and Decrement Operators

## Overview
C provides two special operators that simplify common operations:  
- **Increment (`++`)** → Adds 1 to its operand.  
- **Decrement (`--`)** → Subtracts 1 from its operand.  

These operators are shorthand for frequently used assignment statements:  
```c
x = x + 1;   // same as ++x or x++
x = x - 1;   // same as --x or x--
```

They are widely used in loops, counters, and iterative calculations due to their efficiency and compact syntax.

---

## 🛠️ Prefix vs. Postfix Forms
Increment and decrement operators can be written in **two forms**:  

- **Prefix (`++x`, `--x`)** → Operation is performed *before* the value is used in the expression.  
- **Postfix (`x++`, `x--`)** → Operation is performed *after* the value is used in the expression.  

### Example:
```c
x = 10;
y = ++x;   // prefix: x becomes 11, y = 11

x = 10;
y = x++;   // postfix: y = 10, then x becomes 11
```

- Both forms eventually set `x` to 11.  
- The difference lies in **when** the increment or decrement occurs relative to the expression evaluation.  

---

## ⚡ Efficiency
Most C compilers generate **faster and more efficient object code** for increment and decrement operators compared to equivalent assignment statements. For this reason, they are preferred in professional C programs, especially in loops.  

Example:
```c
for (int i = 0; i < 10; i++) {
    printf("%d ", i);
}
```
Here, `i++` is more efficient than writing `i = i + 1`.

---

## 📊 Operator Precedence
Arithmetic operators in C follow a specific precedence order:  

| Precedence Level | Operators                |
|------------------|--------------------------|
| Highest          | `++`, `--`               |
|                  | Unary minus (`-`)        |
|                  | `*`, `/`, `%`            |
| Lowest           | `+`, `-`                 |

- Operators at the same precedence level are evaluated **left to right**.  
- Parentheses `()` can be used to override precedence and force specific evaluation order.
