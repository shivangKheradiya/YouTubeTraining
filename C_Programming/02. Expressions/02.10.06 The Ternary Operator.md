# ❓ The Ternary (`?`) Operator

## Overview
C provides a powerful and convenient operator called the **ternary operator (`? :`)**, which acts as a shorthand for certain `if-then-else` statements. It allows conditional logic to be expressed compactly within a single line of code.  

---

## 🛠️ General Form
```c
Exp1 ? Exp2 : Exp3;
```

- **Exp1** → The condition to evaluate.  
- **Exp2** → The value returned if `Exp1` is true.  
- **Exp3** → The value returned if `Exp1` is false.  

The colon (`:`) separates the two possible outcomes.

---

## ✔️ Example
```c
x = 10;
y = x > 9 ? 100 : 200;
```

- Since `x > 9` is true, `y` is assigned the value `100`.  
- If `x` had been less than 9, `y` would have received the value `200`.  

Equivalent `if-else` statement:
```c
x = 10;
if (x > 9) 
    y = 100;
else 
    y = 200;
```

---

## 📌 Key Notes
- The ternary operator is often used for **inline conditional assignments**.  
- It improves readability and reduces the need for verbose `if-else` blocks.  
- Best used for **simple conditions**; complex logic should remain in standard `if-else` statements for clarity.
