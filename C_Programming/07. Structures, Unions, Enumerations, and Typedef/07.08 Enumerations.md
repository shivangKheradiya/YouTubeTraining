# 📘 Enumerations (enum)

An **enumeration** in C is a user‑defined type that consists of a set of **named integer constants**. Enumerations appear everywhere in real life. For example, U.S. coins can be represented as:

```
penny, nickel, dime, quarter, half_dollar, dollar
```

In C, enumerations are defined using the keyword `enum`. The general form is:

```c
enum tag { enumeration_list } variable_list;
```

Both the **tag** and the **variable list** are optional, but at least one must be present.

---

## ✅ Defining an Enumeration

Example:

```c
enum coin { penny, nickel, dime, quarter,
            half_dollar, dollar };
```

This creates a new type named `coin`. You can now declare variables of this type:

```c
enum coin money;
```

---

## ✅ Using Enumeration Values

Once declared, enumeration constants behave like integers:

```c
money = dime;

if (money == quarter)
    printf("Money is a quarter.\n");
```

Each symbol in an enumeration corresponds to an integer value:

- The **first** symbol has value **0**
- Each subsequent symbol increases by **1**

So:

```c
printf("%d %d", penny, dime);
```

prints:

```
0 2
```

---

## ✅ Assigning Custom Values

You can assign specific integer values to enumeration symbols:

```c
enum coin { penny, nickel, dime, quarter = 100,
            half_dollar, dollar };
```

This produces:

| Symbol       | Value |
|--------------|--------|
| penny        | 0      |
| nickel       | 1      |
| dime         | 2      |
| quarter      | 100    |
| half_dollar  | 101    |
| dollar       | 102    |

Symbols after an initializer continue counting upward.

---

## ⚠️ Common Misunderstanding: Enum Symbols Are NOT Strings

Enumeration symbols are **not strings**. They are integer constants.

This will NOT work:

```c
money = dollar;
printf("%s", money);   /* ❌ invalid */
```

Nor will this:

```c
strcpy(money, "dime");  /* ❌ invalid */
```

A string containing the name of a symbol is not automatically converted to that symbol.

---

## ✅ Converting Enum Values to Strings

To print the name of an enumeration value, you must convert it manually.

### Option 1: Use a switch statement

```c
switch (money) {
    case penny:       printf("penny"); break;
    case nickel:      printf("nickel"); break;
    case dime:        printf("dime"); break;
    case quarter:     printf("quarter"); break;
    case half_dollar: printf("half_dollar"); break;
    case dollar:      printf("dollar"); break;
}
```

### Option 2: Use an array of strings

```c
char name[][12] = {
    "penny",
    "nickel",
    "dime",
    "quarter",
    "half_dollar",
    "dollar"
};

printf("%s", name[money]);
```

⚠️ This method only works if **no enumeration values are manually initialized**, because the array must be indexed from 0 upward without gaps.

---

## ✅ When Are Enumerations Useful?

Enumerations are ideal when:

- You want readable names instead of raw integers  
- You need a set of related constants  
- You are writing code that does not require converting enum values to strings frequently  

Common uses include:

- Compiler symbol tables  
- State machines  
- Menu options  
- Error codes  
- Token types in parsers
