# A Mailing List Example

This example demonstrates how structures and arrays of structures can be used together to build a simple mailing list program. Each entry in the list contains a name, street, city, state, and ZIP code. All entries are stored in an array of `addr` structures.

## Structure Definition

The program begins by defining a structure to hold one mailing list entry:

```c
struct addr {
    char name[30];
    char street[40];
    char city[20];
    char state[3];
    unsigned long int zip;
} addr_list[MAX];
```

Although ZIP codes are often stored as strings (to support formats used in other countries), this example uses an integer to illustrate numeric structure members.

---

# Program Overview

The program consists of several functions:

- `main()` — controls the menu loop  
- `init_list()` — initializes the structure array  
- `menu_select()` — displays the menu and reads the user’s choice  
- `enter()` — adds a new entry  
- `delete()` — removes an entry  
- `list()` — displays all entries  
- `find_free()` — locates the next unused structure slot  

---

# main()

The `main()` function initializes the list and then repeatedly processes menu selections:

```c
int main(void)
{
    char choice;
    init_list();  /* initialize the structure array */

    for(;;) {
        choice = menu_select();
        switch(choice) {
            case 1: enter();  break;
            case 2: delete(); break;
            case 3: list();   break;
            case 4: exit(0);
        }
    }
    return 0;
}
```

---

# Initializing the List

Each entry is considered unused if its `name` field begins with a null character. The initializer sets all entries to empty:

```c
void init_list(void)
{
    register int t;
    for(t = 0; t < MAX; ++t)
        addr_list[t].name[0] = '\0';
}
```

---

# Menu Selection

The menu is displayed, and the user’s choice is returned as an integer:

```c
int menu_select(void)
{
    char s[80];
    int c;

    printf("1. Enter a name\n");
    printf("2. Delete a name\n");
    printf("3. List the file\n");
    printf("4. Quit\n");

    do {
        printf("\nEnter your choice: ");
        gets(s);
        c = atoi(s);
    } while(c < 0 || c > 4);

    return c;
}
```

---

# Adding a New Entry

The `enter()` function finds the next available slot and fills it with user input:

```c
void enter(void)
{
    int slot;
    char s[80];

    slot = find_free();
    if(slot == -1) {
        printf("\nList Full");
        return;
    }

    printf("Enter name: ");
    gets(addr_list[slot].name);

    printf("Enter street: ");
    gets(addr_list[slot].street);

    printf("Enter city: ");
    gets(addr_list[slot].city);

    printf("Enter state: ");
    gets(addr_list[slot].state);

    printf("Enter zip: ");
    gets(s);
    addr_list[slot].zip = strtoul(s, '\0', 10);
}
```

---

# Finding a Free Slot

A free slot is one whose `name` field is empty:

```c
int find_free(void)
{
    register int t;

    for(t = 0; addr_list[t].name[0] && t < MAX; ++t)
        ;

    if(t == MAX)
        return -1;  /* no free slots */

    return t;
}
```

---

# Deleting an Entry

Deleting an entry simply clears the `name` field:

```c
void delete(void)
{
    register int slot;
    char s[80];

    printf("Enter record #: ");
    gets(s);
    slot = atoi(s);

    if(slot >= 0 && slot < MAX)
        addr_list[slot].name[0] = '\0';
}
```

---

# Listing All Entries

The `list()` function prints all non-empty entries:

```c
void list(void)
{
    register int t;

    for(t = 0; t < MAX; ++t) {
        if(addr_list[t].name[0]) {
            printf("%s\n", addr_list[t].name);
            printf("%s\n", addr_list[t].street);
            printf("%s\n", addr_list[t].city);
            printf("%s\n", addr_list[t].state);
            printf("%lu\n\n", addr_list[t].zip);
        }
    }
    printf("\n\n");
}
```

# Complete Program

Here is the full mailing list program, rewritten cleanly and consistently:

```c
/* A simple mailing list example using an array of structures. */

#include <stdio.h>
#include <stdlib.h>

#define MAX 100

struct addr {
    char name[30];
    char street[40];
    char city[20];
    char state[3];
    unsigned long int zip;
} addr_list[MAX];

void init_list(void), enter(void);
void delete(void), list(void);
int menu_select(void), find_free(void);

int main(void)
{
    char choice;
    init_list();

    for(;;) {
        choice = menu_select();
        switch(choice) {
            case 1: enter();  break;
            case 2: delete(); break;
            case 3: list();   break;
            case 4: exit(0);
        }
    }
    return 0;
}

void init_list(void)
{
    register int t;
    for(t = 0; t < MAX; ++t)
        addr_list[t].name[0] = '\0';
}

int menu_select(void)
{
    char s[80];
    int c;

    printf("1. Enter a name\n");
    printf("2. Delete a name\n");
    printf("3. List the file\n");
    printf("4. Quit\n");

    do {
        printf("\nEnter your choice: ");
        gets(s);
        c = atoi(s);
    } while(c < 0 || c > 4);

    return c;
}

void enter(void)
{
    int slot;
    char s[80];

    slot = find_free();
    if(slot == -1) {
        printf("\nList Full");
        return;
    }

    printf("Enter name: ");
    gets(addr_list[slot].name);

    printf("Enter street: ");
    gets(addr_list[slot].street);

    printf("Enter city: ");
    gets(addr_list[slot].city);

    printf("Enter state: ");
    gets(addr_list[slot].state);

    printf("Enter zip: ");
    gets(s);
    addr_list[slot].zip = strtoul(s, '\0', 10);
}

int find_free(void)
{
    register int t;

    for(t = 0; addr_list[t].name[0] && t < MAX; ++t)
        ;

    if(t == MAX)
        return -1;

    return t;
}

void delete(void)
{
    register int slot;
    char s[80];

    printf("Enter record #: ");
    gets(s);
    slot = atoi(s);

    if(slot >= 0 && slot < MAX)
        addr_list[slot].name[0] = '\0';
}

void list(void)
{
    register int t;

    for(t = 0; t < MAX; ++t) {
        if(addr_list[t].name[0]) {
            printf("%s\n", addr_list[t].name);
            printf("%s\n", addr_list[t].street);
            printf("%s\n", addr_list[t].city);
            printf("%s\n", addr_list[t].state);
            printf("%lu\n\n", addr_list[t].zip);
        }
    }
    printf("\n\n");
}
```
