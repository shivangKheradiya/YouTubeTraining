# 📘 Passing Entire Structures to Functions

In C, you can pass an entire structure to a function just as you would pass any other variable. When you do this, the structure is passed **by value**, meaning the function receives a **copy** of the structure. Any changes made inside the function do **not** affect the original structure in the caller.

---

## ✅ Passing a Structure by Value

When using a structure as a function parameter, the **type of the argument must match the type of the parameter exactly**.

Example:

```c
#include <stdio.h>

/* Define a structure type. */
struct struct_type {
    int a, b;
    char ch;
};

void f1(struct struct_type parm);

int main(void)
{
    struct struct_type arg;
    arg.a = 1000;

    f1(arg);   /* pass entire structure */
    return 0;
}

void f1(struct struct_type parm)
{
    printf("%d", parm.a);
}
```

### ✅ Key Point  
Because `parm` is a **copy** of `arg`, modifying `parm` inside `f1()` would not change `arg` in `main()`.

---

## ✅ Structure Type Must Be Global

If you plan to use a structure type in multiple functions, the structure definition must be placed **outside** of all functions (i.e., at global scope).  
If `struct_type` were declared inside `main()`, the function `f1()` would not be able to use it.

---

## ❌ Type Names Must Match Exactly

Two structures with identical members are **not** considered the same type unless they share the same type name. The following example is incorrect and will not compile:

```c
/* This program is incorrect and will not compile. */

#include <stdio.h>

/* First structure type */
struct struct_type {
    int a, b;
    char ch;
};

/* Second structure type with identical layout,
   but a different name */
struct struct_type2 {
    int a, b;
    char ch;
};

void f1(struct struct_type2 parm);

int main(void)
{
    struct struct_type arg;
    arg.a = 1000;

    f1(arg);   /* ❌ type mismatch */
    return 0;
}

void f1(struct struct_type2 parm)
{
    printf("%d", parm.a);
}
```

Even though both structures contain the same members, they are treated as **different types**, so passing one where the other is expected results in a compilation error.

---

## ✅ Summary for Students

- Passing a structure to a function passes a **copy**, not the original.  
- The structure type must be **visible** to any function that uses it.  
- The **type names must match exactly**—not just the member layout.  
- Passing entire structures is useful for clean, modular program design.
