# 📘 Arrays and Structures Within Structures

In C, a structure member can be either a **simple data type** (such as `int`, `float`, or `double`) or an **aggregate type**. Aggregate types include:

- Arrays  
- Other structures  

You have already seen aggregate members such as the character arrays used in earlier examples.

---

## ✅ Arrays as Structure Members

A structure can contain arrays just like any other variable. For example:

```c
struct x {
    int a[10][10];   /* 10 × 10 array of integers */
    float b;
} y;
```

To access the element at row 3, column 7 of the array `a` inside structure `y`, you write:

```c
y.a[3][7];
```

This works exactly like accessing a normal multidimensional array—only now it is stored inside a structure.

---

## ✅ Nested Structures

A structure can also contain another structure as one of its members. This is called a **nested structure**.

Example:

```c
struct emp {
    struct addr address;   /* nested structure */
    float wage;
} worker;
```

Here:

- `address` is a structure of type `addr`  
- `wage` is a floating‑point value  

To assign a value to the `zip` field inside the nested `address` structure, you write:

```c
worker.address.zip = 93456;
```

Members are always accessed **from outermost to innermost**, using the dot operator at each level.

---

## ✅ Nesting Depth in C

The C standards specify minimum nesting levels:

- **C89**: at least **15** levels of nested structures  
- **C99**: recommends at least **63** levels  

In practice, compilers often support even deeper nesting, but extremely deep nesting is rarely needed in real‑world programs.
