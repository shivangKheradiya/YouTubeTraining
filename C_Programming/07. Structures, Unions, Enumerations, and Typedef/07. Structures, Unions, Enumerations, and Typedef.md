# Custom Data Types

The C language provides **five mechanisms** for creating your own custom data types. These tools allow you to model complex information, improve code clarity, and build more expressive programs.

- **Structures** — Aggregate data types that group multiple variables under a single name. (They are also commonly referred to as *compound* or *conglomerate* types.)
- **Unions** — Allow a single block of memory to be interpreted as different data types at different times.
- **Bit‑fields** — Special structure or union members that give convenient access to individual bits.
- **Enumerations** — Lists of named integer constants that improve readability and maintainability.
- **`typedef`** — A keyword used to create a new name (alias) for an existing type.

Each of these features is explored in detail throughout this chapter.
