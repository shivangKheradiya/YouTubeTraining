# 📘 Passing Structures to Functions  
In C Programming Tutorials

Functions in C can receive not only basic data types like `int` or `char`, but also **entire structures** or **individual structure members**. This allows you to organize your program more cleanly and pass complex data between functions.

This section introduces the two main approaches:

---

## ✅ 1. Passing Individual Structure Members  
You can pass a single member of a structure just like any normal variable.  
For example:

```c
printf("%d", student.age);
```

Here, only the `age` member is passed to the function.

This method is simple and efficient when you only need one or two fields from a structure.

---

## ✅ 2. Passing an Entire Structure  
C also allows you to pass the **whole structure** to a function:

```c
void display(struct student s);
```

When you pass a structure this way, the function receives a **copy** of the structure.  
This is useful when:

- You want to process or display all structure data  
- You want to keep the original structure unchanged  
- You want to simplify function parameters by grouping related values  

---

## ✅ Why This Matters  
Passing structures to functions helps you:

- Write cleaner, modular code  
- Avoid long parameter lists  
- Keep related data bundled together  
- Build more complex programs (records, objects, data tables, etc.)

This concept is essential for real‑world C programming, especially when working with:

- Databases  
- File records  
- Game objects  
- Network packets  
- Embedded systems data
