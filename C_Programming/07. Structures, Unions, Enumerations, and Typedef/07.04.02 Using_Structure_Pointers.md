# 📘 Using Structure Pointers

Structure pointers are an essential tool in C programming. They are commonly used for two major purposes:

1. **Passing structures to functions by reference**  
2. **Building dynamic data structures**, such as linked lists, trees, and other dynamically allocated objects  

In this section, we focus on the first use—passing structures efficiently to functions.

---

## ✅ Why Use Structure Pointers?

Passing an entire structure to a function uses **call‑by‑value**, meaning the entire structure is copied onto the stack. For small structures, this overhead is minimal. But for larger structures—especially those containing arrays—copying can become slow and inefficient.

The solution is to pass a **pointer** to the structure instead.

### Benefits of passing a structure pointer:

- ✅ Only the **address** is passed → much faster  
- ✅ The function can **modify the original structure**  
- ✅ No large memory copies are required  

---

## ✅ Getting the Address of a Structure

To obtain the address of a structure variable, use the `&` operator:

```c
struct bal {
    float balance;
    char name[80];
} person;

struct bal *p;   /* declare a structure pointer */

p = &person;     /* store the address of person in p */
```

---

## ✅ Accessing Members Through a Pointer

When working with a structure pointer, you use the **arrow operator (`->`)** instead of the dot operator.

```c
p->balance
```

The arrow operator is simply:

```
->
```

It replaces:

```
(*p).balance
```

and is much easier to read.

---

# ✅ Example: A Simple Software Timer Using Structure Pointers

Below is a program that uses a structure pointer to update and display a software timer.

```c
/* Display a software timer. */
#include <stdio.h>

#define DELAY 128000

struct my_time {
    int hours;
    int minutes;
    int seconds;
};

void display(struct my_time *t);
void update(struct my_time *t);
void delay(void);

int main(void)
{
    struct my_time systime;

    systime.hours = 0;
    systime.minutes = 0;
    systime.seconds = 0;

    for(;;) {
        update(&systime);
        display(&systime);
    }

    return 0;
}
```

---

## ✅ Updating the Time (Using a Pointer)

```c
void update(struct my_time *t)
{
    t->seconds++;

    if(t->seconds == 60) {
        t->seconds = 0;
        t->minutes++;
    }

    if(t->minutes == 60) {
        t->minutes = 0;
        t->hours++;
    }

    if(t->hours == 24)
        t->hours = 0;

    delay();
}
```

---

## ✅ Displaying the Time (Using a Pointer)

```c
void display(struct my_time *t)
{
    printf("%02d:", t->hours);
    printf("%02d:", t->minutes);
    printf("%02d\n", t->seconds);
}
```

---

## ✅ Delay Function

```c
void delay(void)
{
    long int t;
    for(t = 1; t < DELAY; ++t)
        ;
}
```

Changing the value of `DELAY` adjusts the speed of the timer.

---

# ✅ How It All Works

- `systime` is a structure local to `main()`.  
- `update()` and `display()` receive **pointers** to this structure.  
- Inside these functions, members are accessed using the **arrow operator**.  
- Because the functions receive a pointer, they can **modify the original structure**.

---

# ✅ Key Takeaways

- Use the **dot operator (`.`)** when accessing members of a structure variable.  
- Use the **arrow operator (`->`)** when accessing members through a pointer.  
- Passing a structure pointer is faster and allows the function to modify the original data.  
- Structure pointers are foundational for dynamic data structures and efficient program design.
