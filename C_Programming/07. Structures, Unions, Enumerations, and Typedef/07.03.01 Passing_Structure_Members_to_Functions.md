# 📘 Passing Structure Members to Functions

In C, you can pass **individual members** of a structure to a function just as you would pass any normal variable. It does not matter that the value comes from inside a structure—the function simply receives the value itself.

Consider the following structure:

```c
struct fred {
    char x;
    int y;
    float z;
    char s[10];
} mike;
```

## ✅ Passing Individual Members

Each member can be passed directly to a function:

```c
func(mike.x);      /* passes the character stored in x */
func2(mike.y);     /* passes the integer stored in y */
func3(mike.z);     /* passes the float stored in z */
func4(mike.s);     /* passes the address of the string s */
func(mike.s[2]);   /* passes the character at s[2] */
```

In every case, the **value of the member** is passed.  
It makes no difference that the value belongs to a structure.

---

## ✅ Passing the Address of a Structure Member

If you want to pass the **address** of a specific member, place the `&` operator **before the structure variable**, not before the member name:

```c
func(&mike.x);      /* address of character x */
func2(&mike.y);     /* address of integer y */
func3(&mike.z);     /* address of float z */
func4(mike.s);      /* address of string s (no & needed) */
func(&mike.s[2]);   /* address of character s[2] */
```

### Important Notes

- ✅ The `&` operator goes before the **structure variable**, not the member.  
  Example: `&mike.x` (correct), not `mike.&x` (invalid).
- ✅ Arrays already represent addresses, so `mike.s` naturally passes a pointer—no `&` required.
