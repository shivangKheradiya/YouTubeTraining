# Arrays of Structures

Structures can be stored in arrays just like any other data type. To create an array of structures, you first define the structure type and then declare an array variable of that type.

For example, assuming the structure `addr` has already been defined, the following declaration creates an array of 100 structure elements:

```c
struct addr addr_list[100];
```

This allocates 100 separate `addr` structures, each containing its own set of members.

---

## Accessing Elements in an Array of Structures

To work with a specific structure in the array, you index the array name. For example, to print the ZIP code stored in the **third** structure:

```c
printf("%lu", addr_list[2].zip);
```

As with all arrays in C, indexing begins at **0**.

---

## Indexing Structure Members

When referring to a specific structure within the array, you index the array.  
When referring to a specific member within that structure, you index the member.

For example, the following statement assigns `'X'` to the first character of the `name` field in the **third** structure:

```c
addr_list[2].name[0] = 'X';
```

Here:

- `addr_list[2]` selects the third structure  
- `.name` selects the `name` member  
- `[0]` selects the first character of that array member
