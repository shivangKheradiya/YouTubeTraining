# Structures

A **structure** in C is a user‑defined data type that groups several variables under a single name. This makes it easy to keep related pieces of information together. A structure declaration acts as a *template* from which you can create actual structure variables, also called *instances*. The individual variables inside a structure are known as **members** (often called *fields* or *elements*).

Structures are typically used when the data items naturally belong together. For example, a mailing list entry—containing a name, street, city, state, and ZIP code—is a perfect candidate for a structure. Here is a structure that models this information:

```c
struct addr
{
    char name[30];
    char street[40];
    char city[20];
    char state[3];
    unsigned long int zip;
};
```

The keyword `struct` tells the compiler that a structure type is being defined. The identifier `addr` is the **structure tag**, which names this particular structure type. Notice that the declaration ends with a semicolon, because a structure declaration is a complete statement.

At this stage, no memory has been allocated—only the *type* has been defined. To create an actual structure variable, you must declare one explicitly:

```c
struct addr addr_info;
```

Here, `addr_info` is a structure variable of type `struct addr`. The type describes the layout, and the variable represents a concrete instance stored in memory.

When a structure variable is declared, the compiler allocates enough space to hold all of its members. Each structure variable has its own independent copy of every member. For example, if you declare:

```c
struct addr {
    char name[30];
    char street[40];
    char city[20];
    char state[3];
    unsigned long int zip;
} addr_info, binfo, cinfo;
```

you create three separate variables—`addr_info`, `binfo`, and `cinfo`—each containing its own `name`, `street`, `city`, `state`, and `zip` fields. Changing `binfo.zip` does not affect `cinfo.zip`, and so on.

If you only need a single structure variable, you may omit the structure tag entirely:

```c
struct {
    char name[30];
    char street[40];
    char city[20];
    char state[3];
    unsigned long int zip;
} addr_info;
```

This defines one structure variable named `addr_info` without creating a reusable structure type.

## General Form of a Structure Declaration

```
struct tag {
    type member_name;
    type member_name;
    type member_name;
    ...
} structure_variables;
```

Either the **tag** or the **structure variable list** may be omitted, but not both.  
If both are omitted, the compiler has no way to refer to the structure.
