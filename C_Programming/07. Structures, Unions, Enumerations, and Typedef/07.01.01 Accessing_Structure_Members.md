# Accessing Structure Members

You access individual members of a structure using the **dot operator (`.`)**. The dot operator connects a structure variable with one of its members.

For example, the following statement assigns the ZIP code `12345` to the `zip` field of the structure variable `addr_info`:

```c
addr_info.zip = 12345;
```

The pattern is always:

```
object_name.member_name
```

To display the ZIP code stored in `addr_info.zip`, you can write:

```c
printf("%lu", addr_info.zip);
```

This prints the value contained in the `zip` member of the `addr_info` structure.

---

## Using Structure Members as Arguments

Structure members can be passed directly to functions. For example, because `name` is a character array, you can pass it to `gets()` like this:

```c
gets(addr_info.name);
```

This sends a pointer to the first character of the `name` array.

---

## Indexing Array Members Inside Structures

Since `name` is an array, you can access its individual characters using array indexing. The following loop prints the contents of `addr_info.name` one character at a time:

```c
for (t = 0; addr_info.name[t]; ++t)
    putchar(addr_info.name[t]);
```

Notice that **the index is applied to the member name**, not the structure variable.  
`addr_info` represents the entire structure, while `name` is a specific element within that structure.

To index a structure member, always apply the subscript to the **member**, like this:

```
structure_variable.member[index]
```
