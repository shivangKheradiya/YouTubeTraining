# 📘 Declaring a Structure Pointer

Just like pointers to basic data types, C allows you to create **pointers to structures**. A structure pointer is declared by placing an asterisk (`*`) before the pointer’s name.

For example, assuming the structure `addr` has already been defined, the following statement declares `addr_pointer` as a pointer to a structure of that type:

```c
struct addr *addr_pointer;
```

This means `addr_pointer` can store the **address** of a `struct addr` variable, allowing you to access and manipulate structure data through a pointer.
