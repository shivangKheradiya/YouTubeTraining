# 📘 Unions

A **union** is a special data type in C that allows **multiple variables of different types to share the same memory location**. This makes it possible to interpret the same block of memory in different ways—an ability that is extremely useful in low‑level programming, type conversions, and memory‑efficient designs.

Declaring a union is similar to declaring a structure. Its general form is:

```c
union tag {
    type member_name;
    type member_name;
    type member_name;
    ...
} union_variables;
```

---

## ✅ Example: Declaring a Union Type

```c
union u_type {
    int i;
    char ch;
};
```

This declaration defines a union type but does **not** create any variables. To create a union variable named `cnvt`, write:

```c
union u_type cnvt;
```

In this union:

- `i` and `ch` **share the same memory location**
- Only **one** of them is valid at a time
- The size of the union is the size of its **largest member**

For example, if an `int` is 2 bytes and a `char` is 1 byte, the union will occupy **2 bytes**.

At any moment, you can treat the stored data as either an integer or a character.

---

## ✅ Accessing Union Members

Union members are accessed using the same operators used for structures:

- **Dot operator (`.`)** for direct access  
- **Arrow operator (`->`)** when using a pointer  

Example:

```c
cnvt.i = 10;     /* assign 10 to the integer member */
```

Using a pointer:

```c
void func1(union u_type *un)
{
    un->i = 10;  /* assign 10 through a pointer */
}
```

---

## ✅ Why Use Unions?

Unions are especially useful when:

- You need to interpret the same bytes in different ways  
- You want to perform low‑level type manipulation  
- You need memory‑efficient storage for mutually exclusive data types  

For example, unions are often used to:

- Examine or modify the individual bytes of a floating‑point number  
- Perform custom rounding or precision adjustments  
- Convert between binary formats  
- Build compact data structures for embedded systems

# ✅ Practical Example: Writing a Short Integer to a File

The C standard library does not provide a dedicated function to write a **short integer** directly to a file. Although `fwrite()` can do it, it introduces unnecessary overhead.

Using a union, you can easily write a short integer **one byte at a time**.

### Step 1: Define a union that overlays a short integer with a 2‑byte array

```c
union pw {
    short int i;
    char ch[2];
};
```

### Step 2: Implement a custom `putw()` function

```c
#include <stdio.h>
#include <stdlib.h>

union pw {
    short int i;
    char ch[2];
};

int putw(short int num, FILE *fp);

int main(void)
{
    FILE *fp;

    fp = fopen("test.tmp", "wb+");
    if(fp == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    putw(1025, fp);   /* write the value 1025 */
    fclose(fp);

    return 0;
}

int putw(short int num, FILE *fp)
{
    union pw word;
    word.i = num;

    putc(word.ch[0], fp);   /* write low byte */
    return putc(word.ch[1], fp);  /* write high byte */
}
```

### ✅ What’s happening?

- The short integer is stored in `word.i`
- The same memory is viewed as a 2‑byte array `word.ch`
- Each byte is written separately using `putc()`

This demonstrates how unions allow you to reinterpret data at the byte level—something that is extremely useful in systems programming.
