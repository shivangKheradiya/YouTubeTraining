# 📘 `typedef` — Creating New Type Names in C

The `typedef` keyword allows you to define **new names** (aliases) for existing data types. It does **not** create a new data type; instead, it provides a more readable or portable name for an existing one.

Using `typedef` can make your programs:

- ✅ More portable across different machines  
- ✅ Easier to maintain  
- ✅ More self‑documenting and readable  

This is especially helpful when dealing with machine‑dependent data types.

---

## ✅ General Form of `typedef`

```c
typedef type newname;
```

- **type** → any valid C data type  
- **newname** → the alias you want to create  

The new name does **not** replace the original type; it simply becomes an additional way to refer to it.

---

## ✅ Example: Creating a New Name for `float`

```c
typedef float balance;
```

This tells the compiler that **balance** is another name for `float`.

You can now declare variables using the new type name:

```c
balance over_due;
```

Here, `over_due` is a floating‑point variable—`balance` is simply an alias for `float`.

---

## ✅ Chaining `typedef` Names

Once a type alias is defined, it can be used in another `typedef`:

```c
typedef balance overdraft;
```

Now:

- `overdraft` → alias for `balance`  
- `balance` → alias for `float`  

So `overdraft` is ultimately another name for `float`.

---

## ✅ Why Use `typedef`?

- ✅ **Portability:** If a type changes between systems, only the `typedef` needs updating  
- ✅ **Readability:** Names like `balance`, `speed_t`, or `byte` are more descriptive than raw types  
- ✅ **Cleaner code:** Especially useful for complex types like pointers, structures, and function pointers  

However, remember:

> `typedef` does **not** create a new physical type—only a new name for an existing one.
