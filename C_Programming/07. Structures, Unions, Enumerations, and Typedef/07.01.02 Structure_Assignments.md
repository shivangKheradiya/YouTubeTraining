# Structure Assignments

C allows you to assign one structure to another **as long as both structures are of the same type**. This means you can copy all members in a single assignment statement—there is no need to assign each field individually.

The following example demonstrates how structure assignment works:

```c
#include <stdio.h>

int main(void)
{
    struct {
        int a;
        int b;
    } x, y;

    x.a = 10;
    y = x;   /* assign one structure to another */

    printf("%d", y.a);
    return 0;
}
```

After the assignment `y = x;`, all members of `x` are copied into `y`.  
Therefore, `y.a` will contain the value **10**.

Structure assignment provides a simple and efficient way to duplicate the contents of one structure variable into another, as long as both share the same structure definition.
