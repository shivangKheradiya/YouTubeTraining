# 📘 Bit‑Fields

C provides a built‑in feature called a **bit‑field**, which allows you to access and manipulate individual bits within a structure. Bit‑fields are useful in several situations, such as:

- When storage is limited and you want to pack multiple Boolean values into a single byte  
- When hardware devices encode status information into specific bits  
- When encryption or low‑level routines require direct access to individual bits  

Although these tasks can be performed using bitwise operators, bit‑fields offer a more structured and readable approach.

---

## ✅ Defining a Bit‑Field

A bit‑field must be a member of a **structure** or **union**. It specifies how many bits a particular field occupies.

General form:

```c
type name : length;
```

Where:

- **type** must be `int`, `signed`, or `unsigned`  
- **length** is the number of bits allocated to the field  
- C99 also allows `_Bool` as a bit‑field type  

---

## ✅ Example: Hardware Status Byte

Suppose a serial communication device returns a status byte with the following bit meanings:

| Bit | Meaning When Set               |
|-----|--------------------------------|
| 0   | Change in clear‑to‑send        |
| 1   | Change in data‑set‑ready       |
| 2   | Trailing edge detected         |
| 3   | Change in receive line         |
| 4   | Clear‑to‑send                  |
| 5   | Data‑set‑ready                 |
| 6   | Telephone ringing              |
| 7   | Received signal                |

You can represent this byte using a bit‑field:

```c
struct status_type {
    unsigned delta_cts : 1;
    unsigned delta_dsr : 1;
    unsigned tr_edge   : 1;
    unsigned delta_rec : 1;
    unsigned cts       : 1;
    unsigned dsr       : 1;
    unsigned ring      : 1;
    unsigned rec_line  : 1;
} status;
```

---

## ✅ Using Bit‑Fields

Example usage:

```c
status = get_port_status();

if (status.cts)
    printf("clear to send");

if (status.dsr)
    printf("data ready");
```

To assign a value to a bit‑field, treat it like any other structure member:

```c
status.ring = 0;   /* clear the ring bit */
```

If the structure is accessed through a pointer, use the arrow operator:

```c
ptr->cts = 1;
```

---

## ✅ Anonymous Bit‑Fields

You can skip naming certain bit‑fields to ignore unused bits:

```c
struct status_type {
    unsigned : 4;   /* skip first 4 bits */
    unsigned cts : 1;
    unsigned dsr : 1;
} status;
```

Bits after `dsr` do not need to be declared if they are not used.

---

## ✅ Mixing Bit‑Fields with Normal Members

Bit‑fields can appear alongside regular structure members:

```c
struct emp {
    struct addr address;
    float pay;
    unsigned lay_off    : 1;  /* active or laid off */
    unsigned hourly     : 1;  /* hourly or salaried */
    unsigned deductions : 3;  /* number of deductions */
};
```

This example stores three pieces of information in **just one byte**, instead of three separate bytes.

---

## ⚠️ Restrictions of Bit‑Fields

Bit‑fields come with several limitations:

- You **cannot take the address** of a bit‑field  
- Bit‑fields **cannot be arrays**  
- Bit ordering (left‑to‑right or right‑to‑left) is **machine‑dependent**  
- Different compilers may impose additional restrictions  

Because of these machine dependencies, bit‑fields are best used when portability is not a primary concern or when working closely with hardware.
