# ✅ Opening a File

The **`fopen()`** function is the standard way to open a file in C. When you call it, it creates a **stream** and associates that stream with a specific file. If the operation succeeds, `fopen()` returns a **file pointer** of type `FILE *`, which your program will use for all subsequent I/O on that file. If the operation fails, it returns **`NULL`**.

---

## ✅ Prototype of `fopen()`

```c
FILE *fopen(const char *filename, const char *mode);
```

- **`filename`**: the name of the file, optionally including a path  
- **`mode`**: a string that specifies how the file should be opened (read, write, append, binary, etc.)

---

## ✅ Common File I/O Functions

These functions—declared in `<stdio.h>`—form the core of the C file system:

| Function | Purpose |
|---------|---------|
| `fopen()` | Open a file |
| `fclose()` | Close a file |
| `putc()`, `fputc()` | Write a character |
| `getc()`, `fgetc()` | Read a character |
| `fgets()` | Read a string |
| `fputs()` | Write a string |
| `fprintf()` | Formatted output to a file |
| `fscanf()` | Formatted input from a file |
| `fseek()` | Move to a specific byte position |
| `ftell()` | Get current file position |
| `rewind()` | Reset position to start |
| `feof()` | Detect end-of-file |
| `ferror()` | Detect I/O errors |
| `remove()` | Delete a file |
| `fflush()` | Flush buffered output |

These functions are part of the standard C library and widely documented in references such as GeeksforGeeks and the GNU C library docs.

---

## ✅ File Modes (Text and Binary)

The **mode string** determines how the file is opened. Common modes include:

| Mode | Meaning |
|------|---------|
| `r` | Open text file for reading (fails if file doesn’t exist) |
| `w` | Create text file for writing (overwrites if exists) |
| `a` | Append to text file (creates if missing) |
| `rb`, `wb`, `ab` | Same as above, but for binary files |
| `r+` | Read/write, file must exist |
| `w+` | Read/write, create or overwrite |
| `a+` | Read/write, append or create |
| `r+b`, `w+b`, `a+b` | Binary versions of the above |

The difference between **`r+`** and **`w+`** is well‑documented:  
- `r+` requires the file to exist  
- `w+` creates the file and **truncates** it if it already exists

---

## ✅ Example: Opening a File Safely

```c
FILE *fp;

if ((fp = fopen("test", "w")) == NULL) {
    printf("Cannot open file.\n");
    exit(1);
}
```

This pattern ensures you detect errors such as missing permissions or a full disk before attempting to write.

---

## ✅ Text vs. Binary Mode

- **Text mode** may translate newline characters depending on the system (e.g., `\n` ↔ `\r\n`).
- **Binary mode** performs **no translation**, preserving exact byte values.

---

## ✅ Additional Notes

- If you open a file in **append mode**, all writes go to the end, and the file is created if missing.
- Opening a file with **`w`** or **`w+`** destroys existing contents.
- The maximum number of files you can have open at once is given by **`FOPEN_MAX`**, which is at least 8 in standard C implementations.
