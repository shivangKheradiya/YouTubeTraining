# ✅ Random‑Access I/O with `fseek()`

C’s standard I/O library allows you to jump to any location in a file using the `fseek()` function. This makes it possible to read or write data at arbitrary positions rather than processing the file sequentially.

### **Prototype**

```c
int fseek(FILE *fp, long int numbytes, int origin);
```

### **Parameters**

- **`fp`** — a valid file pointer returned by `fopen()`
- **`numbytes`** — the offset in bytes
- **`origin`** — where the offset begins, using one of these macros:

| Origin | Meaning |
|--------|----------|
| `SEEK_SET` | Beginning of file |
| `SEEK_CUR` | Current position |
| `SEEK_END` | End of file |

These meanings are confirmed in standard references such as GeeksforGeeks and AlphaCodingSkills.

### **Return value**

- **0** → success  
- **non‑zero** → failure (e.g., invalid seek)

---

# ✅ Example: Seeking to a Specific Byte

The following program opens a file in binary mode, seeks to a specific byte offset, and prints the character found there:

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    FILE *fp;

    if (argc != 3) {
        printf("Usage: SEEK filename byte\n");
        exit(1);
    }

    if ((fp = fopen(argv[1], "rb")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    if (fseek(fp, atol(argv[2]), SEEK_SET)) {
        printf("Seek error.\n");
        exit(1);
    }

    printf("Byte at %ld is %c.\n", atol(argv[2]), getc(fp));

    fclose(fp);
    return 0;
}
```

This demonstrates a direct seek from the start of the file using `SEEK_SET`.

---

# ✅ Seeking by Data Type Size

Random access becomes especially useful when working with fixed‑size records. For example, if a file contains an array of structures:

```c
fseek(fp, 9 * sizeof(struct addr), SEEK_SET);
```

This moves the file pointer to the **10th record** (index 9).

---

# ✅ Getting the Current Position: `ftell()`

```c
long int ftell(FILE *fp);
```

- Returns the current byte offset within the file.
- Returns **–1** on error.

This value is safe to use later with `fseek(fp, saved_position, SEEK_SET)`.

---

# ✅ Why Random Access Should Use Binary Mode

According to standard documentation, text mode may perform newline translations (e.g., `\n` ↔ `\r\n`), meaning the byte positions in memory do not match the actual bytes in the file. This is why random access is recommended only for **binary files**.

The exception:  
You may safely seek in a text file **only** to a position previously obtained from `ftell()`.

---

# ✅ Important Note

Even if a file contains only text, you may open it in **binary mode** to avoid translation issues. The limitation applies to *text mode*, not to the file’s content.

---

# ✅ **Summary:**  
**`fseek()` lets you move the file position indicator to any byte in a file, enabling true random‑access I/O.** You specify an offset, a starting reference point (`SEEK_SET`, `SEEK_CUR`, or `SEEK_END`), and the function repositions the stream accordingly.
