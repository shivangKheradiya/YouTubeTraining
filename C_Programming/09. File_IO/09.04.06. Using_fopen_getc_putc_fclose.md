# ✅ Using `fopen()`, `getc()`, `putc()`, and `fclose()` in C

These four functions form the smallest useful set of routines for basic file handling in C. With them, you can open a file, read characters, write characters, and close the file when you're done.

To illustrate how they work together, here are two simple programs: one writes keyboard input to a file, and the other reads a file and displays its contents.

---

## ✅ Example 1: Writing Keyboard Input to a File (KTOD)

This program:

- Expects a filename on the command line  
- Opens that file for writing  
- Reads characters from the keyboard using `getchar()`  
- Writes each character to the file using `putc()`  
- Stops when the user types a dollar sign (`$`)  
- Closes the file with `fclose()`  

```c
/* KTOD: A key-to-disk program */
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    FILE *fp;
    char ch;

    if (argc != 2) {
        printf("You forgot to enter the filename.\n");
        exit(1);
    }

    if ((fp = fopen(argv[1], "w")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    do {
        ch = getchar();
        putc(ch, fp);
    } while (ch != '$');

    fclose(fp);
    return 0;
}
```

Running this program as:

```
KTOD TEST
```

lets you type text that will be saved into a file named **TEST**.

## ✅ Example 2: Displaying a File on the Screen (DTOS)

This companion program:

- Takes a filename from the command line  
- Opens the file for reading  
- Reads characters one at a time using `getc()`  
- Prints each character to the screen with `putchar()`  
- Stops when `getc()` returns `EOF`  
- Closes the file  

```c
/* DTOS: Display text file on screen */
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    FILE *fp;
    char ch;

    if (argc != 2) {
        printf("You forgot to enter the filename.\n");
        exit(1);
    }

    if ((fp = fopen(argv[1], "r")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    ch = getc(fp);  /* read one character */
    while (ch != EOF) {
        putchar(ch); /* print to screen */
        ch = getc(fp);
    }

    fclose(fp);
    return 0;
}
```

## ✅ How to Try Them

1. Run **KTOD** to create a file and type some text into it.  
2. Run **DTOS** with the same filename to display the contents.

These two programs demonstrate the basic workflow of C file I/O:

- **Open** a file  
- **Read or write** characters  
- **Close** the file
