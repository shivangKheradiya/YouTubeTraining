# ✅ Erasing Files with `remove()`

The C standard library provides the **`remove()`** function to delete a file from the file system. It takes the name of the file you want to erase and attempts to remove it. If the operation succeeds, the function returns **0**; if it fails—because the file doesn’t exist, permissions are insufficient, or the file is in use—it returns a **non‑zero** value.

---

## 🔹 Function Prototype

```c
int remove(const char *filename);
```

- **`filename`**: a C‑string containing the name (and optional path) of the file to delete.
- **Return value**:
  - **0** → file successfully deleted  
  - **non‑zero** → deletion failed  

---

## ✅ Example Program: Confirm Before Deleting

The following program demonstrates how to use `remove()` safely. It asks the user to confirm the deletion before actually erasing the file. This kind of “double‑check” utility can be helpful for beginners or for preventing accidental file loss.

```c
/* Double check before erasing. */
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>

int main(int argc, char *argv[])
{
    char str[80];

    if (argc != 2) {
        printf("usage: xerase <filename>\n");
        exit(1);
    }

    printf("Erase %s? (Y/N): ", argv[1]);
    gets(str);

    if (toupper(*str) == 'Y')
        if (remove(argv[1])) {
            printf("Cannot erase file.\n");
            exit(1);
        }

    return 0;
}
```

### ✅ How it works

1. The program expects exactly one command‑line argument: the name of the file to delete.
2. It prompts the user for confirmation.
3. If the user types **Y** or **y**, the program calls `remove()`.
4. If `remove()` returns a non‑zero value, an error message is printed.
5. Otherwise, the file is successfully deleted.

---

## ✅ Notes

- `remove()` deletes the file **immediately** if the operating system allows it.
- If the file is open elsewhere, deletion may fail depending on the OS (e.g., Windows locks open files).
- The program uses `gets()`, which is unsafe; modern code should use `fgets()` instead.
