# ✅ Flushing a Stream with `fflush()`

**`fflush()` forces any buffered output to be written immediately to the file or device associated with a stream.** This is useful when you want to ensure that pending output is saved without closing the file.

---

## 🔹 Prototype

```c
int fflush(FILE *fp);
```

- **`fp`**: a pointer to an open output or update stream  
- **`NULL`**: flushes *all* open output streams  

According to standard documentation, `fflush()` writes any buffered data to the underlying file or device, ensuring that nothing remains in memory waiting to be written.

---

## ✅ What `fflush()` Does

Most C streams are **buffered**, meaning output is stored temporarily in memory before being written to disk or the console. This improves performance but means data may not be written immediately.

Calling `fflush()`:

- Forces the buffer to be written out  
- Ensures the file contains all output up to that point  
- Does **not** close the file  

The GNU C Library confirms that flushing “delivers any buffered output on the stream to the file”.

---

## ✅ Return Value

- **0** → success  
- **EOF** → failure (and the stream’s error indicator is set)

Common causes of failure include disk errors or unavailable devices.

---

## ✅ Flushing All Streams

If you call:

```c
fflush(NULL);
```

then **every open output stream** is flushed. This behavior is documented in multiple references, including Tutorialspoint and TutorialKart.

---

## ✅ When You Might Use `fflush()`

- When writing log files and wanting immediate updates  
- Before a program crash might lose buffered output  
- When interacting with devices that require immediate output  
- When mixing input and output on the same stream
