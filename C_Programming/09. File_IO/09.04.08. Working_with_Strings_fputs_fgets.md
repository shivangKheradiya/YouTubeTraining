# ✅ Working with Strings: `fputs()` and `fgets()`

Beyond single‑character I/O with `getc()` and `putc()`, C also provides two functions designed specifically for handling **entire strings**: `fgets()` for input and `fputs()` for output. These functions operate on file streams just like the character‑based routines, but they process multiple characters at once.

---

## 🔹 Function Prototypes

```c
int fputs(const char *str, FILE *fp);
char *fgets(char *str, int length, FILE *fp);
```

---

## ✅ `fputs()` — Writing a String to a File

`fputs()` writes the **null‑terminated string** pointed to by `str` into the stream identified by `fp`.

- On success, it returns a non‑negative value.
- If an error occurs, it returns **EOF**.

It does **not** automatically append a newline, so if you want each string to appear on its own line in the file, you must add one yourself.

---

## ✅ `fgets()` — Reading a String from a File

`fgets()` reads characters from a file until one of the following occurs:

- A newline character is encountered  
- `length - 1` characters have been read  
- An error or end‑of‑file condition occurs  

Important details:

- If a newline is read, **it becomes part of the resulting string**.
- The function always null‑terminates the output buffer.
- On success, it returns the pointer `str`.
- On failure (including end‑of‑file before any characters are read), it returns **NULL**.

This makes `fgets()` much safer than the old `gets()` function, which should never be used in modern code.

---

## ✅ Example Program Using `fputs()`

The following program reads lines from the keyboard and writes them to a file named **TEST**.  
Entering a blank line ends the program.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char str[80];
    FILE *fp;

    if ((fp = fopen("TEST", "w")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    do {
        printf("Enter a string (CR to quit):\n");
        gets(str);              /* read a line from keyboard */
        strcat(str, "\n");      /* add newline for readability */
        fputs(str, fp);         /* write to file */
    } while (*str != '\n');

    return 0;
}
```

This example shows how `fputs()` can be used to write entire lines at once.  
(And yes—`gets()` is unsafe, but this mirrors the original teaching style.)
