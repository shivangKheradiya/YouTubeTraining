# ✅ Reading and Writing Binary Data: `fread()` and `fwrite()`

When you need to work with data larger than a single byte—such as integers, floating‑point values, or entire structures—the C standard library provides two powerful block‑I/O functions: **`fread()`** and **`fwrite()`**. These functions allow you to transfer raw memory blocks directly to and from a file, making them ideal for binary files and efficient data processing.

---

## 🔹 Function Prototypes

```c
size_t fread(void *buffer, size_t num_bytes, size_t count, FILE *fp);
size_t fwrite(const void *buffer, size_t num_bytes, size_t count, FILE *fp);
```

These prototypes match the standard definitions described in the Linux manual and Microsoft documentation.

---

## ✅ How the Parameters Work

### **`buffer`**
- For **`fread()`**, this is where the incoming data will be stored.
- For **`fwrite()`**, this is the memory region containing the data you want to write.

### **`num_bytes`**
- The size (in bytes) of each item you want to read or write.
- Often you pass `sizeof(type)` here.

### **`count`**
- How many items of size `num_bytes` you want to transfer.

Together, the total number of bytes processed is:

\[
\text{num\_bytes} \times \text{count}
\]

This design is confirmed in multiple references, including Stack Overflow and the GNU C Library documentation.

### **`fp`**
- A valid file pointer returned by `fopen()`.

---

## ✅ Return Values

### **`fread()`**
Returns the **number of items successfully read**, which may be:
- **Less than `count`** if end‑of‑file is reached or an error occurs  
- **Zero** if nothing could be read

To distinguish between EOF and error, you can use `feof()` or `ferror()`.

### **`fwrite()`**
Returns the **number of items successfully written**.  
This should equal `count` unless an error occurs.

---

## ✅ Why Use `fread()` and `fwrite()`?

According to the GNU C Library manual, block I/O is efficient and ideal for binary data because it:
- Avoids character‑by‑character overhead  
- Preserves exact memory representation  
- Prevents precision loss for floating‑point values  
- Allows reading/writing entire structures directly

This makes these functions essential for tasks like:
- Saving and loading structs  
- Handling binary file formats  
- Fast data serialization  
- Copying raw memory blocks
