# File System Basics

The C file system is built from a collection of related functions, all of which are declared in the `<stdio.h>` header. This header provides the prototypes for the standard input/output routines and defines several important data types used throughout file handling. According to the C standard library specification, `<stdio.h>` defines **`FILE`**, **`fpos_t`**, and **`size_t`**, each serving a specific role in managing streams and file positions.

---

## Core Types Defined in `<stdio.h>`

### **`size_t`**
A type used for representing sizes and counts. It is an unsigned integer type defined by the implementation.

### **`fpos_t`**
A type capable of storing all information needed to represent a file position in a portable way. It is also an unsigned type in most implementations.

### **`FILE`**
A structure that holds all the internal information about an open stream—buffering state, file position, status flags, and more.

These types form the foundation of the C file I/O system.

---

## Important Macros in `<stdio.h>`

The header also defines several macros that support file operations:

- **`NULL`** – Represents a null pointer.
- **`EOF`** – Returned by input functions when the end of a file is reached or an error occurs. It is often defined as `-1`.
- **`FOPEN_MAX`** – Indicates the maximum number of files the implementation guarantees can be open simultaneously.
- **`SEEK_SET`, `SEEK_CUR`, `SEEK_END`** – Constants used with `fseek()` to control file positioning:
  - `SEEK_SET` → beginning of the file  
  - `SEEK_CUR` → current position  
  - `SEEK_END` → end of the file  
  These values are used by `fseek()` to perform random access within a file.

These macros make it possible to write portable, predictable file‑handling code.

---

## Summary

The C file system revolves around a small set of essential types and macros defined in `<stdio.h>`. Together, they provide the building blocks for opening files, navigating through them, reading and writing data, and managing streams in a consistent and portable way.
