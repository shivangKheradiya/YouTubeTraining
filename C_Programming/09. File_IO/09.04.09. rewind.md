# ✅ Using `rewind()` in C

The **`rewind()`** function is used to move a file’s position indicator back to the very beginning of the stream. This is useful when you want to reread a file without closing and reopening it. According to standard references, `rewind()` also clears the stream’s error and end‑of‑file flags.

---

## 🔹 Prototype

```c
void rewind(FILE *fp);
```

- `fp` must be a valid file pointer returned by `fopen()`.
- The function does not return a value.

After calling `rewind()`, the next read or write operation begins at the start of the file.

---

## ✅ Why Use `rewind()`?

When you write to a file and then want to read it back within the same program, the file position indicator will be at the end of the written data. Calling `rewind()` resets the position so you can read from the beginning without reopening the file.

This is especially useful when a file is opened in **update mode** (`"w+"`, `"r+"`, or `"a+"`), which allows both reading and writing.

---

## ✅ Example Program Using `rewind()`

The following program writes user‑entered strings to a file named **TEST**, then rewinds the file and displays its contents. The file is opened in `"w+"` mode so it can be both written to and read from.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char str[80];
    FILE *fp;

    if ((fp = fopen("TEST", "w+")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    do {
        printf("Enter a string (CR to quit):\n");
        gets(str);
        strcat(str, "\n");   /* add a newline */
        fputs(str, fp);
    } while (*str != '\n');

    /* Now read and display the file */
    rewind(fp);  /* move file position back to start */

    while (!feof(fp)) {
        fgets(str, 79, fp);
        printf(str);
    }

    return 0;
}
```

### What this program does:

1. Opens **TEST** in read/write mode (`"w+"`).
2. Reads lines from the keyboard until a blank line is entered.
3. Writes each line to the file.
4. Calls **`rewind()`** to reset the file position.
5. Uses `fgets()` to read the file back from the beginning.
6. Prints each line to the screen.
