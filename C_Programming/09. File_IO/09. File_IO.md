# Introduction to the C File System

This chapter describes the **C file system**. As explained in Chapter 8, the C I/O system is implemented through **library functions**, not through language keywords. This design makes the I/O system extremely powerful and flexible.

When operating on files, data can be transferred either:

- In its **internal binary representation**, or  
- In a **human-readable text format**  

Because of this, you can easily create files tailored to any purpose—whether you need compact, efficient binary data for programs, or clear, readable text for users and debugging.
