# ✅ Formatted File I/O: `fprintf()` and `fscanf()`

C’s standard I/O library includes two functions—**`fprintf()`** and **`fscanf()`**—that work just like `printf()` and `scanf()`, but instead of interacting with the console, they operate on **files**. This makes them ideal for reading and writing human‑readable text data.

---

## 📌 Function Prototypes

```c
int fprintf(FILE *fp, const char *control_string, ...);
int fscanf(FILE *fp, const char *control_string, ...);
```

- **`fp`** is a file pointer returned by `fopen()`.
- **`control_string`** contains format specifiers (e.g., `%d`, `%s`, `%f`), just like in `printf()` and `scanf()`.

According to Tutorialspoint, `fscanf()` reads formatted input from a stream using the same conversion rules as `scanf()`. GeeksforGeeks confirms that `fprintf()` and `fscanf()` are part of the standard C file‑I/O toolkit.

---

## ✅ What These Functions Do

### **`fprintf()`**
- Writes formatted text to a file.
- Behaves exactly like `printf()`, but the output goes to the file stream.

### **`fscanf()`**
- Reads formatted text from a file.
- Behaves like `scanf()`, but pulls data from the file stream.

Both functions allow you to work with text files in a way that feels natural if you already know `printf()` and `scanf()`.

---

## ✅ Example Program

This example:

1. Reads a string and an integer from the keyboard.  
2. Writes them to a file using `fprintf()`.  
3. Reopens the file and reads the values back using `fscanf()`.  
4. Prints the results to the screen.

```c
/* fscanf() - fprintf() example */
#include <stdio.h>
#include <io.h>
#include <stdlib.h>

int main(void)
{
    FILE *fp;
    char s[80];
    int t;

    if ((fp = fopen("test", "w")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    printf("Enter a string and a number: ");
    fscanf(stdin, "%s%d", s, &t);   /* read from keyboard */
    fprintf(fp, "%s %d", s, t);     /* write to file */
    fclose(fp);

    if ((fp = fopen("test", "r")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    fscanf(fp, "%s%d", s, &t);      /* read from file */
    fprintf(stdout, "%s %d", s, t); /* print on screen */

    return 0;
}
```

After running it, you can open the file **TEST** and see the stored text in plain, readable form.

---

## ⚠️ Performance Note

Formatted I/O is convenient, but not always efficient:

- **`fprintf()` and `fscanf()` convert data to and from ASCII text**, which adds overhead.
- **`fread()` and `fwrite()` work with raw binary data**, making them faster and more compact.

If you care about **speed** or **file size**, binary I/O is usually the better choice.
