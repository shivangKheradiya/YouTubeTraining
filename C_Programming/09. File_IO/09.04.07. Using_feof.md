# ✅ Using `feof()`

When you read characters from a file using `getc()`, the function returns **`EOF`** when it reaches the end of the file. However, relying solely on the return value of `getc()` can be misleading for two reasons:

### **1. Binary files may legitimately contain a byte whose value equals `EOF`.**
Since `EOF` is just an integer constant (commonly `-1`), a binary file could contain a byte that compares equal to it. If you test only the return value of `getc()`, you might incorrectly think the end of the file has been reached.

### **2. `getc()` returns `EOF` both on end‑of‑file *and* on read errors.**
If you only check for `EOF`, you cannot tell whether you hit the end of the file or encountered an I/O failure.

To handle both issues, C provides the function **`feof()`**, which explicitly reports whether the end of the file has been reached.

---

## ✅ Prototype of `feof()`

```c
int feof(FILE *fp);
```

- Returns **non‑zero** if the end of the file has been reached  
- Returns **0** otherwise  

This allows you to distinguish between end‑of‑file and other conditions.

---

## ✅ Example: Reading Until End‑of‑File

A typical loop for reading a binary file safely looks like this:

```c
while (!feof(fp))
    ch = getc(fp);
```

This pattern works for both text and binary files.

---

## ✅ Example Program: Copying a File

The following program demonstrates how `feof()` can be used when copying a file.  
Both the input and output files are opened in **binary mode**, and the loop continues until `feof()` reports that the input file has been fully read.

```c
/* Copy a file. */
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    FILE *in, *out;
    char ch;

    if (argc != 3) {
        printf("You forgot to enter a filename.\n");
        exit(1);
    }

    if ((in = fopen(argv[1], "rb")) == NULL) {
        printf("Cannot open source file.\n");
        exit(1);
    }

    if ((out = fopen(argv[2], "wb")) == NULL) {
        printf("Cannot open destination file.\n");
        exit(1);
    }

    /* Copy the file one byte at a time. */
    while (!feof(in)) {
        ch = getc(in);
        if (!feof(in))
            putc(ch, out);
    }

    fclose(in);
    fclose(out);
    return 0;
}
```

This program works for both text and binary files because it avoids misinterpreting binary data as an end‑of‑file marker.
