# Standard Streams

**C programs automatically start with three open streams—`stdin`, `stdout`, and `stderr`—which normally connect to the console but can be redirected by the operating system.** They behave like ordinary `FILE*` pointers and can be used with any standard I/O function.

---

# ✅ Understanding the Standard Streams

When a C program begins execution, the runtime environment automatically opens **three predefined streams**:

- **`stdin`** — standard input  
- **`stdout`** — standard output  
- **`stderr`** — standard error  

These are described in the C standard library and documented in cppreference and the GNU C Library manual. Wikipedia notes that these streams are preconnected channels between a program and its environment.

Although they usually refer to the console (keyboard and screen), operating systems such as Windows, Unix, and DOS allow **I/O redirection**, meaning these streams can be pointed to files or other devices.

---

# ✅ Using Standard Streams as `FILE*`

Because each standard stream is effectively a `FILE*`, you can pass them to any function that expects a file pointer. For example, `putchar()` could be implemented as:

```c
int putchar(char c)
{
    return putc(c, stdout);
}
```

This works because `stdout` is simply a pointer to a `FILE` object representing the program’s standard output stream.

---

# ✅ Reading from `stdin` Safely

You can use `fgets()` to read from the console through `stdin`:

```c
char str[255];
fgets(str, 80, stdin);
```

This is safer than `gets()` because `fgets()` enforces a maximum number of characters, preventing buffer overruns.

The only catch is that **`fgets()` keeps the newline character**, so you may need to remove it manually:




```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[80];
    int i;

    printf("Enter a string: ");
    fgets(str, 10, stdin);

    /* remove newline, if present */
    i = strlen(str) - 1;
    if (str[i] == '\n') str[i] = '\0';

    printf("This is your string: %s", str);
    return 0;
}
```

---

# ✅ Important Notes

- **You cannot reassign `stdin`, `stdout`, or `stderr` using `fopen()`**, because they are not ordinary variables—they are predefined macros that evaluate to `FILE*` expressions.
- These streams are **opened automatically** at program start and **closed automatically** at program termination.
- `stderr` is typically unbuffered, ensuring error messages appear immediately.
