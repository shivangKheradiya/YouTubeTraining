# ✅ Using `fread()` and `fwrite()` in C

Once a file has been opened in **binary mode**, you can use `fread()` and `fwrite()` to transfer blocks of raw data directly between memory and a file. These functions are ideal for reading and writing numbers, arrays, and even entire structures—anything that occupies more than a single byte.

---

## 🔹 How Block I/O Works

Both functions operate on **items**, where each item has a fixed size in bytes. You specify:

- the **address** of the memory buffer  
- the **size** of each item  
- the **number** of items  
- the **file stream**  

This makes it easy to write or read any data type by using `sizeof(type)` to determine its size.

---

## ✅ Example: Writing and Reading Basic Data Types

The following example writes a `double`, an `int`, and a `long` to a binary file, then rewinds the file and reads them back:

```c
/* Write some non-character data to a disk file and read it back. */
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *fp;
    double d = 12.23;
    int i = 101;
    long l = 123023L;

    if ((fp = fopen("test", "wb+")) == NULL) {
        printf("Cannot open file.\n");
        exit(1);
    }

    fwrite(&d, sizeof(double), 1, fp);
    fwrite(&i, sizeof(int), 1, fp);
    fwrite(&l, sizeof(long), 1, fp);

    rewind(fp);

    fread(&d, sizeof(double), 1, fp);
    fread(&i, sizeof(int), 1, fp);
    fread(&l, sizeof(long), 1, fp);

    printf("%f %d %ld", d, i, l);

    fclose(fp);
    return 0;
}
```

### ✅ Key points illustrated by this program

- The **buffer** is simply the variable’s own memory address (`&d`, `&i`, `&l`).  
- `sizeof(type)` ensures the correct number of bytes is transferred.  
- The file is opened with `"wb+"` so it can be both written and read in binary mode.  
- In real applications, you should always check the return values of `fread()` and `fwrite()` to detect partial reads/writes or errors.

---

## ✅ Using Block I/O with Structures

One of the most powerful uses of `fread()` and `fwrite()` is storing and retrieving entire structures in a single operation.

For example, given:

```c
struct struct_type {
    float balance;
    char name[80];
} cust;
```

You can write the entire structure to a file with:

```c
fwrite(&cust, sizeof(struct struct_type), 1, fp);
```

This writes the complete memory image of `cust`—including the float and the character array—in one call.

# ✅ A Mailing List Example Using `fread()` and `fwrite()`

This example shows how powerful block‑I/O can be when working with large amounts of structured data. Instead of writing each field individually, you can save and load entire structures with a single call to `fwrite()` or `fread()`.

The mailing list is stored as an array of structures:

```c
struct addr {
    char name[30];
    char street[40];
    char city[20];
    char state[3];
    unsigned long zip;
} addr_list[MAX];
```

- `MAX` determines how many entries the list can hold.
- A record is considered **unused** if its `name` field begins with a null character (`'\0'`).

---

# ✅ Saving and Loading the Mailing List

Two functions handle persistence:

- **`save()`** writes all active records to a binary file.
- **`load()`** reads them back into memory.

Because `fread()` and `fwrite()` operate on raw memory blocks, each function is extremely compact.

---

## ✅ Saving the List

```c
void save(void)
{
    FILE *fp;
    int i;

    fp = fopen("maillist", "wb");
    if (!fp) {
        printf("Cannot open file.\n");
        return;
    }

    for (i = 0; i < MAX; i++)
        if (addr_list[i].name[0] != '\0')
            if (fwrite(&addr_list[i], sizeof(struct addr), 1, fp) != 1)
                printf("File write error.\n");

    fclose(fp);
}
```

### Key points

- Only entries with a non‑empty `name` field are written.
- Each structure is written in one call.
- The return value of `fwrite()` is checked to detect errors.

---

## ✅ Loading the List

```c
void load(void)
{
    FILE *fp;
    int i;

    fp = fopen("maillist", "rb");
    if (!fp) {
        printf("Cannot open file.\n");
        return;
    }

    init_list();  // clear the array first

    for (i = 0; i < MAX; i++) {
        if (fread(&addr_list[i], sizeof(struct addr), 1, fp) != 1) {
            if (feof(fp))
                break;
            printf("File read error.\n");
        }
    }

    fclose(fp);
}
```

### Why `feof()` is needed

`fread()` returns the same value (less than requested) when:

- the end of the file is reached, **or**
- an error occurs.

So the code checks `feof(fp)` to distinguish between the two.
