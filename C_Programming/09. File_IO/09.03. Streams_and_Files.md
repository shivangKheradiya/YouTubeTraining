# Streams and Files

Before diving into the C file system, it’s important to understand the distinction between **streams** and **files**, because the entire C I/O model is built around this abstraction.

---

## ✅ What Are Streams?

A **stream** is an abstraction provided by the C I/O system. It represents a **flow of data** between your program and some input/output device.

Key idea:

- A stream hides the details of the underlying device.
- Whether you're reading from a keyboard, a file on disk, or even a network device, the interface looks the same.

This abstraction gives C a **consistent, device‑independent I/O model**.

---

## ✅ What Are Files?

In C terminology, a **file** refers to the actual device or resource being accessed:

- A disk file  
- A terminal  
- A printer  
- Any other I/O device  

The file is the **physical or logical data source**, while the stream is the **software interface** your program uses to interact with it.

---

## ✅ Why the Distinction Matters

Understanding how streams and files relate is essential because:

- You always work with **streams** in your code (`FILE *` objects).
- The C library handles the details of mapping those streams to actual **files** or devices.
- This separation allows C programs to be portable and flexible across different systems.
