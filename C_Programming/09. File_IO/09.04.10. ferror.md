# ✅ Using `ferror()`

When you perform input or output on a file, things can go wrong—disks can fill up, files can disappear, or hardware can fail. The C standard library provides the **`ferror()`** function to let you check whether the most recent file operation encountered an error.

---

## 🔹 Prototype

```c
int ferror(FILE *fp);
```

- `fp` must be a valid file pointer.
- The function returns **non‑zero** if an error has occurred.
- It returns **0** if no error is present.

Because each I/O operation updates the stream’s error status, you should call `ferror()` **immediately after** the operation you want to check. Waiting too long risks losing the error information.

---

## ✅ Why `ferror()` Matters

`getc()`, `putc()`, `fread()`, and other I/O functions often return special values (like `EOF`) to indicate either **end‑of‑file** or **an error**. Without `ferror()`, you cannot reliably distinguish between the two.

`ferror()` gives you a precise way to detect whether a failure occurred during reading or writing.

---

## ✅ Example Program: Replacing Tabs with Spaces

The following program demonstrates how to use `ferror()` to check for I/O errors while processing a file. It reads characters from an input file, replaces each tab with the appropriate number of spaces, and writes the result to an output file. After every read or write, it checks for errors.

```c
/* Replace tabs with spaces, with error checking. */
#include <stdio.h>
#include <stdlib.h>

#define TAB_SIZE 8
#define IN  0
#define OUT 1

void err(int e);

int main(int argc, char *argv[])
{
    FILE *in, *out;
    int tab, i;
    char ch;

    if (argc != 3) {
        printf("usage: detab <in> <out>\n");
        exit(1);
    }

    if ((in = fopen(argv[1], "rb")) == NULL) {
        printf("Cannot open %s.\n", argv[1]);
        exit(1);
    }

    if ((out = fopen(argv[2], "wb")) == NULL) {
        printf("Cannot open %s.\n", argv[2]);
        exit(1);
    }

    tab = 0;

    do {
        ch = getc(in);
        if (ferror(in)) err(IN);

        /* If a tab is found, output spaces */
        if (ch == '\t') {
            for (i = tab; i < TAB_SIZE; i++) {
                putc(' ', out);
                if (ferror(out)) err(OUT);
            }
            tab = 0;
        } else {
            putc(ch, out);
            if (ferror(out)) err(OUT);

            tab++;
            if (tab == TAB_SIZE) tab = 0;
            if (ch == '\n' || ch == '\r') tab = 0;
        }

    } while (!feof(in));

    fclose(in);
    fclose(out);
    return 0;
}

void err(int e)
{
    if (e == IN)
        printf("Error on input.\n");
    else
        printf("Error on output.\n");

    exit(1);
}
```

---

## ✅ What This Program Demonstrates

- **`ferror()` is checked after every read and write**, ensuring no error goes unnoticed.
- Tabs are expanded into spaces based on a fixed tab width.
- Both input and output files are opened in **binary mode**, making the program safe for any file type.
- The helper function `err()` prints a message and terminates the program when an error is detected.
