# ✅ Writing a Character to a File

**C provides two equivalent functions for writing a single character to a file: `putc()` and `fputc()`.**  
They behave the same way, and both write exactly one byte to the stream associated with a file pointer.

---

## 📝 `putc()` and `fputc()` — What They Are

C defines two functions for outputting a character:

- **`putc()`** — often implemented as a macro for speed  
- **`fputc()`** — always a real function call  

They exist side‑by‑side mainly for historical reasons. Modern C programs may use either one.

Both functions write a character to a file that has already been opened with `fopen()`.

---

## 🧩 Function Prototype

```c
int putc(int ch, FILE *fp);
```

- **`ch`**: the character to write (passed as an `int`, but only the low‑order byte is used)  
- **`fp`**: a valid file pointer returned by `fopen()`  

The file pointer tells the function exactly which file stream to write to.

---

## ✅ Return Value

- On **success**, `putc()` returns the character that was written.  
- On **failure**, it returns **`EOF`**, indicating a write error.

Typical causes of failure include:

- The file is not open for writing  
- The disk is full  
- The stream has encountered an I/O error  

You can call `ferror(fp)` afterward to determine the specific problem.

---

## 📌 Summary

- **`putc()` and `fputc()` do the same job**—write one character to a file.  
- **Only the low‑order byte of the `int` argument is written.**  
- **They return the written character on success, or `EOF` on error.**
