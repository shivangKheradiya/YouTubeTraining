# Reading Individual Characters with `scanf()`

You can read individual characters in C not only with `getchar()` and related functions, but also using `scanf()` with the `%c` format specifier. However, there are some important differences and caveats you need to understand, especially in interactive programs.

---

## Reading a single character with `%c`

To read a single character using `scanf()`, use the `%c` format specifier:

```c
char ch;
scanf("%c", &ch);
```

- `%c` tells `scanf()` to read exactly **one character**, including whitespace.
- The character is stored directly into `ch`.

Like many implementations of `getchar()`, using `%c` with `scanf()` typically involves **line-buffered input**, meaning the user generally must press Enter before the character is actually processed. This can make `%c` slightly awkward in interactive, character-by-character input scenarios.

---

## How `%c` treats whitespace

Unlike other format specifiers (such as `%d`, `%f`, `%s`), `%c` **does not skip whitespace**.

- Spaces, tabs, and newlines are read as normal characters.
- They are not treated as separators.

For example, with this input stream:

```
x y
```

and this code:

```c
char a, b, c;
scanf("%c%c%c", &a, &b, &c);
```

You get:

- `a` → `'x'`  
- `b` → `' '` (space)  
- `c` → `'y'`

This behavior is often surprising if you're used to `%d` or `%s`, which skip over whitespace automatically.
