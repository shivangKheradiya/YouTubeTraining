# **The `*` and `#` Modifiers**

`printf` supports two additional modifiers—`*` and `#`—that extend the flexibility of formatted output. These modifiers allow you to control prefixes, decimal formatting, and even dynamically supply field width and precision at runtime.

---

## 🔷 **The `#` Modifier**

The `#` flag changes the default formatting behavior of certain specifiers.

### ✅ **For Floating‑Point Formats (`%g`, `%G`, `%f`, `%e`, `%E`)**
Using `#` ensures that a **decimal point is always printed**, even if no fractional digits appear.

Example:

```
%#f  
%#g  
```

### ✅ **For Hexadecimal (`%x`, `%X`)**
Adds a **`0x`** or **`0X`** prefix to the printed value.

Example:

```
%x   → a  
%#x  → 0xa
```

### ✅ **For Octal (`%o`)**
Adds a **leading zero**.

Example:

```
%o   → 12  
%#o  → 012
```

### ✅ **Restrictions**
- `#` cannot be applied to other specifiers.
- In C99, it may also be used with `%a` to ensure a decimal point is shown.

---

## 🔷 **The `*` Modifier**

The `*` modifier allows you to **supply field width and precision dynamically** using arguments passed to `printf`.

Instead of writing:

```
%10.4f
```

You can write:

```
%*.*f
```

And provide the width and precision as arguments:

```c
printf("%*.*f", 10, 4, 1234.34);
```

Here:

- `10` → minimum field width  
- `4` → precision  
- `1234.34` → value to print  

`printf` matches each `*` to the next argument in order.

---

## 📝 **Example Program Using `#` and `*`**

```c
#include <stdio.h>

int main(void)
{
    printf("%x %#x\n", 10, 10);      // normal hex vs. hex with 0x prefix
    printf("%*.*f", 10, 4, 1234.34); // dynamic width and precision

    return 0;
}
```
