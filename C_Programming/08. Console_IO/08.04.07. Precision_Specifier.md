# **The Precision Specifier**

The precision specifier allows you to control the **exactness and detail** of printed output in C. It follows the minimum field width (if present) and begins with a period (`.`) followed by an integer. Its meaning changes depending on the data type being formatted.

---

## 🎯 **How the Precision Specifier Works**

The general form looks like this:

```
%[width].[precision][format]
```

The effect of the precision value depends on the format specifier used.

---

## ✅ **Precision with Floating‑Point Numbers (`%f`, `%e`, `%E`)**

When applied to floating‑point formats, the precision specifier determines the **number of digits after the decimal point**.

Example:

```
%10.4f
```

- Minimum width: 10 characters  
- Decimal places: 4  

```c
printf("%10.4f\n", 123.456789);
```

---

## ✅ **Precision with `%g` and `%G`**

For `%g` and `%G`, the precision value specifies the **number of significant digits**, not decimal places.

```c
printf("%.6g\n", 123.456789);
```

---

## ✅ **Precision with Strings (`%s`)**

When used with strings, the precision specifier sets the **maximum number of characters** to print.

Example:

```
%5.7s
```

- Minimum width: 5  
- Maximum characters printed: 7  
- Longer strings are **truncated**.

```c
printf("%10.15s\n", "This is a simple test.");
```

---

## ✅ **Precision with Integers (`%d`, `%i`, `%u`, etc.)**

For integers, the precision specifier sets the **minimum number of digits** to display.

- If the number has fewer digits, **leading zeros** are added.
- If it has more digits, it prints normally.

Example:

```
%3.8d
```

- Minimum width: 3  
- Minimum digits: 8  
- Output is padded with zeros on the left.

---

## 📝 **Example Program**

```c
#include <stdio.h>

int main(void)
{
    printf("%.4f\n", 123.1234567);
    printf("%3.8d\n", 1000);
    printf("%10.15s\n", "This is a simple test.");

    return 0;
}
```
