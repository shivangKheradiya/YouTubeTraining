# 📘 Formatted Console I/O

C provides two powerful functions for handling **formatted input and output**:

- **`printf()`** — formats and writes data to the console  
- **`scanf()`** — formats and reads data from the keyboard  

These functions allow you to control exactly **how** data is displayed or interpreted, making them essential tools for building interactive programs.

---

## ✅ What Makes Them “Formatted”?

Unlike simple character‑based I/O functions, `printf()` and `scanf()` can:

- Handle **all built‑in data types**  
- Work with **null‑terminated strings**  
- Convert between text and numeric formats  
- Allow you to specify width, precision, alignment, and more  

This gives you complete control over how data is presented to the user and how input is parsed.

---

## ✅ `printf()` — Formatted Output

`printf()` sends formatted text to the console.  
You supply a **format string** that tells C how to display each value.

Example:

```c
printf("Value: %d", 42);
```

---

## ✅ `scanf()` — Formatted Input

`scanf()` reads data from the keyboard and converts it into the types you specify.

Example:

```c
scanf("%d", &number);
```

Because `scanf()` stores data into variables, you must pass **addresses** (using `&`) for most types.

---

## ✅ Why These Functions Matter

Together, `printf()` and `scanf()` form the backbone of console‑based programs in C.  
They allow you to:

- Display numbers, characters, strings, and more  
- Read user input in a controlled, predictable way  
- Build interactive applications  
- Format data for clean, readable output
