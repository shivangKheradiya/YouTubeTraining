# **Displaying Memory Addresses with `%p`**

In this part of the tutorial, we explore how to display memory addresses in C. Understanding how to print addresses is especially useful when learning about pointers, memory layout, and low‑level debugging.

---

## 🧭 **Displaying an Address**

### ✅ **Using `%p`**
To print a memory address, use the `%p` format specifier.  
This tells `printf` to output the address in a machine‑dependent format that matches your system’s addressing style.

```c
printf("%p", pointer_variable);
```

The argument must be a **pointer**, such as the address of a variable (`&variable`).

---

## 📝 **Example Program**

The following program prints the memory address of the global variable `sample`:

```c
#include <stdio.h>

int sample;

int main(void)
{
    printf("%p", &sample);
    return 0;
}
```

When executed, the program displays the address where `sample` is stored in memory.  
The exact output will vary depending on your system and compiler.
