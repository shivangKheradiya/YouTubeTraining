# Using a Scanset with `scanf()`

`scanf()` supports a powerful, general‑purpose input feature called a **scanset**. A scanset lets you define a **set of acceptable characters**, and `scanf()` will keep reading characters as long as they belong to that set.

---

## What a scanset is

A scanset is a special format specifier of the form:

```c
%[characters]
```

- The opening `[` must be preceded by `%`.
- The characters inside the brackets define the **allowed set**.
- Input characters are read **one by one** and stored into a character array, until a character is encountered that is **not** in the set.
- The resulting array is **null‑terminated**, just like a normal C string.

### Example scanset

```c
%[XYZ]
```

This tells `scanf()`:

- “Read characters as long as they are `X`, `Y`, or `Z`.”
- Stop when any other character is encountered.

---

## Example program using a scanset

```c
#include <stdio.h>

int main(void)
{
    int i;
    char str[80], str2[80];

    scanf("%d%[abcdefg]%s", &i, str, str2);
    printf("%d %s %s", i, str, str2);

    return 0;
}
```

### Try this input

Type:

```
123abcdtye
```

and press ENTER.

### What happens

- `%d` reads `123` into `i`.
- `%[abcdefg]` reads characters from the set `{a, b, c, d, e, f, g}`:
  - It reads `a`, `b`, `c`, `d` into `str`.
  - It stops when it sees `t` (because `t` is not in the set).
- `%s` then reads the rest (`tye`) into `str2`.

Output:

```
123 abcd tye
```

---

## Inverted scansets with `^`

You can invert a scanset by starting it with `^`:

```c
%[^abc]
```

This means:

- “Accept any character **except** `a`, `b`, or `c`.”

So `scanf()` keeps reading until it encounters one of the excluded characters.

---

## Ranges and case sensitivity

In most implementations, you can specify ranges using a hyphen:

```c
%[A-Z]
```

- Accepts the characters `A` through `Z`.

Important:

- Scansets are **case sensitive**.
- If you want both upper‑ and lowercase letters, you must specify both:

```c
%[A-Za-z]
```
