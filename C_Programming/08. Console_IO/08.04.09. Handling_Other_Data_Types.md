# **Handling Other Data Types with Format Modifiers**

`printf` provides several **length modifiers** that allow you to correctly format and display different integer and floating‑point types. These modifiers ensure that the data passed to `printf` matches the expected size, especially when working with short, long, or extended‑precision values.

---

## 🧱 **Length Modifiers for Integer Types**

These modifiers can be applied to the integer format specifiers:  
`d`, `i`, `o`, `u`, and `x`.

### ✅ **`l` (ell) — Long Integer**
Indicates that the corresponding argument is of type **long int** or **long unsigned int**.

Examples:

```
%ld   → long int  
%lu   → long unsigned int
```

### ✅ **`h` — Short Integer**
Indicates that the argument is of type **short int** or **short unsigned int**.

Examples:

```
%hd   → short int  
%hu   → short unsigned int
```

### ✅ **Using `l` and `h` with `%n`**
These modifiers can also be applied to `%n`:

- `%ln` → pointer to a long int  
- `%hn` → pointer to a short int  

---

## 🌐 **Wide‑Character Support (Amendment 1 / C95)**

If your compiler supports wide‑character features:

- `%lc` → wide character (`wchar_t`)  
- `%ls` → wide‑character string  

These use the `l` modifier to indicate wide‑character data.

---

## 🧮 **Floating‑Point Length Modifiers**

### ✅ **`L` — Long Double**
Used with floating‑point specifiers `e`, `f`, and `g` to indicate a **long double** argument.

Examples:

```
%Lf  
%Le  
%Lg
```

---

## 🆕 **C99 Additions: `hh` and `ll`**

C99 introduced two additional length modifiers:

### ✅ **`hh` — Signed/Unsigned Char**
Applies to `d`, `i`, `o`, `u`, `x`, or `n`.

- `%hhd` → signed char  
- `%hhu` → unsigned char  
- `%hhn` → pointer to signed char  

### ✅ **`ll` — Long Long Integer**
Also applies to `d`, `i`, `o`, `u`, `x`, or `n`.

- `%lld` → long long int  
- `%llu` → unsigned long long int  
- `%lln` → pointer to long long int  

### ✅ **Note on `l` with Floating‑Point**
C99 allows `l` to prefix `a`, `e`, `f`, and `g`, but **it has no effect**.
