# **Minimum Field Width Specifier**

The minimum field width specifier allows you to control the **minimum number of characters** used when printing values with `printf`. This is especially useful for aligning columns, creating tables, and producing clean, readable output.

---

## 📏 **What Is the Minimum Field Width?**

When you place an integer between the `%` sign and the format code, it tells `printf` to ensure that the output occupies **at least that many characters**.

- If the output is **shorter**, it is padded with spaces (by default).  
- If the output is **longer**, it is printed in full without truncation.

Example:

```
%10d   → minimum width of 10 characters  
```

---

## 🔢 **Padding with Zeros**

If you want to pad the output with **zeros** instead of spaces, place a `0` before the width:

```
%05d   → pads numbers shorter than 5 digits with leading zeros
```

Example:

```c
printf("%05d", 42);   // prints 00042
```

---

## 📝 **Example Program: Field Width with Floating‑Point Numbers**

```c
#include <stdio.h>

int main(void)
{
    double item;
    item = 10.12304;

    printf("%f\n", item);       // default formatting
    printf("%10f\n", item);     // minimum width of 10
    printf("%012f\n", item);    // zero‑padded width of 12

    return 0;
}
```

### ✅ **Sample Output**

```
10.123040
  10.123040
00010.123040
```

## 📊 **Using Field Width to Create Tables**

Minimum field width is extremely useful when printing aligned columns.  
The following program prints a table of numbers, their squares, and their cubes:

```c
#include <stdio.h>

int main(void)
{
    int i;

    /* display a table of squares and cubes */
    for(i = 1; i < 20; i++)
        printf("%8d %8d %8d\n", i, i*i, i*i*i);

    return 0;
}
```
