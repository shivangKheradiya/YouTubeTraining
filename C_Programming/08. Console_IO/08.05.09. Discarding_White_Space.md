# Discarding Unwanted Whitespace with `scanf()`

When using `scanf()`, whitespace handling is built into the way the control string is interpreted. Understanding this behavior is crucial for reading input correctly and avoiding subtle bugs.

---

## How `scanf()` treats whitespace in the control string

Any **whitespace character** that appears in the `scanf()` control string has special meaning. It tells `scanf()` to **skip over leading whitespace characters in the input stream**.

Whitespace characters include:

- Space  
- Tab  
- Vertical tab  
- Formfeed  
- Newline  

---

## What actually happens

When `scanf()` encounters a whitespace character (like a space or newline) in the control string, it will:

- Read, but **not store**, any number of whitespace characters from the input (including zero),
- Stop as soon as it reaches the **first non‑whitespace character**,
- Then continue processing the next format specifier.

In other words, **one whitespace character in the control string absorbs any amount of whitespace in the input**.

### Example

Control string:

```c
scanf("%d %d", &a, &b);
```

Between the two `%d`:

- That single space tells `scanf()`:
  - “Skip any number of spaces, tabs, or newlines before reading the next integer.”

So all of these inputs work the same:

```
10 20
10    20
10
20
```

They all successfully assign `10` to `a` and `20` to `b`.
