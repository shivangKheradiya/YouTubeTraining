# Inputting a Memory Address with `scanf()`

You can use `scanf()` not only to read numbers and strings, but also to input **memory addresses**. This is done with the `%p` format specifier, which is designed specifically for pointer values.

---

## Using `%p` to read an address

The `%p` format specifier tells `scanf()` to read a value as a **pointer**, using whatever address representation is defined by the system’s architecture.

Key points:

- `%p` reads an address from input.
- The corresponding argument to `scanf()` must be a **pointer to a pointer**, because `scanf()` needs to store the read address into your pointer variable.

---

## Example program: Reading and using an address

```c
#include <stdio.h>

int main(void)
{
    char *p;

    printf("Enter an address: ");
    scanf("%p", &p);
    printf("Value at location %p is %c\n", p, *p);

    return 0;
}
```

### How it works

- `p` is a `char *` (pointer to `char`).
- `scanf("%p", &p);` reads an address from input and stores it in `p`.
- `printf("Value at location %p is %c\n", p, *p);`:
  - Prints the address in `p` using `%p`.
  - Dereferences `p` with `*p` and prints the character stored at that memory location.
