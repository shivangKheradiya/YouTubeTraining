# `scanf()` Format Modifiers

Just like `printf()`, `scanf()` allows many of its format specifiers to be **modified**. These modifiers control things like how many characters are read, and what exact data type the input is stored into.

---

## Limiting input with maximum field width

You can specify a **maximum field length** by placing an integer between the `%` and the format specifier. This limits how many characters `scanf()` will read for that field.

```c
scanf("%20s", str);
```

- `%20s` → read **at most 20 characters** into `str`.
- Input stops after 20 characters or when a whitespace is encountered, whichever comes first.

If the input stream contains more characters than the maximum field width, the extra characters remain in the input buffer and will be consumed by the **next** input call.

### Example behavior

If the user types:

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

with:

```c
scanf("%20s", str);
```

- Only the first 20 characters (`A` through `T`) go into `str`.
- The remaining `UVWXYZ` stay in the input stream.
- A subsequent call like:

  ```c
  scanf("%s", str);
  ```

  will then read `UVWXYZ` into `str`.

Also note: if whitespace is encountered before reaching the maximum width, input for that field ends early and `scanf()` moves on to the next field.

## Length modifiers for integers

You can modify integer format codes (`d`, `i`, `o`, `u`, `x`, `n`) to match different integer sizes:

- **`h`** → `short` or `unsigned short`  
- **`l`** (ell) → `long` or `unsigned long`  

Examples:

```c
short s;
long l;

scanf("%hd", &s);   // read a short int
scanf("%ld", &l);   // read a long int
```

These ensure the input is stored in a correctly sized variable.

---

## Length modifiers for floating‑point types

By default, when using `scanf()`:

- `%f`, `%e`, `%g` → read into a **`float *`**  
- With `l` (ell): `%lf`, `%le`, `%lg` → read into a **`double *`**  
- With `L`: `%Lf`, `%Le`, `%Lg` → read into a **`long double *`**

Examples:

```c
float f;
double d;
long double ld;

scanf("%f", &f);     // float
scanf("%lf", &d);    // double
scanf("%Lf", &ld);   // long double
```

---

## Wide-character input with `l` modifier

If your compiler supports the wide-character features from Amendment 1 (1995), you can use `l` with `c`, `s`, and scansets for wide characters:

- `%lc` → pointer to `wchar_t` (single wide character)  
- `%ls` → pointer to `wchar_t` array (wide-character string)  
- `%l[ ... ]` → wide-character scanset

Example:

```c
wchar_t wc;
wchar_t wstr[80];

scanf("%lc", &wc);
scanf("%ls", wstr);
```

---

## C99 additions: `hh` and `ll`

C99 adds two more length modifiers for finer control over integer pointer types in `scanf()`:

- **`hh`** (for `d`, `i`, `o`, `u`, `x`, `n`):  
  - Argument is a **pointer to signed or unsigned `char`**  
  - Example: `scanf("%hhd", &c);` where `c` is a `signed char`

- **`ll`** (for `d`, `i`, `o`, `u`, `x`, `n`):  
  - Argument is a **pointer to signed or unsigned `long long int`**  
  - Example: `scanf("%lld", &llval);` where `llval` is `long long int`

These ensure that `scanf()` writes to the correct-sized integer types, especially on modern systems where `long long` is common.
