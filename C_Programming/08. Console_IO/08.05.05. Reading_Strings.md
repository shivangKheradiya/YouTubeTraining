# Reading Strings with `scanf()`

You can use `scanf()` to read strings from the input stream by using the `%s` format specifier. However, it behaves differently from functions like `gets()` or `fgets()`, especially when it comes to spaces and other whitespace characters.

---

## Using `%s` to read a string

When you use the `%s` specifier, `scanf()`:

- Reads characters from the input stream  
- Stops when it encounters the **first whitespace character**  
- Stores the characters into the target **character array**  
- Automatically appends a **null terminator (`'\0'`)** at the end  

In the context of `scanf()`, **whitespace** includes:

- Space  
- Newline (`\n`)  
- Tab (`\t`)  
- Vertical tab  
- Formfeed  

### Example behavior

Unlike `gets()` (which reads a whole line until ENTER is pressed), `scanf("%s", ...)` stops at the first whitespace. This means you **cannot** directly read a string like `"this is a test"` as a single input using `%s`, because the read will stop at `"this"`.

---

## Example program with `%s`

Try this program and enter the string `"hello there"` when prompted:

```c
#include <stdio.h>

int main(void)
{
    char str[80];

    printf("Enter a string: ");
    scanf("%s", str);
    printf("Here's your string: %s", str);

    return 0;
}
```

### Sample interaction

Input:

```
hello there
```

Output:

```
Enter a string: hello there
Here's your string: hello
```

Only the `"hello"` part is read and stored, because `%s` stops at the first space.
