# 📘 Reading and Writing Strings

Once you understand character‑based input and output, the next step is working with **strings**.  
C provides two simple console I/O functions for this purpose:

- **`gets()`** — reads a string from the keyboard  
- **`puts()`** — writes a string to the screen  

These functions make it easy to handle multi‑character input and output.

---

## ✅ How `gets()` Works

`gets()` reads characters from the keyboard until the user presses **ENTER**.  
It then:

- Stores the characters into the array provided  
- Replaces the ENTER key with a **null terminator (`\0`)**  
- Returns a pointer to the string  

Prototype:

```c
char *gets(char *str);
```

Example:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[80];
    gets(str);
    printf("Length is %d", strlen(str));
    return 0;
}
```

### ⚠️ Important Warning About `gets()`

`gets()` **does not check array boundaries**.  
If the user types more characters than the array can hold, memory will be overwritten — a serious bug.

Because of this, `gets()` is considered unsafe and should be avoided in production code.  
A safer alternative is **`fgets()`**, which lets you specify the maximum number of characters to read.

---

## ✅ How `puts()` Works

`puts()` outputs a string followed by a newline.  
Prototype:

```c
int puts(const char *str);
```

Key points:

- Recognizes escape sequences like `\t`  
- Faster and lighter than `printf()`  
- Ideal when you only need to print a string (no formatting)

Example:

```c
puts("hello");
```

`puts()` returns a non‑negative value on success or `EOF` on error, though console output rarely fails.

---

## ✅ Summary of Basic Console I/O Functions

| Function     | Description |
|--------------|-------------|
| `getchar()`  | Reads one character; usually waits for ENTER |
| `getche()`   | Reads one character with echo; no ENTER needed (non‑standard) |
| `getch()`    | Reads one character without echo; no ENTER needed (non‑standard) |
| `putchar()`  | Writes one character |
| `gets()`     | Reads a string (unsafe — no bounds checking) |
| `puts()`     | Writes a string with newline |

# ✅ Example Program: A Simple Dictionary

The following program demonstrates several console I/O functions.  
It asks the user for a word, searches a small built‑in dictionary, and prints the meaning if found.

```c
/* A simple dictionary. */
#include <stdio.h>
#include <string.h>
#include <ctype.h>

/* list of words and meanings */
char *dic[][40] = {
    "atlas",     "A volume of maps.",
    "car",       "A motorized vehicle.",
    "telephone", "A communication device.",
    "airplane",  "A flying machine.",
    "", ""       /* null terminate the list */
};

int main(void)
{
    char word[80], ch;
    char **p;

    do {
        puts("\nEnter word: ");
        scanf("%s", word);

        p = (char **)dic;

        /* find matching word and print its meaning */
        do {
            if (!strcmp(*p, word)) {
                puts("Meaning:");
                puts(*(p + 1));
                break;
            }
            p = p + 2;  /* advance through the list */
        } while (*p);

        if (!*p)
            puts("Word not in dictionary.");

        printf("Another? (y/n): ");
        scanf(" %c%*c", &ch);

    } while (toupper(ch) != 'N');

    return 0;
}
```

### ✅ What to Notice

- `dic` is an **array of pointers to strings**  
- Each word is followed by its meaning  
- The list ends with two empty strings (`""`, `""`)  
- Input is read using `scanf()`  
- Output uses `puts()` for simplicity
