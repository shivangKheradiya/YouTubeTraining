# 📘 Console I/O

Unlike some programming languages, **C does not provide built‑in keywords for input and output**. Instead, all I/O operations are performed through a powerful and flexible set of **library functions**. This design gives C a highly adaptable I/O system capable of handling data transfer across a wide range of devices.

All standard I/O functions are declared in the header:

```c
#include <stdio.h>
```

C provides two major categories of I/O:

- **Console I/O** — interacting with the keyboard and screen  
- **File I/O** — reading from and writing to files  

Although both systems share many similarities internally, conceptually they serve different purposes.  
This section focuses on **console I/O**, while file I/O is covered separately.

---

## ✅ What Standard C Includes — and What It Doesn’t

Standard C defines only the **basic console I/O functions**. It does **not** include:

- Screen control functions (cursor movement, clearing the screen, colors)  
- Graphics functions  
- Windowing or GUI functions (e.g., Windows dialog boxes)  

These features vary widely across systems, so they are left to compilers and operating systems. Many compilers provide their own extensions for screen control and graphics, but they are **not part of the C language itself**.

---

## ✅ Console I/O vs. Standard Input/Output

Throughout this tutorial, “console I/O” refers to:

- **Input** from the keyboard  
- **Output** to the screen  

However, in reality, C’s I/O functions operate on:

- **Standard Input (stdin)**  
- **Standard Output (stdout)**  

These streams can be **redirected** to files or other devices.  
For simplicity, this chapter assumes no redirection is being used.  
(I/O redirection is covered later in the course.)

---

## ✅ A Note About C++

C++ includes additional I/O features such as:

- `<<` (insertion operator)  
- `>>` (extraction operator)  

These are **not available in C**.  
C relies entirely on its library functions for input and output.
