# Non-Whitespace Characters in the `scanf()` Control String

Besides format specifiers and whitespace, **literal non-whitespace characters** in the `scanf()` control string have a specific and strict meaning. They must be matched exactly in the input stream.

---

## How non-whitespace characters are treated

Any **non-whitespace character** in the control string (that is not part of a format specifier) tells `scanf()` to:

- **Read and discard** that exact character from the input stream.
- If the next character in the input does **not** match, `scanf()` **stops** processing and the input operation fails at that point.

### Example

Control string:

```c
"%d,%d"
```

Behavior:

1. `%d` → read an integer  
2. `,` → read and discard a comma  
3. `%d` → read another integer  

So for this call:

```c
scanf("%d,%d", &a, &b);
```

Valid input would look like:

```
10,20
```

If the comma is missing (e.g., `10 20`), `scanf()` will not match the `,` in the format string and will terminate at that point.

---

## Reading and discarding a percent sign

Because `%` begins a format specifier, you can’t match a literal percent sign directly with `%`.  
Instead, you must write:

```c
%%
```

in the control string to:

- Read and discard a **literal `%`** from the input.

Example:

```c
scanf("%d%%d", &a, &b);
```

expects input like:

```
10%20
```
