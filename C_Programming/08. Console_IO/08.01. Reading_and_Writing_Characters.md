# 📘 Reading and Writing Characters

When working with console input and output, the two simplest functions you’ll encounter are:

- **`getchar()`** — reads a single character from the keyboard  
- **`putchar()`** — writes a single character to the screen  

These functions form the foundation of character‑based I/O in C.

---

## ✅ How `getchar()` Works

`getchar()` waits for the user to press a key and then returns the character that was typed.  
The character is also automatically echoed to the screen.

Prototype:

```c
int getchar(void);
```

Although `getchar()` returns an **int**, you can safely store the result in a `char` variable because the actual character is stored in the low‑order byte. The function returns **EOF** (usually –1) if an error occurs or if the end of input is reached.

---

## ✅ How `putchar()` Works

`putchar()` outputs a single character to the screen at the current cursor position.

Prototype:

```c
int putchar(int c);
```

Even though it accepts an integer argument, only the low‑order byte is printed.  
`putchar()` returns the character written, or **EOF** if an error occurs.

---

## ✅ Example Program: Reverse the Case of Input Characters

The following program demonstrates both functions.  
It reads characters from the keyboard and prints them back with reversed case:

- lowercase → uppercase  
- uppercase → lowercase  

The program stops when the user enters a period (`.`).

```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    char ch;

    printf("Enter some text (type a period to quit).\n");

    do {
        ch = getchar();

        if (islower(ch))
            ch = toupper(ch);
        else
            ch = tolower(ch);

        putchar(ch);

    } while (ch != '.');

    return 0;
}
```
