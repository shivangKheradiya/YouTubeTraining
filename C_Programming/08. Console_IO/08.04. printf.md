# 📘 `printf()` — Formatted Output

The `printf()` function is one of the most important tools in C programming. It allows you to display text, numbers, characters, and other data types in a **formatted** and controlled way.

Prototype:

```c
int printf(const char *control_string, ...);
```

`printf()` returns:

- ✅ The number of characters successfully written  
- ❌ A negative value if an error occurs  

---

## ✅ How `printf()` Works

The **control string** passed to `printf()` contains two types of elements:

### **1. Literal characters**
These are printed exactly as they appear.

### **2. Format specifiers**
These begin with `%` and tell `printf()` how to display the corresponding argument.

Example:

```c
printf("I like %c %s", 'C', "very much!");
```

Output:

```
I like C very much!
```

Here:

- `%c` → prints the character `'C'`
- `%s` → prints the string `"very much!"`

The number of format specifiers **must match** the number of arguments, and they are processed **from left to right**.

---

## ✅ Common `printf()` Format Specifiers

Below is a clean, modern summary of the most widely used format codes:

| Code | Meaning |
|------|---------|
| `%a` | Hexadecimal floating‑point (C99) |
| `%A` | Hexadecimal floating‑point (uppercase, C99) |
| `%c` | Character |
| `%d` | Signed decimal integer |
| `%i` | Signed decimal integer (same as `%d`) |
| `%e` | Scientific notation (lowercase `e`) |
| `%E` | Scientific notation (uppercase `E`) |
| `%f` | Decimal floating‑point |
| `%g` | Uses `%e` or `%f`, whichever is shorter |
| `%G` | Uses `%E` or `%F`, whichever is shorter |
| `%o` | Unsigned octal |
| `%s` | String |
| `%u` | Unsigned decimal integer |
| `%x` | Unsigned hexadecimal (lowercase) |
| `%X` | Unsigned hexadecimal (uppercase) |
| `%p` | Pointer address |
| `%n` | Stores number of characters printed so far into an integer pointer |
| `%%` | Prints a literal `%` sign |

These specifiers give you precise control over how data appears on the screen.
