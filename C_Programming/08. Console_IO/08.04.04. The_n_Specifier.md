# **Using the `%n` Format Specifier**

In this part of the tutorial, we explore one of the most unusual and lesser‑known features of `printf` in C: the `%n` format specifier. Unlike other specifiers, `%n` does **not** print anything. Instead, it provides a way to track how many characters have been output up to a certain point.

---

## 🧩 **What `%n` Does**

### ✅ **Stores the Number of Characters Printed**
The `%n` format specifier tells `printf` to store the number of characters printed so far into an integer variable.  
Because `%n` writes to a variable, its corresponding argument **must be a pointer to an integer**.

```c
printf("text%n", &variable);
```

After the call to `printf`, the variable will contain the count of characters printed before `%n` was encountered.

---

## 📝 **Example Program**

```c
#include <stdio.h>

int main(void)
{
    int count;

    printf("this%n is a test\n", &count);
    printf("%d", count);

    return 0;
}
```

### ✅ **Explanation**
- The string `"this"` contains **4 characters**.
- When `%n` is reached, `printf` stores the value **4** into `count`.
- The second `printf` prints the value of `count`.

### ✅ **Sample Output**

```
this is a test
4
```

---

## 🎯 **When to Use `%n`**

The `%n` specifier is mainly used for **dynamic formatting**, such as:
- Aligning text based on runtime conditions  
- Tracking output length for custom formatting logic  
- Implementing advanced console UI behaviors  

Although not commonly used in everyday C programming, it’s a powerful tool when precise control over output formatting is required.
