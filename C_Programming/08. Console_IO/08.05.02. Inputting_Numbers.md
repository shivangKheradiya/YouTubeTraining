# **Inputting Numbers with `scanf()`**

`scanf()` provides flexible ways to read numeric input in various formats, including decimal, octal, hexadecimal, and floating‑point values. Understanding how each format specifier works ensures that your program reads user input correctly and safely.

---

## 🔢 **Reading Integer Values**

### ✅ **Decimal Integers**
Use either `%d` or `%i` to read an integer.

- `%d` → reads a **decimal** integer  
- `%i` → reads an integer in **decimal, octal, or hexadecimal**, depending on the input format  

Examples:

```c
scanf("%d", &x);   // decimal only
scanf("%i", &x);   // auto-detects base
```

---

## 🌊 **Reading Floating‑Point Numbers**

To read floating‑point values in standard or scientific notation, use:

- `%f`  
- `%e`  
- `%g`  

C99 also adds:

- `%a` → reads a floating‑point number in hexadecimal notation

Example:

```c
scanf("%f", &value);
```

---

## 🧮 **Reading Octal and Hexadecimal Integers**

You can read numbers in different bases using:

- `%o` → octal input  
- `%x` → hexadecimal input (uppercase or lowercase letters allowed)

Example program:

```c
#include <stdio.h>

int main(void)
{
    int i, j;

    scanf("%o%x", &i, &j);   // read octal into i, hex into j
    printf("%o %x", i, j);   // print them back out

    return 0;
}
```

This allows input such as:

```
17   (octal)
1A   (hexadecimal)
```

---

## 📘 **Common `scanf()` Format Specifiers**

| Code | Meaning |
|------|---------|
| `%a` | Reads a floating‑point value (C99 only) |
| `%c` | Reads a single character |
| `%d` | Reads a decimal integer |
| `%i` | Reads an integer in decimal, octal, or hexadecimal |
| `%e` | Reads a floating‑point number |
| `%f` | Reads a floating‑point number |
| `%g` | Reads a floating‑point number |
| `%o` | Reads an octal number |
| `%s` | Reads a string |
| `%x` | Reads a hexadecimal number |
| `%p` | Reads a pointer |
| `%n` | Stores the number of characters read so far |
| `%u` | Reads an unsigned decimal integer |
| `%[ ]` | Scans for a set of characters |
| `%%` | Reads a literal percent sign |

---

## ⛔ **When `scanf()` Stops Reading**

`scanf()` stops reading a number **as soon as it encounters a non‑numeric character**.

Examples:

- Input: `123abc`  
  - `%d` reads: `123`  
  - Stops at: `a`

This behavior is important when validating user input.
