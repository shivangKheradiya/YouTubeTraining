# **`scanf()` Input Function**

`scanf()` is C’s general‑purpose console input routine. It can read all built‑in data types and automatically convert textual input into the appropriate internal format. In many ways, it acts as the **reverse of `printf()`**, which formats output.

---

## 📥 **What `scanf()` Does**

`scanf()` reads input from the standard input stream (usually the keyboard), interprets it according to a **control string**, and stores the resulting values into variables provided as arguments.

### ✅ **Function Prototype**

```c
int scanf(const char *control_string, ...);
```

### ✅ **Return Value**

- Returns the **number of input items successfully assigned**.
- Returns **EOF** if an input failure or error occurs.

This makes it useful for validating user input.

---

## 🧭 **How the Control String Works**

The `control_string` determines how input is parsed and stored. It consists of three types of characters:

### ✅ **1. Format Specifiers**
These tell `scanf()` what type of data to read and how to interpret it.

Examples:
- `%d` → integer  
- `%f` → floating‑point  
- `%s` → string  

Each specifier corresponds to a variable in the argument list, and **each variable must be passed by address** (e.g., `&x`).

---

### ✅ **2. White‑Space Characters**
Spaces, tabs, and newlines in the control string cause `scanf()` to skip any amount of whitespace in the input.

This means:
- `" %d"` and `"%d"` behave the same  
- `scanf()` ignores extra spaces, tabs, and line breaks  

---

### ✅ **3. Non‑White‑Space Characters**
Any non‑whitespace character in the control string must **match exactly** in the input.

Example:

```c
scanf("%d-%d", &a, &b);
```

The user must enter something like:

```
10-20
```

The hyphen must be present.
