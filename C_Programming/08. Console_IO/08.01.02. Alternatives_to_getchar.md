# 📘 Alternatives to `getchar()`

Because `getchar()` is often implemented using **line‑buffered input**, it may not behave well in interactive programs. Many compilers require the user to press **ENTER** before `getchar()` returns a character, which makes real‑time input difficult.

To solve this, most C compilers provide additional **non‑standard** functions that allow immediate, character‑by‑character input. These functions are not part of Standard C, but they are widely supported and commonly used.

---

## ✅ `getch()` and `getche()`

Two of the most popular alternatives are:

```c
int getch(void);
int getche(void);
```

These functions are typically declared in:

```c
#include <conio.h>
```

Some compilers—such as Microsoft Visual C++—prefix them with an underscore:

- `_getch()`
- `_getche()`

---

## ✅ How They Work

### **`getch()`**
- Waits for a keypress  
- Returns the character **immediately**  
- **Does not echo** the character to the screen  

### **`getche()`**
- Same as `getch()`  
- **Echoes** the character to the screen  

These functions are ideal for interactive programs where you want instant input without waiting for ENTER.

---

## ✅ Example: Using `getch()` Instead of `getchar()`

Here is the earlier case‑reversal program rewritten using `getch()`:

```c
#include <stdio.h>
#include <conio.h>
#include <ctype.h>

int main(void)
{
    char ch;

    printf("Enter some text (type a period to quit).\n");

    do {
        ch = getch();

        if (islower(ch))
            ch = toupper(ch);
        else
            ch = tolower(ch);

        putchar(ch);

    } while (ch != '.');

    return 0;
}
```

### ✅ What changes?

- Input is **no longer line‑buffered**  
- Each keypress is processed instantly  
- Characters appear on the screen in reverse case as soon as you press them  

---

## ⚠️ Important Note for Visual C++ Users

In some versions of Microsoft Visual C++:

- `_getch()` and `_getche()` **do not work correctly** with standard input functions like `scanf()` or `gets()`  
- You must use special versions such as `cscanf()` or `cgets()`  

Always check your compiler’s documentation if you mix these functions.
