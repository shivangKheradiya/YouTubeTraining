# **Inputting Unsigned Integers**

To read unsigned integer values from user input, `scanf()` provides a dedicated format specifier. This ensures that the input is interpreted correctly and stored as a non‑negative integer.

---

## 🔢 **Using `%u` for Unsigned Integers**

To input an **unsigned integer**, use the `%u` format specifier.  
This tells `scanf()` to read the value as an **unsigned decimal number** and store it in an `unsigned int` variable.

### ✅ **Example**

```c
unsigned num;
scanf("%u", &num);
```

- The user enters an unsigned number  
- `scanf()` converts it  
- The value is stored in `num`

Because `num` is unsigned, it can only hold **zero or positive values**, and it has a larger upper range than a signed integer.
