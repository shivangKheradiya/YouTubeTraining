# **Justifying Output**

By default, `printf` right‑justifies all output. This means that when the field width is wider than the value being printed, the output is aligned to the **right edge** of the field. However, C also allows you to left‑justify output using a simple formatting flag.

---

## ↔️ **Right vs. Left Justification**

### ✅ **Right Justification (Default)**  
If the field width is larger than the data, `printf` pads the **left side** with spaces so the value appears on the right.

Example:

```
%8d   → right‑justified in an 8‑character field
```

### ✅ **Left Justification (`-` flag)**  
To left‑justify output, place a **minus sign (`-`)** immediately after the `%`.

Example:

```
%-10.2f
```

- Left‑justified  
- Width: 10 characters  
- Precision: 2 decimal places  

This forces the value to align to the **left edge** of the field.

---

## 📝 **Example Program**

```c
#include <stdio.h>

int main(void)
{
    printf(".........................\n");
    printf("right-justified: %8d\n", 100);
    printf(" left-justified: %-8d\n", 100);

    return 0;
}
```

---

## ✅ **Sample Output**

```
.........................  
right-justified:      100  
 left-justified: 100     
```

The dotted line helps visualize how the values align within their fields.
