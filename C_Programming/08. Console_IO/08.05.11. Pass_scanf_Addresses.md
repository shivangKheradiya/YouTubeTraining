# You Must Pass Addresses to `scanf()`

Every variable that receives a value from `scanf()` must be passed **by address**. This is essential because `scanf()` needs to **write directly into the variable’s memory location**, and in C that is done using pointers.

---

## Why `scanf()` needs addresses

C uses **call by value** by default, meaning functions get copies of argument values. To let a function modify a variable, you must pass its **address** (a pointer). `scanf()` uses this mechanism to store the input into your variables.

So, instead of passing the variable itself, you pass:

- `&variable` for scalars (like `int`, `float`, etc.)
- The **array name** for strings, which already behaves like a pointer

---

## Example: Reading an integer

To read an integer into the variable `count`, you write:

```c
int count;
scanf("%d", &count);
```

- `%d` tells `scanf()` to read an integer.
- `&count` is the **address** of `count`, where the result will be stored.

Forgetting the `&` here is a very common and serious mistake.

---

## Example: Reading a string into a character array

Strings are stored in **character arrays**, and the array name (without an index) is already the address of its first element.

```c
char str[80];
scanf("%s", str);
```

- `%s` reads a string up to the first whitespace.
- `str` is already a pointer to `str[0]`, so you **do not** use `&str` here.

If you wrote `&str`, you’d be passing the address of the array object itself (a different type), which is incorrect for `scanf("%s", ...)`.
