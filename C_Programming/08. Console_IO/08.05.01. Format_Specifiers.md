# **`scanf()` Format Specifiers**

Format specifiers tell `scanf()` **what type of data to read next**. Each specifier begins with a `%` sign and corresponds to a variable in the argument list. As `scanf()` processes the control string from **left to right**, each format specifier is matched with the next argument provided.

---

## 🎯 **What Format Specifiers Do**

Format specifiers define:

- **The type of input expected** (integer, float, character, string, etc.)
- **How the input should be interpreted and stored**
- **Which variable receives the value**

Every variable passed to `scanf()` must be provided **by address** (e.g., `&x`), so the function can store the input directly into memory.

---

## ✅ **Common `scanf()` Format Specifiers**

Although your table (Table 8‑3) lists them in detail, here are the most frequently used ones:

| Specifier | Meaning |
|----------|---------|
| `%d` | Read an integer |
| `%f` | Read a floating‑point number |
| `%lf` | Read a double |
| `%c` | Read a single character |
| `%s` | Read a string (stops at whitespace) |
| `%u` | Read an unsigned integer |
| `%x` / `%o` | Read hexadecimal / octal input |

These specifiers appear in the control string in the same order as the variables in the argument list.

---

## 🧪 **How Matching Works**

Given this call:

```c
scanf("%d %f %s", &i, &x, name);
```

`scanf()` will:

1. Read an integer → store in `i`  
2. Read a floating‑point value → store in `x`  
3. Read a string → store in `name`  

Each specifier consumes exactly the type of input it expects.
