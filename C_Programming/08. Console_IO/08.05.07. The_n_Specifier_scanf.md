# The `%n` Specifier in `scanf()`

The `%n` format specifier in `scanf()` is different from the others because it doesn’t read new input; instead, it **reports how much has already been read**.

---

## What `%n` Does in `scanf()`

The `%n` specifier tells `scanf()` to:

- Store the **number of characters read so far** from the input stream  
- into the **integer variable pointed to** by the corresponding argument  
- counting characters **up to the point where `%n` appears** in the format string

### Example conceptually

```c
int count;
scanf("%d%n", &value, &count);
```

- `%d` reads an integer from input.  
- `%n` then stores into `count` the number of characters successfully read so far (including digits, signs, etc., but not characters still left in the input).

`%n` doesn’t consume any additional characters; it just records how many have already been processed by this `scanf()` call.
