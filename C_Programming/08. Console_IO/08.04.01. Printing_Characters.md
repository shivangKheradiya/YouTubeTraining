# **C Programming Tutorial – Printing Characters and Strings**

Welcome to this tutorial!  
In this video, we explore one of the most fundamental concepts in C programming: **printing characters and strings using the `printf` function**. Whether you're a beginner or brushing up on the basics, this guide will help you understand how formatted output works in C.

---

## 📝 **Key Concepts Covered**

### ✅ **Printing a Character**
To print a single character in C, use the `%c` format specifier.  
This tells `printf` to output the character exactly as it is.

```c
char letter = 'A';
printf("The character is: %c\n", letter);
```

### ✅ **Printing a String**
To print a sequence of characters (a string), use `%s`.

```c
char name[] = "Alice";
printf("Hello, %s!\n", name);
```

---

## 📂 **Example Program**

```c
#include <stdio.h>

int main() {
    char ch = 'X';
    char word[] = "Hello";

    printf("Character: %c\n", ch);
    printf("String: %s\n", word);

    return 0;
}
```
