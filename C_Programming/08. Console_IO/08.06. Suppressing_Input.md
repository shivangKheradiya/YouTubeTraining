# Suppressing Input with `scanf()`

Sometimes you want `scanf()` to **read** certain characters or fields from the input stream, but **not store** them in any variable. This is where **assignment suppression** comes in.

---

## Using `*` to skip fields

If you place an `*` **immediately after `%`** in a format specifier, `scanf()` will:

- Read and consume the input that matches that specifier,
- But **not assign** it to any argument,
- And you do **not** provide a corresponding variable for that field.

This is called **assignment suppression**.

### Example

```c
scanf("%d%*c%d", &x, &y);
```

Here:

- `%d` → reads an integer and stores it in `x`
- `%*c` → reads a single character but **does not store it** (no argument is provided)
- `%d` → reads another integer and stores it in `y`

If the user enters:

```
10,10
```

Then:

- `10` is read into `x`
- `,` (the comma) is read by `%*c` and discarded
- The second `10` is read into `y`

---

## When suppression is useful

Assignment suppression is especially helpful when:

- The input contains **separators** (like commas, slashes, or other characters) that you don’t care to store.
- You need to **skip over fields** you don’t need while still consuming them from the input stream.

It lets you precisely control how much of the input is consumed without cluttering your code with temporary variables.
