# **Printing Numbers**

This section of the tutorial explores how to print different types of numbers in C using the `printf` function. You’ll learn how format specifiers control the way integers, floating‑point values, and hexadecimal or octal numbers are displayed.

---

## 🔢 **Printing Integers**

### ✅ **Signed Integers: `%d` and `%i`**
You can print a signed integer in decimal format using either `%d` or `%i`.  
Both specifiers behave the same in `printf` and exist mainly for historical compatibility with `scanf`.

```c
int value = -42;
printf("Value: %d\n", value);
printf("Value: %i\n", value);
```

### ✅ **Unsigned Integers: `%u`**
To print an unsigned integer, use `%u`.

```c
unsigned int count = 300;
printf("Count: %u\n", count);
```

---

## 🌊 **Printing Floating‑Point Numbers**

### ✅ **Standard Floating‑Point: `%f`**
`%f` prints floating‑point values in decimal notation.  
The argument must be of type `double`.

```c
double pi = 3.14159;
printf("Pi: %f\n", pi);
```

### ✅ **Scientific Notation: `%e` and `%E`**
Use `%e` or `%E` to display numbers in scientific notation.

General form:

```
x.dddddE±yy
```

- `%e` → lowercase `e`
- `%E` → uppercase `E`

```c
double num = 12345.678;
printf("%e\n", num);
printf("%E\n", num);
```

---

## 🔀 **Automatic Format Selection: `%g` and `%G`**

`%g` and `%G` allow `printf` to choose between `%f` and `%e`, selecting whichever produces the shorter output.

- `%g` → lowercase scientific notation when needed  
- `%G` → uppercase scientific notation when needed  

### ✅ **Example Program**

```c
#include <stdio.h>

int main(void)
{
    double f;
    for(f = 1.0; f < 1.0e+10; f = f * 10)
        printf("%g ", f);

    return 0;
}
```

### ✅ **Sample Output**

```
1 10 100 1000 10000 100000 1e+006 1e+007 1e+008 1e+009
```

## 🧮 **Printing Octal and Hexadecimal Numbers**

You can print unsigned integers in different bases using:

| Format | Meaning |
|--------|---------|
| `%o`   | Octal (base 8) |
| `%x`   | Hexadecimal (lowercase a–f) |
| `%X`   | Hexadecimal (uppercase A–F) |

### ✅ **Example Program**

```c
#include <stdio.h>

int main(void)
{
    unsigned num;

    for(num = 0; num < 16; num++) {
        printf("%o ", num);   // octal
        printf("%x ", num);   // hex lowercase
        printf("%X\n", num);  // hex uppercase
    }

    return 0;
}
```
