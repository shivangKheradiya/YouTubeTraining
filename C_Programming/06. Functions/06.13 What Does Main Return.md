# What Does `main()` Return?

In C, the `main()` function returns an integer value to the calling process—typically the operating system. This return value serves as the program’s exit status.

Returning a value from `main()` is functionally equivalent to calling `exit()` with the same value. A return value of **0** traditionally indicates successful program completion, while non‑zero values signal various error conditions.

If `main()` does not explicitly return a value, the result passed back to the operating system is technically **undefined**. Although many compilers implicitly return 0 in this situation, relying on this behavior reduces portability and is considered poor practice.

To ensure predictable and portable behavior, always include an explicit `return` statement in `main()`.
