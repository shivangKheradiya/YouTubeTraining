# Declaring Variable‑Length Parameter Lists

C allows you to define functions that accept a **variable number of arguments**. The most familiar example is the standard library function `printf()`, which can take a format string followed by any number of additional values.

To declare a function that accepts a variable number of parameters, you end its parameter list with **three periods**, known as an *ellipsis (`...`)*.

## Example: Declaring a Variadic Function

The following prototype specifies that `func()` requires **at least two integer arguments**, followed by zero or more additional arguments:

```c
int func(int a, int b, ...);
```

This same syntax is used in the function’s definition.

## Requirement: At Least One Fixed Parameter

A variadic function must have **at least one fixed (named) parameter**.  
A declaration like the following is illegal:

```c
int func(...);   /* illegal */
```

At least one named parameter is required so the function has a known starting point for accessing the variable arguments.
