# Calling Functions with Arrays

This section explains how arrays behave when passed to functions in C and why they represent an exception to the standard call‑by‑value mechanism.

## Arrays as Function Arguments

Although C normally uses **call by value**, arrays behave differently.  
When an array is passed to a function:

- **The address of the first element** is passed, not a copy of the entire array.
- The function receives a pointer to the original array.
- Any modifications made inside the function affect the **actual array** used in the call.

This makes array arguments behave like **call by reference**.

## Example: Modifying an Array in a Function

The following program demonstrates how passing an array allows a function to modify its contents. The function `print_upper()` converts a string to uppercase:

```c
#include <stdio.h>
#include <ctype.h>

void print_upper(char *string);

int main(void)
{
    char s[80];
    printf("Enter a string: ");
    gets(s);
    print_upper(s);
    printf("\ns is now uppercase: %s", s);
    return 0;
}

/* Print a string in uppercase. */
void print_upper(char *string)
{
    register int t;
    for (t = 0; string[t]; ++t) {
        string[t] = toupper(string[t]);
        putchar(string[t]);
    }
}
```

### Sample Output

```
Enter a string: This is a test.
THIS IS A TEST.
s is now uppercase: THIS IS A TEST.
```

Because the function modifies the array directly, the original string in `main()` is changed.

## Preventing Modification of the Original Array

If you want to print the string in uppercase **without altering the original**, simply avoid writing back into the array:

```c
#include <stdio.h>
#include <ctype.h>

void print_upper(char *string);

int main(void)
{
    char s[80];
    printf("Enter a string: ");
    gets(s);
    print_upper(s);
    printf("\ns is unchanged: %s", s);
    return 0;
}

void print_upper(char *string)
{
    register int t;
    for (t = 0; string[t]; ++t)
        putchar(toupper(string[t]));
}
```

### Sample Output

```
Enter a string: This is a test.
THIS IS A TEST.
s is unchanged: This is a test.
```

Here, the array remains unchanged because the function only reads from it.

## Example: A Simple Version of `gets()`

The standard library function `gets()` is a classic example of passing an array to a function.  
Below is a simplified version called `xgets()`:

```c
/* A simple version of the standard gets() library function. */
char *xgets(char *s)
{
    char ch, *p;
    int t;

    p = s;  /* gets() returns a pointer to s */

    for (t = 0; t < 80; ++t) {
        ch = getchar();
        switch (ch) {
            case '\n':
                s[t] = '\0';  /* terminate the string */
                return p;
            case '\b':
                if (t > 0) t--;
                break;
            default:
                s[t] = ch;
        }
    }

    s[79] = '\0';
    return p;
}
```

### How `xgets()` Works

- It must be called with a `char *`, typically the name of a character array.
- It reads up to 80 characters from the keyboard.
- Backspace reduces the index, effectively deleting the previous character.
- Pressing ENTER inserts a null terminator to end the string.
- Because the array is modified directly, it contains the characters typed by the user when the function returns.

### Important Note

C does **not** perform automatic bounds checking.  
Any array passed to `xgets()` must be large enough to hold at least 80 characters.
