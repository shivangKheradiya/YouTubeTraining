# Standard Library Function Prototypes

Any standard library function used in your program must be properly prototyped. This is accomplished by including the appropriate **header file** for each library function you intend to use. All required headers are supplied by the C compiler.

In C, standard library headers typically use the **`.h`** extension. Each header file contains:

- **Definitions** used by the library functions  
- **Function prototypes** for all functions provided by that library  

For example, the header `<stdio.h>` appears in most programs because it contains the prototype for `printf()` and other standard input/output functions.

A complete list and description of the standard library headers is provided in Part Two of the book.
