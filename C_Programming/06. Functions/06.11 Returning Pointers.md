# Returning Pointers

Functions in C can return pointers just as they return any other type of value. However, because pointers represent **memory addresses** rather than numeric values, it is important to understand how pointer return types work and why they must be declared carefully.

## Understanding Pointer Return Types

A pointer is not an integer—it is an address that refers to a specific type of data. This distinction matters because:

- **Pointer arithmetic depends on the base type.**  
  For example, incrementing an `int *` typically increases its value by 4 bytes (on systems where `int` is 4 bytes), moving it to the next integer in memory.

- **Different data types have different sizes.**  
  The compiler must know the pointer’s base type to perform correct arithmetic and dereferencing.

Because of this, a function that returns a pointer must specify **exactly what type of pointer** it returns.  
For example:

- Returning a `char *` from a function declared as `int *` is incorrect.
- If a function must return a generic pointer, it should use the type `void *`.

## Declaring a Function That Returns a Pointer

To return a pointer, declare the function with a pointer return type.  
The following example returns a pointer to the first occurrence of character `c` in string `s`. If the character is not found, it returns a pointer to the string’s null terminator.

```c
/* Return pointer to first occurrence of c in s. */
char *match(char c, char *s)
{
    while (c != *s && *s)
        s++;
    return s;
}
```

## Example Program Using `match()`

```c
#include <stdio.h>

char *match(char c, char *s);  /* prototype */

int main(void)
{
    char s[80], *p, ch;

    gets(s);
    ch = getchar();

    p = match(ch, s);

    if (*p)   /* match found */
        printf("%s", p);
    else
        printf("No match found.");

    return 0;
}
```

### How the Program Works

1. The user enters a string.
2. The user enters a character.
3. `match()` searches the string for the character.
4. If the character is found:
   - `p` points to the first occurrence.
   - Printing `p` displays the substring starting at the match.
5. If the character is not found:
   - `p` points to the null terminator.
   - `*p` evaluates to false, and the program prints *No match found.*
