# Function Arguments

This section explains how functions receive arguments in C and how parameters behave within a function.

## Declaring Function Parameters

When a function is designed to accept arguments, it must declare **parameters** to receive the values passed to it. These parameter declarations appear immediately after the function name in the function header.

### Example

```c
/* Return 1 if c is part of string s; 0 otherwise. */
int is_in(char *s, char c)
{
    while (*s)
        if (*s == c) return 1;
        else s++;
    return 0;
}
```

In this example, the function `is_in()` has two parameters:

- `s` — a pointer to a character (representing a string)
- `c` — a character to search for

The function returns `1` if the character `c` appears anywhere in the string `s`; otherwise, it returns `0`.

## Behavior of Parameters

Although parameters serve the special purpose of receiving argument values, they behave exactly like **local variables** within the function:

- You may assign new values to them.
- You may use them in expressions.
- Their lifetime begins when the function is called and ends when the function returns.

Parameters are simply initialized local variables whose initial values come from the arguments supplied by the caller.
