# Returning from a Function

A function in C can terminate and return control to its caller in two primary ways. Understanding these mechanisms is essential for writing clear, efficient, and predictable code.

## 1. Returning at the End of the Function

A function naturally returns when execution reaches its final statement and the closing brace (`}`) is conceptually encountered. Although the brace does not exist in the compiled object code, you can think of it as the implicit return point.

### Example: Reversing a String

The following program prints the string `"I like C"` in reverse and then returns to `main()`:

```c
#include <string.h>
#include <stdio.h>

void pr_reverse(char *s);

int main(void)
{
    pr_reverse("I like C");
    return 0;
}

void pr_reverse(char *s)
{
    register int t;
    for (t = strlen(s) - 1; t >= 0; t--)
        putchar(s[t]);
}
```

Once the loop finishes printing the characters in reverse order, the function has nothing left to do and simply returns to its caller.

## 2. Returning Explicitly with `return`

Most functions do not rely solely on reaching the end of their body. Instead, they use the `return` statement to:

- Exit early  
- Return a value  
- Simplify logic  
- Improve readability and efficiency  

A function may contain multiple `return` statements if doing so makes the code clearer.

### Example: Finding a Substring

The following program searches for a substring within a string. It returns the starting index of the first match or `-1` if no match is found. Two `return` statements are used to simplify the logic.

```c
#include <stdio.h>

int find_substr(char *s1, char *s2);

int main(void)
{
    if (find_substr("C is fun", "is") != -1)
        printf("Substring is found.");
    return 0;
}

/* Return index of first match of s2 in s1. */
int find_substr(char *s1, char *s2)
{
    register int t;
    char *p, *p2;

    for (t = 0; s1[t]; t++) {
        p = &s1[t];
        p2 = s2;

        while (*p2 && *p2 == *p) {
            p++;
            p2++;
        }

        if (!*p2)
            return t;   /* First return: match found */
    }

    return -1;          /* Second return: no match */
}
```

In this example:

- The first `return` exits immediately when a match is found.
- The second `return` handles the case where the loop finishes without finding a match.
