# General Form of a Function

A function in C follows the structure:

```
ret-type function-name(parameter-list)
{
    body of the function
}
```

- **ret-type** specifies the type of data the function returns.  
  A function may return any data type *except an array*.
- **function-name** is the identifier used to call the function.
- **parameter-list** is a comma‑separated list of parameters, each with an associated type and name.

## Parameter List Rules

- Each parameter must include both a **type** and a **variable name**.
- Parameters receive the values of the arguments supplied during a function call.
- A function may have **no parameters**. In this case:
  - The parameter list is empty, or  
  - The keyword `void` may be used explicitly to indicate no parameters.

### Important Distinction

In variable declarations, multiple variables of the same type may be declared using a comma‑separated list:

```c
int a, b, c;
```

However, **function parameters cannot share a type specifier**.  
Each parameter must explicitly declare its own type.

### Correct vs. Incorrect Parameter Declarations

```c
f(int i, int k, int j);     /* correct */
f(int i, k, float j);       /* incorrect: 'k' must have its own type */
```
