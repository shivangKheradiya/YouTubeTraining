# Call by Value and Call by Reference

This section explains the two primary methods of passing arguments to subroutines in programming languages, and how C specifically handles argument passing.

## Methods of Passing Arguments

### Call by Value

In **call by value**, the value of an argument is **copied** into the function’s formal parameter.  
Because the function receives only a copy:

- Any modification to the parameter **does not affect** the original argument.
- The caller’s variable remains unchanged after the function returns.

### Call by Reference

In **call by reference**, the **address** of the argument is passed to the function.  
Inside the function:

- The parameter refers directly to the original argument.
- Any modification to the parameter **affects the actual argument** used in the call.

## How C Passes Arguments

C uses **call by value** for all function arguments. This means:

- A function receives copies of the argument values.
- Code inside the function cannot modify the original variables used in the call.
- To simulate call by reference, pointers must be used explicitly.

## Example: Demonstrating Call by Value in C

```c
#include <stdio.h>

int sqr(int x);

int main(void)
{
    int t = 10;
    printf("%d %d", sqr(t), t);
    return 0;
}

int sqr(int x)
{
    x = x * x;
    return x;
}
```

### Explanation

- The value `10` is passed to `sqr()`, and a **copy** is stored in the parameter `x`.
- The assignment `x = x * x` modifies only the **local** variable `x`.
- The original variable `t` in `main()` remains unchanged.

**Output:**

```
100 10
```

This illustrates the key rule:  
**A function receives a copy of each argument. Changes inside the function do not affect the original variable.**
