# Returning Values

In C, every function that is not declared with the `void` type must return a value. This value is provided through the `return` statement. Understanding how return values work—and how they can be used—is essential for writing correct and reliable programs.

## Requirements for Returning Values

### C89 Behavior  
In C89, if a non‑void function executes a `return` statement **without** a value, the function returns an undefined (garbage) value. Although allowed by the language, this is extremely poor practice.

### C99 and C++ Behavior  
In C99 and C++, a non‑void function **must** return a value in every `return` statement. However, if execution reaches the end of the function body without encountering a `return`, the function still returns an undefined value. This is not a syntax error, but it is a serious logical flaw and should always be avoided.

## Using Functions in Expressions

Any function that is not declared as `void` may be used as part of an expression. For example:

```c
x = power(y);
if (max(x, y) > 100) printf("greater");
for (ch = getchar(); isdigit(ch); )
    ...
```

These are all valid because each function returns a value.

### Invalid Usage

A function call **cannot** appear on the left side of an assignment:

```c
swap(x, y) = 100;   /* incorrect */
```

This is illegal, and the compiler will reject it.

## Categories of Functions

When writing programs, your functions typically fall into one of three categories:

### 1. Computational Functions  
These functions perform operations on their arguments and return a computed value.  
Examples:  
- `sqrt()`  
- `sin()`  

These are “pure” functions: they return a value and have no side effects.

### 2. Status‑Returning Functions  
These functions perform an operation and return a value indicating success or failure.  
Example:  
- `fclose()` returns `0` on success and `EOF` on error.

### 3. Procedural (Void) Functions  
These functions perform an action but do not return a value.  
Example:  
- `exit()` terminates the program.

Functions that do not return a meaningful value should be declared as `void` to prevent accidental misuse in expressions.

## Ignoring Return Values

Even though non‑void functions return values, you are not required to use them. For example, `printf()` returns the number of characters printed, but most programs ignore this value.

A common question is whether a returned value must be assigned to a variable. The answer is **no**—if you do not use it, the value is simply discarded.

### Example: Using and Ignoring Return Values

```c
#include <stdio.h>

int mul(int a, int b);

int main(void)
{
    int x, y, z;
    x = 10;
    y = 20;

    z = mul(x, y);          /* 1: return value assigned */
    printf("%d", mul(x, y));/* 2: return value used in expression */
    mul(x, y);              /* 3: return value ignored */

    return 0;
}

int mul(int a, int b)
{
    return a * b;
}
```

- **Line 1:** The return value is stored in `z`.  
- **Line 2:** The return value is passed directly to `printf()`.  
- **Line 3:** The return value is discarded.
