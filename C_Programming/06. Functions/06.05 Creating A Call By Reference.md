# Creating a Call by Reference

Although C uses **call by value** for all function arguments, you can simulate **call by reference** by passing a **pointer** to the argument rather than the argument itself. Because the function receives the argument’s **address**, it can modify the original variable outside the function.

## Using Pointers to Achieve Call by Reference

Pointers are passed to functions just like any other argument. The only requirement is that the corresponding parameters must be declared as **pointer types**.

### Example: Swapping Two Values

The following function, `swap()`, exchanges the values of two integers by receiving their addresses:

```c
void swap(int *x, int *y)
{
    int temp;
    temp = *x;   /* save the value at address x */
    *x = *y;     /* put y into x */
    *y = temp;   /* put x into y */
}
```

Because `swap()` receives the **addresses** of the variables, it can directly access and modify the values stored at those addresses using standard pointer operations.

## Calling a Function That Uses Pointer Parameters

A function like `swap()` must be called with the **addresses** of the variables you want to modify. The unary operator `&` is used to obtain a variable’s address.

### Example Program

```c
#include <stdio.h>

void swap(int *x, int *y);

int main(void)
{
    int i, j;
    i = 10;
    j = 20;

    printf("i and j before swapping: %d %d\n", i, j);
    swap(&i, &j);   /* pass the addresses of i and j */
    printf("i and j after swapping: %d %d\n", i, j);

    return 0;
}

void swap(int *x, int *y)
{
    int temp;
    temp = *x;   /* save the value at address x */
    *x = *y;     /* put y into x */
    *y = temp;   /* put x into y */
}
```

### Output

```
i and j before swapping: 10 20
i and j after swapping: 20 10
```

In this example:

- `i` is initialized to 10  
- `j` is initialized to 20  
- `swap(&i, &j)` passes their **addresses**, not their values  
- The function modifies the actual variables, resulting in the values being exchanged

## Note on C++

C++ provides built‑in **reference parameters**, which allow true call‑by‑reference semantics without using pointers.  
C does **not** support reference parameters; pointers are the only mechanism for achieving call‑by‑reference behavior.
