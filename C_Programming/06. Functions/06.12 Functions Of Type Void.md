# Functions of Type `void`

The `void` keyword is used in C to explicitly declare functions that do not return a value. Declaring a function as `void` prevents it from being used in expressions and helps avoid accidental misuse.

## Declaring a `void` Function

A `void` function performs an action but does not produce a return value. For example, the function `print_vertical()` prints the characters of a string vertically down the screen:

```c
void print_vertical(char *str)
{
    while (*str)
        printf("%c\n", *str++);
}
```

## Example Program Using `print_vertical()`

```c
#include <stdio.h>

void print_vertical(char *str);  /* prototype */

int main(int argc, char *argv[])
{
    if (argc > 1)
        print_vertical(argv[1]);
    return 0;
}

void print_vertical(char *str)
{
    while (*str)
        printf("%c\n", *str++);
}
```

If the program is run with a command‑line argument, the string is printed one character per line.

## Historical Note

Early versions of C did not include the `void` keyword. In those older programs, functions that did not return a value implicitly defaulted to type `int`, even though no value was actually returned. Modern C requires explicit use of `void` to indicate that a function returns nothing.
