# The `inline` Keyword

C99 introduced the **`inline`** keyword, which can be applied to function declarations to request that the compiler optimize calls to that function. When a function is declared as `inline`, the compiler is encouraged—though not required—to expand the function’s code directly at the point of each call rather than performing a traditional function call.

Inlining can reduce function call overhead and potentially improve performance, especially for very small, frequently used functions. However, it is important to remember that:

- `inline` is **only a suggestion**, not a command  
- The compiler is free to ignore the request  
- Inlining may increase code size if overused  

### Example (conceptual)

```c
inline int square(int x)
{
    return x * x;
}
```

In this case, the compiler may replace calls to `square()` with the expression `x * x` directly.

---

**NOTE:**  
The `inline` specifier is also supported by C++.
