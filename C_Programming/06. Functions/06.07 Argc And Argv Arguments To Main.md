# `argc` and `argv` — Arguments to `main()`

Command‑line arguments allow you to pass information into a program at the moment it is executed. In C, these arguments are received by the `main()` function through two special parameters: **`argc`** and **`argv`**.

## Understanding Command‑Line Arguments

A **command‑line argument** is any text that appears after the program’s name when it is invoked from the operating system’s command prompt. For example:

```
cc program_name
```

Here, `program_name` is a command‑line argument passed to the compiler.

## The Role of `argc` and `argv`

C provides two built‑in parameters to `main()` for handling command‑line arguments:

- **`argc`**  
  - Stands for *argument count*.  
  - Holds the number of command‑line arguments.  
  - Always at least **1**, because the program’s name counts as the first argument.

- **`argv`**  
  - Stands for *argument vector*.  
  - A pointer to an array of character pointers.  
  - Each element points to one command‑line argument.  
  - All arguments are strings; numeric values must be converted manually (e.g., using `atoi()`).

## Example: Greeting the User

The following program prints “Hello” followed by the user’s name, provided as a command‑line argument:

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc != 2) {
        printf("You forgot to type your name.\n");
        exit(1);
    }

    printf("Hello %s", argv[1]);
    return 0;
}
```

If the program is named `name` and you run:

```
name Tom
```

The output will be:

```
Hello Tom
```

## How Arguments Are Separated

- Most environments separate command‑line arguments using **spaces** or **tabs**.
- Characters like commas or semicolons are **not** separators.

Examples:

- `run Spot, run` → three arguments  
- `Herb,Rick,Fred` → one argument (commas are part of the string)

Some systems allow quoting:

```
"Hello world"
```

This is treated as a single argument. Check your OS documentation for specifics.

## Declaring `argv`

The most common declaration is:

```c
char *argv[];
```

The empty brackets indicate an array of unspecified length.  
You can access arguments using array indexing:

- `argv[0]` → program name  
- `argv[1]` → first argument  
- `argv[2]` → second argument, and so on

## Example: Countdown Program

This program counts down from a number provided on the command line. If the second argument is `"display"`, it prints each number as it counts.

```c
/* Countdown program. */
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
#include <string.h>

int main(int argc, char *argv[])
{
    int disp, count;

    if (argc < 2) {
        printf("You must enter the length of the count\n");
        printf("on the command line. Try again.\n");
        exit(1);
    }

    if (argc == 3 && !strcmp(argv[2], "display"))
        disp = 1;
    else
        disp = 0;

    for (count = atoi(argv[1]); count; --count)
        if (disp) printf("%d\n", count);

    putchar('\a');  /* ring the bell */
    printf("Done");

    return 0;
}
```

If no arguments are provided, the program prints an error message.

## Accessing Individual Characters in Arguments

Because `argv` is an array of strings, you can index both the argument and its characters:

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    int t, i;

    for (t = 0; t < argc; ++t) {
        i = 0;
        while (argv[t][i]) {
            putchar(argv[t][i]);
            ++i;
        }
        printf("\n");
    }

    return 0;
}
```

- `argv[t]` → the *t‑th* argument  
- `argv[t][i]` → the *i‑th* character of that argument

## Why Use Command‑Line Arguments?

Command‑line arguments are commonly used to specify:

- Filenames  
- Options or flags  
- Modes of operation  
- Initial configuration values  

They make programs more flexible and professional, especially when used in scripts or batch files.

## Naming `argc` and `argv`

The names are traditional but not required. You may rename them, though most programmers keep the conventional names for clarity.

Some compilers support additional parameters to `main()`. Consult your compiler’s documentation if needed.

## Declaring `main()` Without Parameters

If your program does not use command‑line arguments, it is common to explicitly declare:

```c
int main(void)
```

This indicates that `main()` takes no parameters.
