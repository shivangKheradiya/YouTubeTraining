# The `return` Statement

The `return` statement plays a central role in controlling the flow of execution within a function. It serves two primary purposes:

## 1. Exiting a Function Immediately

When a `return` statement is executed, the function terminates at that exact point. Program control is transferred back to the location where the function was called. Any statements following the `return` within the function body are skipped.

## 2. Returning a Value

In addition to ending the function, `return` can also send a value back to the calling code. This value must match the function’s declared return type. Functions that do not return a value are typically declared with the `void` type and may use `return` solely to exit early.
