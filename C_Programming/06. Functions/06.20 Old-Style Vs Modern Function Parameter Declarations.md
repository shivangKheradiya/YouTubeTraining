# Old‑Style vs. Modern Function Parameter Declarations

Early versions of C used a different method for declaring function parameters than the one used in modern C (C89, C99) and C++. This earlier approach is often referred to as the **classic form**. Modern C uses what is known as the **modern form**, which is the standard in contemporary programming.  

Although both forms are still supported by Standard C, the modern form is strongly recommended. C++ supports **only** the modern form. Still, understanding the old‑style syntax is useful when reading or maintaining older C code.

## Structure of Old‑Style Parameter Declarations

In the old‑style form, a function’s parameter declaration is split into two parts:

1. A **parameter list** inside the parentheses following the function name  
2. The **actual parameter type declarations**, written between the closing parenthesis and the opening brace

### General Form (Old‑Style)

```
type func_name(parm1, parm2, ... parmN)
type parm1;
type parm2;
...
type parmN;
{
    function code
}
```

## Example: Modern vs. Old‑Style

### Modern Declaration

```c
float f(int a, int b, char ch)
{
    /* ... */
}
```

### Old‑Style Equivalent

```c
float f(a, b, ch)
int a, b;
char ch;
{
    /* ... */
}
```

Notice that in the old‑style form, multiple parameters of the same type may be declared together after the type name.

## Important Note

**REMEMBER:**  
The old‑style parameter declaration syntax is considered **obsolete** by Standard C and is **not supported by C++**. Modern code should always use the modern declaration form for clarity, safety, and compatibility.
