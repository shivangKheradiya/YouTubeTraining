# 🗂️ Arrays of Pointers

## Overview
Just like any other data type, **pointers can be stored in arrays**. Arrays of pointers are especially useful when working with strings, dynamic data, or when you need flexible references to multiple objects.  

---

## 🛠️ Declaring Arrays of Pointers
```c
int *x[10];
```

- Declares an array of **10 pointers to integers**.  
- Each element of `x` can store the address of an integer variable.  

---

## ✔️ Example: Assigning and Accessing
```c
int var;
x[2] = &var;   /* assign address of var to third element */
*x[2];         /* access the value of var */
```

- `x[2]` → stores the address of `var`.  
- `*x[2]` → dereferences the pointer, retrieving the value of `var`.  

---

## 📌 Passing Arrays of Pointers to Functions
Arrays of pointers can be passed into functions just like normal arrays:  

```c
void display_array(int *q[]) {
    int t;
    for (t = 0; t < 10; t++)
        printf("%d ", *q[t]);
}
```

- `q` is declared as an **array of integer pointers**.  
- Important: `q` is **not** a pointer to integers, but a pointer to an array of integer pointers.  

---

## 🛠️ Common Use Case: Arrays of Strings
Pointer arrays are often used to hold pointers to string constants.  

### Example: Error Messages
```c
void syntax_error(int num) {
    static char *err[] = {
        "Cannot Open File\n",
        "Read Error\n",
        "Write Error\n",
        "Media Failure\n"
    };
    printf("%s", err[num]);
}
```

- `err` is an array of character pointers.  
- Each pointer refers to a string constant.  
- Calling `syntax_error(2)` prints:  
```
Write Error
```

---

## 📌 Real-World Example
- The **command-line argument `argv`** is an array of character pointers.  
- Each element of `argv` points to a string representing a command-line argument.
