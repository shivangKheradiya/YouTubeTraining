# ➕➖ Pointer Arithmetic

## Overview
In C, only **two arithmetic operations** are permitted on pointers:  
- **Addition**  
- **Subtraction**  

Pointer arithmetic is always performed **relative to the pointer’s base type**, ensuring that pointers move correctly between elements of the type they reference.  

---

## 🛠️ Increment and Decrement
Consider an integer pointer `p1` with a value of `2000`. Assume `int` occupies **2 bytes**:  

```c
p1++;
```
- `p1` now contains `2002`, not `2001`.  
- Each increment moves the pointer to the **next integer**.  

```c
p1--;
```
- `p1` now contains `1998`.  
- Each decrement moves the pointer to the **previous integer**.  

📌 Rule: Pointer arithmetic advances or retreats by the **size of the base type**.  

---

## ✔️ Char Pointers
- For `char` pointers, arithmetic appears “normal” because `char` is always **1 byte**.  
- Example: incrementing a `char *` increases its address by 1.  

---

## 🛠️ Adding/Subtracting Integers
You can add or subtract integers to/from pointers:  
```c
p1 = p1 + 12;
```
- Moves `p1` to the **12th element** beyond its current position.  

---

## 🛠️ Subtracting Pointers
You can subtract one pointer from another to find the **number of elements** between them:  
```c
int arr[20];
int *p1 = &arr[5];
int *p2 = &arr[15];

int diff = p2 - p1;  /* diff = 10 */
```
- The result is the count of base-type objects separating the two pointers.  

---

## 🚫 Prohibited Operations
The following operations are **not allowed** on pointers:  
- Multiplication or division  
- Adding two pointers together  
- Bitwise operations (`&`, `|`, `^`, etc.)  
- Adding or subtracting floating-point values (`float`, `double`)  

---

## 📌 Key Notes
- Pointer arithmetic is **scaled by the size of the base type**.  
- Ensures pointers always reference valid elements of their type.  
- Useful for traversing arrays and calculating distances between elements.
