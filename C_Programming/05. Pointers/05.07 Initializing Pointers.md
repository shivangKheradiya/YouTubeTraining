# 🧷 Initializing Pointers

## Overview
When a **nonstatic local pointer** is declared but not assigned a value, it contains an **unknown (garbage) value**. Using such a pointer before initialization can cause a **program crash** or even destabilize the operating system.  

- **Global pointers** and **static local pointers** are automatically initialized to `null`.  
- Local nonstatic pointers must be explicitly initialized before use.  

---

## 🛠️ The Null Pointer Convention
Most C programmers follow the convention of assigning **null** to pointers that do not currently point to valid memory.  

- `null` is represented by `0`.  
- C guarantees that no object exists at the null address.  
- A null pointer implies “points to nothing.”  

### Example:
```c
char *p = 0;       /* initialize to null */
p = NULL;          /* using the NULL macro */
```

- `NULL` is defined in headers such as `<stdio.h>`.  
- Both forms are equivalent.  

⚠️ **Important:** A null pointer is not “safe.” Dereferencing it will still cause a crash:  
```c
int *p = 0;
*p = 10;   /* WRONG! Causes crash */
```

---

## 📌 Using Null Pointers in Practice
Null pointers can simplify routines and improve efficiency. For example, they can be used to **mark the end of an array of pointers**.  

### Example: Search Function
```c
#include <stdio.h>
#include <string.h>

int search(char *p[], char *name);

char *names[] = {
    "Herb",
    "Rex",
    "Dennis",
    "John",
    NULL   /* marks end of list */
};

int main(void) {
    if (search(names, "Dennis") != -1)
        printf("Dennis is in list.\n");
    if (search(names, "Bill") == -1)
        printf("Bill not found.\n");
    return 0;
}

/* Look up a name. */
int search(char *p[], char *name) {
    register int t;
    for (t = 0; p[t]; ++t)
        if (!strcmp(p[t], name)) return t;
    return -1; /* not found */
}
```

- The array `names` ends with a `NULL` pointer.  
- The `search()` function stops when it encounters `NULL`.  
- This prevents scanning beyond the array.

## 🛠️ Initializing Pointers to String Constants
C programmers often initialize pointers to **string constants**:  
```c
char *p = "hello world";
```

- `p` is a pointer, not an array.  
- The string `"hello world"` is stored in the **string table** created by the compiler.  
- `p` holds the address of that string constant.  

### Example Program
```c
#include <stdio.h>
#include <string.h>

char *p = "hello world";

int main(void) {
    register int t;

    /* print the string forward */
    printf("%s\n", p);

    /* print the string backward */
    for (t = strlen(p) - 1; t > -1; t--)
        printf("%c", p[t]);

    return 0;
}
```

---

## 📌 Key Notes
- Always initialize pointers before use.  
- Use `NULL` to represent unused pointers.  
- Null pointers can mark the end of arrays.  
- String constants are stored in a **compiler-managed string table**, and pointers can reference them directly.
