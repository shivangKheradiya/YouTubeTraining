# 🧩 Dynamically Allocated Arrays

In C, you can allocate memory dynamically using `malloc()` and then treat that memory as if it were an array. Since pointers can be indexed like arrays, this works seamlessly.

---

## Example 1: One-Dimensional Dynamically Allocated Array (String)

```c
/* Allocate space for a string dynamically, request user input,
   and then print the string backwards. */

#include <stdlib.h>
#include <stdio.h>
#include <string.h>

int main(void) {
    char *s;
    int t;

    // Allocate memory for 80 characters
    s = malloc(80 * sizeof(char));
    if (!s) {
        printf("Memory request failed.\n");
        exit(1);
    }

    // Read input safely (use fgets instead of gets)
    printf("Enter a string: ");
    fgets(s, 80, stdin);

    // Remove newline if present
    s[strcspn(s, "\n")] = '\0';

    // Print string backwards
    for (t = strlen(s) - 1; t >= 0; t--) {
        putchar(s[t]);
    }
    putchar('\n');

    free(s);
    return 0;
}
```

✅ **Key points:**
- Always check if `malloc()` succeeded.
- Use `fgets()` instead of `gets()` (since `gets()` is unsafe).
- Free the memory when done.

## Example 2: Two-Dimensional Dynamically Allocated Array

This program builds a table of numbers 1–10 raised to the 1st, 2nd, 3rd, and 4th powers.

```c
#include <stdio.h>
#include <stdlib.h>

// Function to raise an integer to a power
int pwr(int a, int b) {
    int t = 1;
    for (; b; b--) t = t * a;
    return t;
}

int main(void) {
    // Declare a pointer to an array of 10 ints
    int (*p)[10];
    int i, j;

    // Allocate memory for a 4x10 array
    p = malloc(4 * 10 * sizeof(int));
    if (!p) {
        printf("Memory request failed.\n");
        exit(1);
    }

    // Fill the array with powers
    for (j = 1; j <= 10; j++) {
        for (i = 1; i <= 4; i++) {
            p[i - 1][j - 1] = pwr(j, i);
        }
    }

    // Print the table
    for (j = 1; j <= 10; j++) {
        for (i = 1; i <= 4; i++) {
            printf("%10d ", p[i - 1][j - 1]);
        }
        printf("\n");
    }

    free(p);
    return 0;
}
```

---

## ⚡ Important Notes
- `int (*p)[10];` declares `p` as a pointer to an array of 10 integers.
- When incremented, `p` moves to the next row of 10 integers.
- Memory is allocated manually with `malloc()` instead of automatic array declaration.
- In **C++**, you must cast the result of `malloc()`:
  ```c
  p = (int (*)[10]) malloc(40 * sizeof(int));
  ```
