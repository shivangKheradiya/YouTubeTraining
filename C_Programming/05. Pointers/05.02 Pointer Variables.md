# 🧷 Pointer Variables

## Overview
If a variable is going to be a **pointer**, it must be declared explicitly as such. A pointer declaration specifies:  
1. The **base type** of the pointer (the type of object it points to).  
2. The `*` symbol to indicate it is a pointer.  
3. The **variable name**.  

---

## 🛠️ General Form
```c
type *name;
```

- **type** → The base type of the pointer (e.g., `int`, `char`, `double`).  
- **name** → The name of the pointer variable.  

---

## ✔️ Example: Declaring a Pointer
```c
int *p;     /* p is a pointer to int */
char *c;    /* c is a pointer to char */
double *d;  /* d is a pointer to double */
```

- Each pointer is declared with a base type that defines the type of object it is expected to point to.  

---

## 📌 Base Type Importance
- Technically, any pointer can hold **any memory address**.  
- However, all pointer operations (like dereferencing or arithmetic) are performed **relative to the base type**.  
- Example:  
```c
int *p;
```
The compiler assumes that `p` points to an **integer**, whether or not the memory actually contains an integer.  

---

## ⚠️ Compatibility Requirement
Because of this behavior:  
- You must ensure that the pointer’s **base type matches the type of object** it points to.  
- If mismatched, the program may behave incorrectly or unpredictably.  

---

## ✔️ Example: Using a Pointer
```c
int x = 42;
int *p;

p = &x;          /* p points to x */
printf("%d\n", *p);  /* prints 42 */
```

- `&x` → address of `x`.  
- `p` → stores that address.  
- `*p` → dereferences the pointer, accessing the value stored at that address.  

---

By the end of this section, you will:
- Understand how to declare pointer variables in C.  
- Recognize the role of the base type in pointer operations.  
- Ensure type compatibility between pointers and the objects they reference.  
- Use pointers safely to access and manipulate memory.
