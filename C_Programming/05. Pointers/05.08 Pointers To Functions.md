# 🧭 Pointers to Functions

## Overview
A particularly **confusing yet powerful feature** of C is the **function pointer**.  
- Every function has a physical location in memory (its **entry point**).  
- This address can be stored in a pointer variable.  
- Once a pointer points to a function, the function can be **called through that pointer**.  
- Function pointers also allow functions to be **passed as arguments** to other functions, enabling flexible and reusable code.  

---

## 🛠️ Declaring Function Pointers
General form:  
```c
return_type (*name)(parameter_types);
```

Example:  
```c
int (*p)(const char *, const char *);
```
- Declares `p` as a pointer to a function that takes two `const char *` arguments and returns an `int`.  
- Parentheses around `*p` are required for correct interpretation.  

---

## ✔️ Example: Using `strcmp` via Function Pointer
```c
#include <stdio.h>
#include <string.h>

void check(char *a, char *b, int (*cmp)(const char *, const char *));

int main(void) {
    char s1[80], s2[80];
    int (*p)(const char *, const char *);  /* function pointer */

    p = strcmp;   /* assign address of strcmp to p */

    printf("Enter two strings.\n");
    gets(s1);
    gets(s2);

    check(s1, s2, p);  /* pass function pointer */
    return 0;
}

void check(char *a, char *b, int (*cmp)(const char *, const char *)) {
    printf("Testing for equality.\n");
    if (!(*cmp)(a, b)) printf("Equal");
    else printf("Not Equal");
}
```

### Key Points
- `p = strcmp;` assigns the address of `strcmp` to `p`.  
- `(*cmp)(a, b)` calls the function pointed to by `cmp`.  
- Alternative syntax: `cmp(a, b);` (simpler, but less explicit).  

---

## 📌 Why Use Function Pointers?
At first glance, using function pointers may seem unnecessary. However, they are extremely useful in scenarios such as:  
- **Passing functions as parameters** (e.g., comparison functions in sorting).  
- **Creating arrays of functions** (e.g., interpreters or parsers selecting operations dynamically).  
- **Replacing large switch statements** with indexed function calls.  

---

## ✔️ Expanded Example: Multiple Comparison Functions
```c
#include <stdio.h>
#include <ctype.h>
#include <stdlib.h>
#include <string.h>

void check(char *a, char *b, int (*cmp)(const char *, const char *));
int compvalues(const char *a, const char *b);

int main(void) {
    char s1[80], s2[80];
    printf("Enter two values or two strings.\n");
    gets(s1);
    gets(s2);

    if (isdigit(*s1)) {
        printf("Testing values for equality.\n");
        check(s1, s2, compvalues);
    } else {
        printf("Testing strings for equality.\n");
        check(s1, s2, strcmp);
    }
    return 0;
}

void check(char *a, char *b, int (*cmp)(const char *, const char *)) {
    if (!(*cmp)(a, b)) printf("Equal");
    else printf("Not Equal");
}

int compvalues(const char *a, const char *b) {
    if (atoi(a) == atoi(b)) return 0;
    else return 1;
}
```

### Explanation
- If the input begins with a digit, `compvalues()` is used to compare numeric values.  
- Otherwise, `strcmp()` is used to compare strings.  
- The `check()` function doesn’t care which comparison function is used—it simply calls the function pointer it receives.  

---

## 📌 Key Notes
- Function pointers store the **address of a function**.  
- They can be passed as arguments, stored in arrays, or reassigned dynamically.  
- Syntax requires careful use of parentheses.  
- Useful for building **flexible, modular, and efficient programs**.
