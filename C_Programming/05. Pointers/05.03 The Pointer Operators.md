# 🧷 Pointer Operators

## Overview
C provides two fundamental **pointer operators**:  
- `&` → the **address-of operator**  
- `*` → the **dereference operator**  

Together, these operators allow you to work directly with memory addresses and the values stored at those addresses.  

---

## 🛠️ The Address-of Operator (`&`)
- **Type**: Unary operator (requires one operand).  
- **Purpose**: Returns the **memory address** of its operand.  
- **Usage Example**:  
```c
m = &count;
```

### Explanation
- `&count` → the memory address of variable `count`.  
- `m` → receives that address.  
- This has **nothing to do with the value** of `count`; it only stores the location.  

📌 Example scenario:  
- Suppose `count` is stored at memory location `2000` and has the value `100`.  
- After `m = &count;`, `m` will contain `2000`.  

Verbalized: *“m receives the address of count.”*  

---

## 🛠️ The Dereference Operator (`*`)
- **Type**: Unary operator.  
- **Purpose**: Returns the **value stored at the address** held by a pointer.  
- **Usage Example**:  
```c
q = *m;
```

### Explanation
- If `m` contains the address of `count` (e.g., `2000`), then `*m` retrieves the value stored at that address.  
- `q` will receive the value `100`.  

Verbalized: *“q receives the value at address m.”*  

---

## ✔️ Combined Example
```c
int count = 100;
int *m, q;

m = &count;   /* m receives the address of count */
q = *m;       /* q receives the value at address m */
```

- `m` points to `count`.  
- `q` becomes equal to `100`.  

---

## 📌 Key Notes
- `&` → “the address of”  
- `*` → “the value at address”  
- Used together, they allow powerful memory manipulation.  
- Correct usage is critical to avoid invalid memory access.
