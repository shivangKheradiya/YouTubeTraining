# 🔀 Multiple Indirection

## Overview
In C, a pointer can point to another pointer, which in turn points to the target value. This situation is called **multiple indirection**, or **pointers to pointers**.  

- A **normal pointer** stores the address of an object.  
- A **pointer to a pointer** stores the address of another pointer, which then points to the object.  
- While technically you can chain indirection further (pointer to pointer to pointer, etc.), more than two levels is rarely needed and often confusing.  

---

## 🛠️ Declaring Pointers to Pointers
To declare a pointer to a pointer, use **two asterisks**:  
```c
float **newbalance;
```

- `newbalance` is **not** a pointer to a float.  
- It is a pointer to a **float pointer**.  

---

## ✔️ Example: Accessing Values with Multiple Indirection
```c
#include <stdio.h>

int main(void) {
    int x, *p, **q;
    x = 10;
    p = &x;   /* p points to x */
    q = &p;   /* q points to p */

    printf("%d", **q);  /* prints the value of x */
    return 0;
}
```

### Explanation
- `p` → pointer to `x`.  
- `q` → pointer to `p`.  
- `**q` → dereferences twice, retrieving the value of `x` (`10`).  

---

## 📌 Key Notes
- **Single indirection**: `*p` gives the value of the object `p` points to.  
- **Double indirection**: `**q` gives the value of the object pointed to by the pointer that `q` points to.  
- Do not confuse multiple indirection with **linked lists or other data structures** that use pointers. Those are conceptually different.  
- Excessive indirection can make code hard to read and prone to errors.
