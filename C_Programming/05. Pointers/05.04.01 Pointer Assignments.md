# 🔗 Pointer Assignments

## Overview
Pointers can be assigned to one another, allowing multiple pointers to reference the same object in memory. When both pointers are of the **same type**, assignment is straightforward. This section explains how pointer assignment works and how addresses are displayed in C.  

---

## 🛠️ Basic Pointer Assignment
```c
#include <stdio.h>

int main(void) {
    int x = 99;
    int *p1, *p2;

    p1 = &x;   /* p1 points to x */
    p2 = p1;   /* p2 now points to the same location as p1 */

    /* print the value of x twice */
    printf("Values at p1 and p2: %d %d\n", *p1, *p2);

    /* print the address of x twice */
    printf("Addresses pointed to by p1 and p2: %p %p", p1, p2);

    return 0;
}
```

---

## ✔️ Explanation
- `p1 = &x;` → `p1` stores the address of `x`.  
- `p2 = p1;` → `p2` is assigned the same address as `p1`.  
- Both `p1` and `p2` now point to the same object (`x`).  

### Sample Output
```
Values at p1 and p2: 99 99
Addresses pointed to by p1 and p2: 0063FDF0 0063FDF0
```

- Both pointers dereference to the same value (`99`).  
- Both pointers display the same address (`0063FDF0` in this example).  

---

## 📌 Displaying Addresses
- Use the **`%p` format specifier** in `printf()` to display pointer values (addresses).  
- The format of the address depends on the **host computer**.  

---

## ⚠️ Pointer Conversion
- It is possible to assign a pointer of one type to a pointer of another type.  
- Doing so involves a **pointer conversion**, which requires caution.  
- Pointer conversions are covered in the next section.
