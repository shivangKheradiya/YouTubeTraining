# 🔗 Pointers and Arrays

## Overview
In C, **pointers and arrays are closely related**. An array name without an index acts as a pointer to its **first element**, and pointers can be used to access array elements through arithmetic. This duality gives programmers flexibility in how they work with sequences of data.  

---

## 🛠️ Basic Example
```c
char str[80], *p1;
p1 = str;   /* p1 points to the first element of str */
```

- `str` → the starting address of the array (`&str[0]`).  
- `p1` → now points to the first element of `str`.  

To access the **fifth element**:  
```c
str[4];      /* array indexing */
*(p1 + 4);   /* pointer arithmetic */
```

📌 Arrays start at index **0**, so the fifth element is accessed with index `4`.  

---

## 📌 Two Methods of Access
C provides two equivalent ways to access array elements:  
1. **Array indexing** → `str[4]`  
2. **Pointer arithmetic** → `*(p1 + 4)`  

- Array indexing is often easier to read.  
- Pointer arithmetic can be faster and is widely used in performance-critical code.  

---

## ✔️ Example: Writing Strings with `putstr()`

### Version 1: Array Indexing
```c
void putstr(char *s) {
    register int t;
    for (t = 0; s[t]; ++t)
        putchar(s[t]);
}
```

### Version 2: Pointer Arithmetic
```c
void putstr(char *s) {
    while (*s)
        putchar(*s++);
}
```

- Both versions output a string character by character.  
- The pointer version is often considered **cleaner and more efficient**.  
- Professional C programmers typically prefer the pointer style.  

---

## 📌 Key Notes
- An array name without an index is equivalent to a pointer to its first element.  
- `p[n]` is equivalent to `*(p+n)`.  
- Pointer arithmetic moves through memory relative to the base type.  
- Many C routines are written using pointers for clarity and speed.
