# ⚖️ Pointer Comparisons

## Overview
In C, you can compare two pointers in a **relational expression**. This allows you to determine whether one pointer refers to a lower or higher memory location than another.  

Pointer comparisons are generally useful only when both pointers refer to elements of the **same object**, such as an array.  

---

## 🛠️ Basic Example
```c
if (p < q) 
    printf("p points to lower memory than q\n");
```

- Compares the addresses stored in `p` and `q`.  
- Prints a message if `p` points to a lower memory location.  

---

## 📌 Practical Use Case: Stack Implementation
A **stack** is a data structure that uses **first-in, last-out (FILO)** access. It is often compared to a stack of plates: the first plate placed down is the last one used.  

Stacks are widely used in:  
- Compilers  
- Interpreters  
- Spreadsheets  
- System-related software  

To implement a stack in C, you need two functions:  
- `push()` → places values on the stack.  
- `pop()` → removes values from the stack.  

---

## ✔️ Example Program
```c
#include <stdio.h>
#include <stdlib.h>

#define SIZE 50

void push(int i);
int pop(void);

int *tos, *p1, stack[SIZE];

int main(void) {
    int value;
    tos = stack;   /* tos points to the top of stack */
    p1 = stack;    /* initialize p1 */

    do {
        printf("Enter value: ");
        scanf("%d", &value);

        if (value != 0) 
            push(value);
        else 
            printf("value on top is %d\n", pop());

    } while (value != -1);

    return 0;
}

void push(int i) {
    p1++;
    if (p1 == (tos + SIZE)) {
        printf("Stack Overflow.\n");
        exit(1);
    }
    *p1 = i;
}

int pop(void) {
    if (p1 == tos) {
        printf("Stack Underflow.\n");
        exit(1);
    }
    p1--;
    return *(p1 + 1);
}
```

---

## ✔️ Explanation
- **Memory for the stack** is provided by the array `stack`.  
- `p1` points to the current element in the stack.  
- `tos` holds the memory address of the **top of the stack**.  
- **Overflow check**: In `push()`, `p1` is compared against `(tos + SIZE)` to prevent writing beyond the stack.  
- **Underflow check**: In `pop()`, `p1` is compared against `tos` to ensure the stack is not empty.  

---

## ⚠️ Important Note
In `pop()`, parentheses are necessary in the return statement:  
```c
return *(p1 + 1);
```
Without parentheses:  
```c
return *p1 + 1;
```
This would return the value at `p1` plus one, not the value at the location `p1 + 1`.
