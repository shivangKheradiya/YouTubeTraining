# 📚 Arrays

## Overview
An **array** in C is a collection of variables of the **same type**, grouped together under a **common name**. Arrays allow efficient storage and access to multiple values, making them one of the most fundamental data structures in programming.  

---

## 🛠️ Key Characteristics
- **Indexed Access** → Each element in an array is accessed using an **index**.  
- **Contiguous Memory** → All array elements are stored in **adjacent memory locations**.  
  - The **lowest address** corresponds to the first element.  
  - The **highest address** corresponds to the last element.  
- **Dimensions** → Arrays can be:  
  - **One-dimensional** (simple lists).  
  - **Multi-dimensional** (tables, matrices, etc.).  
- **Strings** → The most common array type is the **string**, which is simply an array of characters terminated by a **null character (`'\0'`)**.  

---

## ✔️ Example: One-Dimensional Array
```c
int numbers[5] = {10, 20, 30, 40, 50};
printf("%d", numbers[2]);  /* prints 30 */
```

### Explanation
- `numbers` is an array of 5 integers.  
- `numbers[2]` accesses the third element (indexing starts at 0).  

---

## ✔️ Example: String as an Array
```c
char str[] = "Hello";
printf("%s", str);  /* prints Hello */
```

### Explanation
- `str` is an array of characters.  
- The string is automatically terminated with a **null character (`'\0'`)**.  

---

## 📌 Relationship Between Arrays and Pointers
- Arrays and pointers are **closely related** in C.  
- The name of an array often acts like a pointer to its first element.  
- Understanding arrays requires knowledge of pointers, and vice versa.  
- This chapter focuses on arrays, while pointers are explored in detail later.
