# 🔤 Strings

## Overview
The most common use of a **one-dimensional array** in C is as a **character string**. In C, a string is defined as a **null-terminated character array**.  

- A **null character (`'\0'`)** marks the end of the string.  
- This is the **only type of string** defined by C.  
- Strings are widely used for text manipulation, input/output, and data processing.  

> **Note:** C++ provides a `string` class for object-oriented string handling, but this is **not supported in C**.  

---

## 🛠️ Declaring Strings
When declaring a character array to hold a string, always allocate **one extra character** for the null terminator.  

```c
char str[11];  /* can hold a 10-character string + '\0' */
```

- The array size must be **length of string + 1**.  
- Example: `"hello"` → requires 6 characters (`5 letters + '\0'`).  

---

## ✔️ String Constants
A **string constant** is a list of characters enclosed in double quotes:  
```c
"hello there"
```

- Automatically null-terminated by the compiler.  
- You do not need to add `'\0'` manually.  

---

## 📌 Common String Functions (from `<string.h>`)
| Function        | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| `strcpy(s1, s2)` | Copies `s2` into `s1`.                                                     |
| `strcat(s1, s2)` | Concatenates `s2` onto the end of `s1`.                                    |
| `strlen(s1)`     | Returns the length of `s1` (excluding the null terminator).                |
| `strcmp(s1, s2)` | Compares two strings: returns `0` if equal, `<0` if `s1 < s2`, `>0` if `s1 > s2`. |
| `strchr(s1, ch)` | Returns a pointer to the first occurrence of `ch` in `s1`.                 |
| `strstr(s1, s2)` | Returns a pointer to the first occurrence of `s2` in `s1`.                 |

---

## ✔️ Example Program
```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s1[80], s2[80];
    gets(s1);
    gets(s2);

    printf("lengths: %d %d\n", strlen(s1), strlen(s2));

    if (!strcmp(s1, s2)) 
        printf("The strings are equal\n");

    strcat(s1, s2);
    printf("%s\n", s1);

    strcpy(s1, "This is a test.\n");
    printf("%s", s1);

    if (strchr("hello", 'e')) 
        printf("e is in hello\n");

    if (strstr("hi there", "hi")) 
        printf("found hi");

    return 0;
}
```

### Sample Output (input: `"hello"` and `"hello"`)
```
lengths: 5 5
The strings are equal
hellohello
This is a test.
e is in hello
found hi
```

---

## ⚠️ Important Notes
- `strcmp()` returns **0 if strings are equal**.  
  - Use the logical **`!` operator** to test equality (`if (!strcmp(s1, s2))`).  
- Always ensure arrays are large enough to hold strings plus the null terminator.  
- Functions like `gets()` are unsafe (risk of buffer overflow). Modern C prefers `fgets()`.
