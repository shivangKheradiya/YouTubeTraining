# 📤 Passing Single-Dimension Arrays to Functions

## Overview
In C, you cannot pass an **entire array** directly as a function argument. Instead, you pass a **pointer to the first element** of the array by using the array’s name without an index. This allows functions to operate on arrays efficiently without copying all elements.  

---

## 🛠️ Example: Passing an Array
```c
int main(void) {
    int i[10];
    func1(i);   /* passes address of i[0] */
    /* ... */
}
```

- `i` is a 10-element integer array.  
- Passing `i` to `func1` sends the **address of the first element (`i[0]`)**.  

---

## 📌 Function Parameter Declarations
When a function receives a pointer to a single-dimension array, its formal parameter can be declared in **three equivalent ways**:  

```c
void func1(int *x)   /* pointer */
{
    /* ... */
}
```

```c
void func1(int x[10])   /* sized array */
{
    /* ... */
}
```

```c
void func1(int x[])   /* unsized array */
{
    /* ... */
}
```

### Explanation
- **Pointer form (`int *x`)** → Explicitly declares `x` as a pointer to `int`.  
- **Sized array form (`int x[10]`)** → Suggests an array of 10 integers, but the compiler treats it as a pointer.  
- **Unsized array form (`int x[]`)** → Indicates an array of unspecified length, but again treated as a pointer.  

All three are **functionally identical** because the compiler interprets them as receiving a pointer to `int`.  

---

## ⚠️ Important Note
- The **array length in the parameter declaration does not matter**.  
- Example:  
```c
void func1(int x[32]) {
    /* ... */
}
```
This works even if the actual array passed has a different size, because the compiler generates code for a pointer, not a fixed-size array.  
- **C does not perform bounds checking**, so it is the programmer’s responsibility to ensure indices remain valid.  

---

## 🎯 Learning Goals
By the end of this section, you will:
- Understand that arrays cannot be passed directly to functions.  
- Recognize that passing an array name sends a pointer to its first element.  
- Use any of the three valid parameter declaration styles (`int *x`, `int x[10]`, `int x[]`).  
- Appreciate that array size in function parameters is only **syntactic**, not enforced.  
- Ensure safe array handling since C does not check bounds.
