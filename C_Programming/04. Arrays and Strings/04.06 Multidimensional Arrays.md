# 🧩 Multidimensional Arrays

## Overview
C allows arrays with **more than two dimensions**, known as **multidimensional arrays**. While two-dimensional arrays are common (e.g., matrices), arrays with three or more dimensions are less frequently used due to their **large memory requirements** and **slower access times**.  

---

## 🛠️ General Form
```c
type name[Size1][Size2][Size3]...[SizeN];
```

- **type** → Base type of the array (e.g., `int`, `char`, `double`).  
- **Size1...SizeN** → Dimensions of the array.  
- Each additional dimension multiplies the total storage required.  

---

## 📌 Memory Usage
The total memory required is calculated as:  

\[
\text{bytes} = (\text{Size1} \times \text{Size2} \times \ldots \times \text{SizeN}) \times \text{sizeof(base type)}
\]

### Example:  
- A **4D character array** with dimensions `[10][6][9][4]`:  
  \[
  10 \times 6 \times 9 \times 4 = 2160 \text{ bytes}
  \]  
- If elements are **2-byte integers** → `4320 bytes`.  
- If elements are **8-byte doubles** → `17,280 bytes`.  
- Adding a **5th dimension of size 10** → `172,800 bytes`.  

⚠️ Memory usage grows **exponentially** with dimensions.  

---

## ⚡ Performance Consideration
- Accessing elements in multidimensional arrays requires computing multiple indices.  
- This makes them **slower to access** compared to single-dimension arrays.  

---

## ✔️ Example: Declaring a 4D Array
```c
int m[4][3][6][5];
```

- Declares a 4D integer array with dimensions 4 × 3 × 6 × 5.  
- Total elements = `4 × 3 × 6 × 5 = 360`.  

---

## 📌 Passing Multidimensional Arrays to Functions
When passing multidimensional arrays to functions:  
- You must declare **all but the leftmost dimension**.  
- The compiler needs the rightmost dimensions to calculate row/column offsets correctly.  

### Example:
```c
void func1(int d[][3][6][5]) {
    /* ... */
}
```

- Receives a 4D array with dimensions `[?][3][6][5]`.  
- The leftmost dimension (`?`) can be omitted or specified.
