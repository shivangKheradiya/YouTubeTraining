# 📏 Single-Dimension Arrays

## Overview
A **single-dimension array** is the simplest form of an array in C. It represents a **list of elements of the same type**, stored in **contiguous memory locations** and accessed using an **index**. Arrays must be explicitly declared so the compiler can allocate memory for them.  

---

## 🛠️ General Form
```c
type var_name[size];
```

- **type** → The base type of the array (e.g., `int`, `double`, `char`).  
- **var_name** → The name of the array.  
- **size** → The number of elements the array will hold.  

---

## ✔️ Example: Declaring an Array
```c
double balance[100];  /* 100-element array of type double */
```

- Declares an array named `balance` with 100 elements.  
- Each element is of type `double`.  

---

## 📌 Standards Note
- In **C89**, the size of an array must be a **constant expression** (fixed at compile time).  
- In **C99**, arrays can have sizes determined at **run time** (called *variable-length arrays*).  

---

## ✔️ Example: Accessing Elements
```c
balance[3] = 12.23;
```
- Assigns the value `12.23` to the **fourth element** of `balance`.  
- Remember: array indices in C start at **0**, so `balance[3]` refers to the fourth element.  

---

## ✔️ Example: Character Array
```c
char p[10];
```
- Declares a character array with 10 elements: `p[0]` through `p[9]`.  

---

## ✔️ Example Program: Loading and Displaying an Array
```c
#include <stdio.h>

int main(void) {
    int x[100];  /* declare a 100-integer array */
    int t;

    /* load x with values 0 through 99 */
    for (t = 0; t < 100; ++t) 
        x[t] = t;

    /* display contents of x */
    for (t = 0; t < 100; ++t) 
        printf("%d ", x[t]);

    return 0;
}
```

### Output
- Prints numbers `0` through `99`.  

---

## 🧮 Memory Usage
The total memory required for an array is:  

\[
\text{total bytes} = \text{sizeof(base type)} \times \text{length of array}
\]

Example:  
- `int x[100];` → If `sizeof(int) = 4`, total memory = `4 × 100 = 400 bytes`.  

---

## ⚠️ Important: No Bounds Checking
C does **not** perform bounds checking on arrays.  
```c
int count[10], i;
/* incorrect: overruns array */
for (i = 0; i < 100; i++) 
    count[i] = i;
```

- This code compiles but writes beyond the array’s valid range (`count[0]` to `count[9]`).  
- Overrunning arrays can corrupt other variables or even program code.  
- It is the **programmer’s responsibility** to ensure indices remain valid.  

---

## ✔️ Memory Layout Example
If an array starts at memory location `1000` and is declared as:  
```c
char a[7];
```
- Elements `a[0]` through `a[6]` are stored in contiguous memory locations:  
  - `a[0]` → address `1000`  
  - `a[1]` → address `1001`  
  - …  
  - `a[6]` → address `1006`
