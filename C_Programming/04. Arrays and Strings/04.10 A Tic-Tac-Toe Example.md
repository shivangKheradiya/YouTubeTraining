# 🎮 A Tic-Tac-Toe Example

## Overview
This example demonstrates how **two-dimensional arrays** can be used to simulate board game matrices. The program implements a simple **Tic-Tac-Toe** game where the player competes against the computer.  

- The **matrix array** represents the 3×3 game board.  
- The **player** places `X` marks, while the **computer** places `O` marks.  
- The game continues until either side wins or the board is full (draw).  

---

## 🛠️ Program Flow
1. **Initialization** → The board (`matrix`) is filled with spaces.  
2. **Player Move** → The player enters coordinates (1,1 for top-left; 3,3 for bottom-right).  
3. **Computer Move** → The computer scans for the first available empty cell and places an `O`.  
4. **Check Winner** → After each move, the program checks rows, columns, and diagonals for three identical marks.  
5. **Display Board** → The current state of the board is printed after each turn.  
6. **End Game** → Declares winner (`X` or `O`) or draw.  

---

## ✔️ Example Code
```c
/* A simple Tic Tac Toe game. */
#include <stdio.h>
#include <stdlib.h>

char matrix[3][3]; /* the tic tac toe matrix */

char check(void);
void init_matrix(void);
void get_player_move(void);
void get_computer_move(void);
void disp_matrix(void);

int main(void) {
    char done;
    printf("This is the game of Tic Tac Toe.\n");
    printf("You will be playing against the computer.\n");

    done = ' ';
    init_matrix();

    do {
        disp_matrix();
        get_player_move();
        done = check(); /* see if winner */
        if (done != ' ') break;

        get_computer_move();
        done = check(); /* see if winner */
    } while (done == ' ');

    if (done == 'X') printf("You won!\n");
    else printf("I won!!!!\n");

    disp_matrix(); /* show final positions */
    return 0;
}
```

## 📌 Supporting Functions

### Initialize Board
```c
void init_matrix(void) {
    int i, j;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            matrix[i][j] = ' ';
}
```

### Player Move
```c
void get_player_move(void) {
    int x, y;
    printf("Enter X,Y coordinates for your move: ");
    scanf("%d%*c%d", &x, &y);
    x--; y--;

    if (matrix[x][y] != ' ') {
        printf("Invalid move, try again.\n");
        get_player_move();
    } else matrix[x][y] = 'X';
}
```

### Computer Move
```c
void get_computer_move(void) {
    int i, j;
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++)
            if (matrix[i][j] == ' ') break;
        if (matrix[i][j] == ' ') break;
    }

    if (i * j == 9) {
        printf("draw\n");
        exit(0);
    } else matrix[i][j] = 'O';
}
```

### Display Board
```c
void disp_matrix(void) {
    int t;
    for (t = 0; t < 3; t++) {
        printf(" %c | %c | %c ", matrix[t][0], matrix[t][1], matrix[t][2]);
        if (t != 2) printf("\n---|---|---\n");
    }
    printf("\n");
}
```

### Check Winner
```c
char check(void) {
    int i;
    /* check rows */
    for (i = 0; i < 3; i++)
        if (matrix[i][0] == matrix[i][1] && matrix[i][0] == matrix[i][2])
            return matrix[i][0];

    /* check columns */
    for (i = 0; i < 3; i++)
        if (matrix[0][i] == matrix[1][i] && matrix[0][i] == matrix[2][i])
            return matrix[0][i];

    /* check diagonals */
    if (matrix[0][0] == matrix[1][1] && matrix[1][1] == matrix[2][2])
        return matrix[0][0];
    if (matrix[0][2] == matrix[1][1] && matrix[1][1] == matrix[2][0])
        return matrix[0][2];

    return ' ';
}
```
