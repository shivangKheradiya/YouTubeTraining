# 🧭 Indexing Pointers and Array Initialization

## Overview
Pointers and arrays in C are **closely related**.  
- An **array name without an index** acts as a pointer to its **first element**.  
- Conversely, a **pointer can be indexed** just like an array.  
This relationship allows flexible ways to access and manipulate data.  

---

## 🛠️ Array Names as Pointers
```c
char p[10];
```

- `p` → pointer to the first element (`p[0]`).  
- `&p[0]` → address of the first element.  
- Therefore:  
```c
p == &p[0]   /* true */
```

---

## ✔️ Example: Indexing Pointers
```c
int *p, i[10];
p = i;

p[5] = 100;      /* using index */
*(p + 5) = 100;  /* using pointer arithmetic */
```

- Both statements assign `100` to the **sixth element** of `i`.  
- `p[5]` and `*(p+5)` are equivalent.  

---

## 📌 Two-Dimensional Arrays and Pointers
For a 10×10 integer array `a`:  
```c
a == &a[0][0]   /* equivalent */
```

- Element `a[0][4]` can be accessed as:  
```c
a[0][4]
*((int *)a + 4)
```

- Element `a[1][2]` can be accessed as:  
```c
a[1][2]
*((int *)a + 12)
```

### General Rule:
\[
a[j][k] \equiv *((\text{base type} *)a + (j \times \text{row length}) + k)
\]

- Casting to the base type pointer is required for correct pointer arithmetic.  
- Pointer arithmetic is sometimes faster than array indexing.  

---

## ✔️ Example: Printing a Row with Pointers
```c
int num[10][10];

void pr_row(int j) {
    int *p, t;
    p = (int *)&num[j][0];  /* address of first element in row j */
    for (t = 0; t < 10; ++t)
        printf("%d ", *(p + t));
}
```

### Generalized Version:
```c
void pr_row(int j, int row_dimension, int *p) {
    int t;
    for (t = 0; t < row_dimension; ++t)
        printf("%d ", *(p + t));
}
```

## 📝 String Initialization
Character arrays can be initialized directly with string constants:  
```c
char str[9] = "I like C";
```

Equivalent to:  
```c
char str[9] = {'I',' ','l','i','k','e',' ','C','\0'};
```

- The array must be large enough to include the **null terminator (`'\0'`)**.  
- `"I like C"` has 8 characters, so the array size is 9.  

---

## 🧮 Multidimensional Array Initialization
Multidimensional arrays are initialized like single-dimension arrays.  

### Example:
```c
int sqrs[10][2] = {
    1, 1,
    2, 4,
    3, 9,
    4, 16,
    5, 25,
    6, 36,
    7, 49,
    8, 64,
    9, 81,
    10, 100
};
```

### With Subaggregate Grouping:
```c
int sqrs[10][2] = {
    {1, 1}, {2, 4}, {3, 9}, {4, 16}, {5, 25},
    {6, 36}, {7, 49}, {8, 64}, {9, 81}, {10, 100}
};
```

- If fewer initializers are supplied for a group, the remaining members are **automatically set to zero**.
