# 📐 Unsized Array Initializations

## Overview
When initializing arrays in C, it can be tedious to manually count characters or elements to determine the correct array size. Fortunately, C allows **unsized array initializations**, where the compiler automatically calculates the array’s size based on the number of initializers provided.  

This feature makes code more flexible and less error-prone, especially when working with strings or tables.  

---

## 🛠️ General Concept
```c
type array_name[] = { initializers };
```

- If the **size is omitted**, the compiler allocates enough space to hold all initializers.  
- Works for both **character arrays (strings)** and **multidimensional arrays**.  

---

## ✔️ Example: Strings
```c
char e1[] = "Read error\n";
char e2[] = "Write error\n";
char e3[] = "Cannot open file\n";
```

- The compiler automatically sizes each array to fit the string plus the **null terminator (`'\0'`)**.  
- Equivalent to manually declaring:  
```c
char e1[12] = "Read error\n";
char e2[13] = "Write error\n";
char e3[18] = "Cannot open file\n";
```

### Demonstration
```c
printf("%s has length %d\n", e2, sizeof e2);
```

Output:
```
Write error
 has length 13
```

---

## 📌 Advantages
- **No manual counting** of characters or elements.  
- **Safer and more maintainable**: you can change the initializer without worrying about incorrect dimensions.  
- Works for **tables and multidimensional arrays** as well.  

---

## ✔️ Example: Unsized Multidimensional Array
```c
int sqrs[][2] = {
    {1, 1},
    {2, 4},
    {3, 9},
    {4, 16},
    {5, 25},
    {6, 36},
    {7, 49},
    {8, 64},
    {9, 81},
    {10, 100}
};
```

- Declares a table of numbers and their squares.  
- The compiler automatically determines the number of rows (`10`).  
- Only the **rightmost dimension** must be specified (`2`), so the compiler knows the row length.
