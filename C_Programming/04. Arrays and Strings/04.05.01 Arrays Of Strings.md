# 📝 Arrays of Strings

## Overview
It is common in programming to use an **array of strings**. For example, a database input processor may verify user commands against an array of valid commands. In C, arrays of strings are implemented using a **two-dimensional character array**.  

- The **left dimension** specifies the number of strings.  
- The **right dimension** specifies the maximum length of each string (including the null terminator).  

---

## 🛠️ Declaration
```c
char str_array[30][80];
```

- Declares an array of **30 strings**, each with a maximum length of **79 characters** plus the null terminator.  

---

## ✔️ Accessing Individual Strings
```c
gets(str_array[2]);
```

- Reads input into the **third string** (`str_array[2]`).  
- Equivalent to:  
```c
gets(&str_array[2][0]);
```
- The first form (`str_array[2]`) is more common and idiomatic in professional C code.  

---

## ✔️ Example Program: Simple Text Editor
```c
/* A very simple text editor. */
#include <stdio.h>
#define MAX 100
#define LEN 80

char text[MAX][LEN];

int main(void) {
    register int t, i, j;
    printf("Enter an empty line to quit.\n");

    /* Input lines of text */
    for (t = 0; t < MAX; t++) {
        printf("%d: ", t);
        gets(text[t]);
        if (!*text[t]) break;  /* quit on blank line */
    }

    /* Redisplay each line character by character */
    for (i = 0; i < t; i++) {
        for (j = 0; text[i][j]; j++) 
            putchar(text[i][j]);
        putchar('\n');
    }

    return 0;
}
```

### Explanation
- The program reads up to **100 lines of text**, each up to **79 characters long**.  
- Input stops when a blank line is entered.  
- Each line is then redisplayed one character at a time.  

---

## 📌 Key Notes
- Arrays of strings are stored as **two-dimensional character arrays**.  
- Accessing a string requires only the **row index**.  
- Each string must be null-terminated (`'\0'`).  
- Functions like `gets()` are unsafe (risk of buffer overflow). Modern C prefers `fgets()`.
