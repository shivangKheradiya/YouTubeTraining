# 📏 Variable-Length Arrays (VLAs)

## Overview
In **C89**, array dimensions must be declared using **constant expressions**, meaning the size of an array is fixed at **compile time**.  

Starting with **C99**, C introduced **Variable-Length Arrays (VLAs)**, a powerful feature that allows array dimensions to be specified by **any valid expression**, including values known only at **run time**.  

---

## 🛠️ General Form
```c
type array_name[expression];
```

- **type** → Base type of the array (e.g., `int`, `char`).  
- **expression** → Any valid expression whose value is determined at run time.  

---

## ✔️ Example: Variable-Length Array
```c
void f(int dim) {
    char str[dim];  /* a variable-length character array */
    /* ... */
}
```

### Explanation
- The size of `str` is determined by the value of `dim` passed to `f()`.  
- Each call to `f()` can create `str` with a **different length**.  

---

## 📌 Scope Restrictions
- VLAs are allowed only for **local arrays**:  
  - **Block scope** (inside functions).  
  - **Prototype scope** (function parameters).  
- VLAs **cannot** be declared as global or static arrays.  

---

## ⚡ Why VLAs Were Added
- Designed primarily to support **numeric and scientific processing**, where array sizes often depend on input data.  
- Widely applicable in situations where array dimensions are not known until run time.  

---

## 🚫 Compatibility Notes
- VLAs are **not supported in C89**.  
- VLAs are **not supported in C++**.  
- Some compilers may disable VLAs unless explicitly compiled in **C99 mode** or later.  

---

## 🎯 Learning Goals
By the end of this section, you will:
- Understand the difference between fixed-size arrays (C89) and variable-length arrays (C99).  
- Declare arrays whose size is determined at run time.  
- Recognize scope restrictions: VLAs are only allowed locally.  
- Appreciate the usefulness of VLAs in numeric and scientific applications.
